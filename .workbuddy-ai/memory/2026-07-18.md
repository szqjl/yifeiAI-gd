### 部署
- JDK 17+；jar：`guandan-java-1.0.0.jar`；Windows/Linux 原生可执行 `guandan.exe` / `guandan-linux`
- 端口：单进程 **3000 (HTTP) + 8181 (WebSocket)**；集群 8181 负载均衡 + 8182/8183/8184 workers
- 启动命令：
  - 单线程：`java -jar target/guandan-java-1.0.0.jar`
  - 多线程：`java -Dguandan.cluster.mode=true -Dguandan.cluster.workers=4 -jar ...`
  - 指定端口：`java -Dserver.port=8182 -jar ...`

### WebSocket 协议（与 v1006 平台差异点要确认）
- 地址：`ws://127.0.0.1:8181`，JSON UTF-8
- **顶层结构**：`{ "type": "MESSAGE_TYPE", "data": {...} }`（与 v1006 不一样！v1006 是平铺字段）
- **客户端→服务端**：
  - `CREATE_ROOM`：`userId, round, seatNum` → `roomId, userNum`
  - `JOIN_ROOM`：`userId, roomId, seatNum` → 满 4 人自动开局
  - `PLAY`：`roomId, player, act`（act 是 `[Pattern, Rank, CardList]`）
  - `TRIBUTE`：`roomId, player, act`（`["tribute", "tribute", [cards]]`）
  - `PAYTRIBUTE`：`roomId, player, tributePos, tribute, act`（**tributePos/tribute 必须回显**）
- **服务端→客户端 `notify`（广播）**：
  - `stage: "beginning"`：`handCards, myPos`
  - `stage: "play"`：`curPos, curAction, greaterPos, greaterAction`（**全部 3 人 PASS 时 greaterPos=-1，greaterAction=null**）
  - `stage: "tribute"`：`result: [[Giver, Receiver, Card]]`
  - `stage: "anti-tribute"`：`antiNums, antiPos`
  - `stage: "back"`：`result: [[Returner, Receiver, Card]]`
  - `stage: "episodeOver"`：`order, curRank, restCards: [[Seat, [cards]]]`
  - `stage: "gameOver"`：`curTimes, settingTimes`（**N 局**）
  - `stage: "gameResult"`：`victory, victoryRank`（**victory: 0 = 0+2 队，1 = 1+3 队**）
- **服务端→客户端 `act`（定向）**：
  - `type: "act"` + `stage` + `handCards, publicInfo[{rest}], selfRank, oppoRank, curRank, curPos, curAction, greaterAction, greaterPos, actionList, indexRange`
  - 回复方式：从 `actionList` 中按 index 选（`actionList[selectedIndex]`）
  - `stage: "tribute"` / `"back"` 的 `act` 也按 index 选

### 牌型

- **新增 `FourKings`**（字面「四张 K」炸弹，与王炸区别？待 v8-dev 客户端确认）

### 关键差异（v8 vs v1006 平台）
1. **消息嵌套**：v1006 是平铺字段 `{stage, handCards, ...}`；v8 是 `{type, data: {...}}` 或 `{type, stage, ...}` 混用
2. **act 响应方式**：v8 显式给 `indexRange`，客户端回 `actionList[index]`；v1006 客户端回 `{"actIndex": N}` 或 `{"act": [...]}`
3. **新建房间接口**：v8 有 `CREATE_ROOM` + `JOIN_ROOM`（4 人 room 模型）；v1006 是平台调度，无显式建房
4. **断线**：v8 明说「不支持自动重连，需新连接」
5. **还贡牌点限制**：v8 显式说「不能 > 10」
