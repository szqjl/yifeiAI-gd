# Guandan AI Development Journal

## Date: 2025-11-30
### Topic: Transition to Self-Learning Architecture (V5)

Today marks a major milestone in the development of the Guandan AI. We have successfully transitioned from a purely rule-based system (V4) to a **Self-Learning Reinforcement Learning System (V5)**. This shift allows the AI to learn strategies autonomously through self-play and imitation, rather than relying solely on hard-coded logic.

### 1. Architecture Redesign
We restructured the project into five key components to support autonomous learning:

*   **The Playground (`src/rl_env`)**:
    *   Created `game_engine.py`: A high-performance local game logic engine.
    *   Created `guandan_env.py`: A Gymnasium-compatible environment wrapper, allowing standard RL algorithms to interact with the game.

*   **The Brain (`src/rl_agent`)**:
    *   Implemented `model.py`: A Neural Network (MLP) that takes game state (hand, table, history) as input and outputs action probabilities for 108 possible card moves.
    *   Implemented `agent.py`: A **PPO (Proximal Policy Optimization)** agent that learns from experience.

*   **The Teacher (`src/knowledge_processor`)**:
    *   Implemented `replay_parser.py`: A tool to parse existing JSON game logs into training data.
    *   Implemented `strategy_encoder.py`: A reward shaping module that translates text-based strategy rules (e.g., "don't break bombs") into numerical rewards to guide the AI.

*   **The Dojo (`src/train`)**:
    *   **Imitation Learning**: Created `pretrain.py` to clone behavior from human/V4 logs. We successfully trained a baseline model (`bc_model_v1.pth`) on 211 samples.
    *   **Self-Play**: Created `self_play.py` for the AI to play against itself. This loop generates data, updates the model, and saves checkpoints (`ppo_model_v1.pth`).
    *   **Logging**: Added `TRAINING_LOG.md` to track rewards and win rates over time.

*   **Integration (`src/decision`)**:
    *   Created `rl_decision_engine.py`: A bridge that allows the main game client (`yf1_v4.py`) to use the trained RL model for decision-making.
    *   Updated `yf1_v4.py` to support switching between the Rule-Based Engine and the RL Engine.

### 2. Key Achievements
-   **Autonomous Learning Loop**: The AI can now play millions of games against itself locally to improve.
-   **Hybrid Capability**: The client can still use the robust V4 logic while the V5 RL model is training and maturing.
-   **Knowledge Integration**: We built a pipeline to feed human knowledge (replays and rules) into the RL training process.

### 3. Next Steps
-   **Training**: Run `START_RL_TRAINING.bat` for an extended period (days) to let the AI converge on optimal strategies.
-   **Refinement**: Improve the `strategy_encoder` with more complex rules from the strategy documents.
-   **Evaluation**: Regularly test the RL agent against the V4 Rule-Based agent to measure progress.
