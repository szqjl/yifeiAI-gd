## 4. 平台 `NUM_GAMES` 单位陷阱（**需写入 memory**）

- 设置 `NUM_GAMES=30`，实际只产出 **20 局**记录（`game_count=20`），平台输出 1 次 `达到设定游戏次数`。
- 推测：`offline_platform v1006` 把 `NUM_GAMES` 当作 **目标级数/分数阈值**（如某队累计胜场或晋级到某等级即结束），而不是 round 数。
- **影响**：要跑 N 局，不能简单设 `NUM_GAMES=N`。后续需校准换算关系或采用别的统计口径（如运行 K 次小批量再合并）。
- 本批次 75 分钟实际只跑了约 1 分钟的决策时间（10:07:17–10:07:22 完成），其余时间是平台空转 + 兜底超时。**下次可把 `GAME_RUN_TIMEOUT` 降回 ~120s**，平台结束后客户端会被强制 kill，对结果没影响。
