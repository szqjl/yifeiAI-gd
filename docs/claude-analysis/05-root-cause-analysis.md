# 05 - 根本原因分析（最终诊断）

**日期**：2026-05-27  
**核心结论**：M1 的 0% 胜率 = 信息贫乏 + 缺乏队伙协作能力

---

## 🎯 根本原因一句话

**M1 的 0% 胜率不是因为「决策逻辑不对」，而是因为「缺乏对对手和队友的历史信息」，导致无法做到队伍级协作和对手建模。**

---

## 问题的三个战略层次

### Lv1：个别决策（M1 在做，做得不够好）

```
这一张牌：我该出什么？
✅ M1 能判断：单张 > 对子 > 三张
✅ M1 能判断：主动 vs 被动
✅ M1 能判断：压住 vs PASS
❌ 但不能：联动队友、对抗对手
```

### Lv2：队伍联动（M1 几乎不做）

```
这一副：我+队友如何配合赢这一副？

关键行为：
- 👥 主动传牌给队友
- 🎯 压制对手为队友创造机会
- 📊 根据队友剩牌调整激进程度
- 🧩 残局规划：两手如何恰好出完

M1 缺失：完全没有这一层
```

### Lv3：全局对抗（只有 lalala 做）

```
这一局：我们队能否从2打到A并双上？

关键决策：
- 这一副争头游还是保存实力？
- 对方快升A了，要全力阻拦吗？
- 级数差距时怎么调整激进程度？

M1 缺失：没有全局视野
```

## M1 的信息贫乏问题

### 对比：lalala vs M1

```
lalala：
  ├─ 完整的 history（对手出过什么）
  ├─ 完整的 remain_cards（剩余牌库）
  ├─ 可以做对手建模
  ├─ 可以做队伙规划
  └─ → 能赢

M1：
  ├─ 手牌（handCards）
  ├─ 合法动作列表（actionList）
  ├─ 其他玩家剩牌数（numofnext, numofpre, etc.）
  ├─ 无对手建模能力
  ├─ 无队伙规划能力
  └─ → 必输
```

**根本问题不在"决策逻辑对不对"，而在"能获取到什么信息"。**

即使 M1 的决策逻辑再完美，也无法超越 lalala，因为：

1. **不知道对手出过什么牌** → 无法压制对手的薄弱点
2. **不知道队友出过什么牌** → 无法为队友创造机会
3. **不知道总牌库分布** → 无法规划残局

## 最终结论

### PHASE2 的失败根因

PHASE2 的 50+ 改动在解决"这一张牌对不对"的问题。

但掼蛋赢的关键**不在"这一张牌"，而在"这一副怎么双上"**。

而"这一副怎么双上"取决于"我队两人是否配合"。

而"配合"需要"知道对方已经出过什么牌"。

**所以，真正需要改的不是"决策逻辑"，而是"能获取到什么信息"。**

### 从 lalala 学来的最关键的东西

**不是"if-then 规则"，而是"完整的状态观察"。**
