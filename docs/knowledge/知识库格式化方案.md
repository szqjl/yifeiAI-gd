#### 0.6 出牌顺序和位缃关系（平台标准）

**出牌顺序**（平台实际实现）：
- 根据平台使用说明：`order` 瀛楁佃〃示完鐗屾″簭：堝 `[0, 1, 2, 3]`），代表出牌顺序
- 根据一等奖代码实现：`numofnext = (myPos+1)%4`（下家），`numofpre = (myPos-1)%4`（上家）
- **平台实际出牌顺序**：**0 ↓ 1 ↓ 2 ↓ 3 ↓ 0...**（顺时针：

**位置关系计算鍏寮**：
- **涓嬪朵綅缃**：`(myPos + 1) % 4`
- **涓婂朵綅缃**：`(myPos - 1) % 4`
- **瀵瑰朵綅缃**：`(myPos + 2) % 4`（队友）

**座位关系示例**（按出牌顺序，顺时针）：
- **0号位**：
  - 涓婂讹細**3号位**（在0之前出牌，`(0-1)%4=3`：
  - 涓嬪讹細**1号位**（在0之后出牌，`(0+1)%4=1`：
  - 瀵瑰讹細**2号位**（队友，`(0+2)%4=2`：
- **1号位**：
  - 涓婂讹細**0号位**（在1之前出牌，`(1-1)%4=0`：
  - 涓嬪讹細**2号位**（在1之后出牌，`(1+1)%4=2`：
  - 瀵瑰讹細**3号位**（队友，`(1+2)%4=3`：
- **2号位**：
  - 涓婂讹細**1号位**（在2之前出牌，`(2-1)%4=1`：
  - 涓嬪讹細**3号位**（在2之后出牌，`(2+1)%4=3`：
  - 瀵瑰讹細**0号位**（队友，`(2+2)%4=0`：
- **3号位**：
  - 涓婂讹細**2号位**（在3之前出牌，`(3-1)%4=2`：
  - 涓嬪讹細**0号位**（在3之后出牌，`(3+1)%4=0`：
  - 瀵瑰讹細**1号位**（队友，`(3+2)%4=1`：

**閲嶈佽说明**：
- 虽然江苏掼蛋规则绗240鏉¤"出牌浠ラ嗘椂针为搴"，但平台实际实现为顺时针顺序
- 应以平台实现为准，使用顺时针顺序和上杩拌＄畻鍏寮

# 掼蛋牌型定义

## 概述
掼蛋游戏涓的合法牌型及其定义，鏄游戏的基础规则銆

## 牌型列表（平台标准变量）

### 1. 单张 (Single)
- **平台变量鍚**: `Single`
- **定义**：任意一张牌
- **优先绾**：最浣
- **应用场景**：所有场鏅
- **JSON示例**:
  ```json
  {
    "type": "Single",
    "cards": ["H2"]
  }
  ```

### 2. 对子 (Pair)
- **平台变量鍚**: `Pair`
- **定义**：两张牌点相同的牌，包括两张大王和两张小鐜
- **优先绾**：低
- **应用场景**：控制单寮犮侀厤合策鐣
- **JSON示例**:
  ```json
  {
    "type": "Pair",
    "cards": ["H2", "D2"]
  }
  ```

### 3. 三张 (Trips)
- **平台变量鍚**: `Trips`
- **定义**：三张牌点相同的鐗
- **优先绾**：中
- **应用场景**：配鍚堝瑰瓙组成三带浜

### 4. 三连瀵 (ThreePair)
- **平台变量鍚**: `ThreePair`
- **定义**：三涓牌点相邻鐨勫瑰瓙
- **优先绾**：中
- **应用场景**：快速出鐗屻佸噺少手鏁

### 5. 三带浜 (ThreeWithTwo)
- **平台变量鍚**: `ThreeWithTwo`
- **定义**：一涓三张和一涓对子
- **优先绾**：中
- **应用场景**：常见组牌方寮

### 6. 钢板 (TwoTrips)
- **平台变量鍚**: `TwoTrips`
- **定义**：两涓牌点相邻的三寮
- **优先绾**：中楂
- **应用场景**：特殊牌型，鍙鍋疯

### 7. 顺子 (Straight)
- **平台变量鍚**: `Straight`
- **定义**：五张牌点相邻的单张
- **优先绾**：中
- **应用场景**：连接单鐗

### 8. 同花椤 (StraightFlush)
- **平台变量鍚**: `StraightFlush` 猸 淇正：使用平台标准变量鍚
- **定义**：花色相同的顺子（特殊顺子）
- **优先绾**：高
- **应用场景**：可鍘5张以内的炸弹

### 9. 炸弹 (Bomb)
- **平台变量鍚**: `Bomb`
- **定义**：四寮(鍚)以上牌点相同的单寮
- **优先绾**：最楂
- **应用场景**：扭杞牌路、闯鍏

### 10. 王炸 (Bomb)
- **平台变量鍚**: `Bomb` (特殊)
- **定义**：大鐜嬨佸皬王各两张
- **优先绾**：最楂
- **应用场景**：可压所有牌鍨

# 出炸鎶巧之涓：炸浠么牌

## 概述
炸弹鏄掼蛋涓绋有的重型武器，平均每浜2.1涓炸，每个炸价鍊4鐐广傛ｇ‘选择炸什么牌鏄出炸鎶巧的基础銆

## 核心原则
**经济性原鍒**：用鏈小的代价获得鏈大的收益

## 炸牌优先绾

### 1. 首打炸弹（最高优先级：
- **原因**：炸弹打炸弹鏈鍚堥傦紝4点压4点最为经娴
- **适用**：80%的情况下鏄正确鐨
- **操作**：氱板埌敌人的炸弹闭眼打浣

### 2. 打双大王
- **浠峰**：2点强
- **作用**：控鍒2手单璺，也鍙控制对子
- **牌力**：仅次于炸弹

### 3. 打主牌三带二 (ThreeWithTwo)
- **平台变量鍚**: `ThreeWithTwo`
- **浠峰**：1点强
- **作用**：控制三带二，拆鎴愬瑰瓙鍙能登基，后期单主牌也有很大的登基机会
- **JSON示例**（平台格式）:
  ```json
  ["ThreeWithTwo", "2", ["H2", "D2", "C2", "H3", "D3"]]
  ```

### 4. 打其他登基牌
- **浠峰**：1鐐
- **说明**：价鍊1点的登基鐗

### 5. 打其他牌
- **适用**：弄不准鏄否为登基牌，但为了避免敌方跑牌太多，鍙及时出炸鍒舵
- **说明**：虽属超打，但有时很有必瑕

## 超打概念
**定义**：压牌时，不鏄用刚好大对方涓级的牌，而是用相对较大的鐗

**鍧忓**：可鑳介犳垚敌方的小牌登鍩

**示例**：
- 你手涓有大鐜(`R`)、A，上家出K你直接用大王压，就是超打

## 概述

- 鉁 **单牌弱路****：** 如果单牌鏄强路且有两个小单张时，可酌情考虑銆
- 鉁 **两个小单寮**：必然一大一小，先打鍝涓好呢？需要运用尾牌原鐞嗐

## 操作姝ラ

4. 首攻单张：优鍏堝勭悊弱路单张

- **盘牌首攻非常閲嶈**：有鏃跺欓栨敾错了，头游也灏遍炰簡
- **两个小单张不打不健康**：这鏄掼蛋的经典口璇

## 鈴 时间处理规范

### 时间瀛楁佃佹眰

**所有时间相关字段必须使用系统时间API：岀佹㈢‖编码时间銆**

#### Python示例
```python
from datetime import datetime

# 获取当前时间
current_time = datetime.now()

# 格式化时间字符串
time_str = current_time.strftime('%Y-%m-%d %H:%M:%S')
# 输出：2025-01-XX XX:XX:XX

# 涓文格寮
time_str_cn = current_time.strftime('%Y骞%m鏈%d鏃 %H:%M:%S')
# 输出：2025骞01月XX鏃 XX:XX:XX
```

#### JavaScript示例
```javascript
// 获取当前时间
const currentTime = new Date();

// 格式化时间字符串
const timeStr = currentTime.toLocaleString('zh-CN', {
  year: 'numeric',
  month: '2-digit',
  day: '2-digit',
  hour: '2-digit',
  minute: '2-digit',
  second: '2-digit'
});
// 输出：2025/01/XX XX:XX:XX

// ISO格式
const isoStr = currentTime.toISOString();
// 输出：2025-01-XXTXX:XX:XX.XXXZ
```
