# 开局策略 (Opening Strategy)

## 📖 说明

开局策略库包含游戏开局阶段（第一圈牌，剩余牌数 >= 20）的核心策略。

## 📁 文件列表

### 01_opening_teammate_cooperation.md - 开局队友配合策略
**优先级**：高（8/10）  
**来源**：基于对战日志分析（yfv4_vs_lalala）

**核心内容**：
- ❌ **错误案例**：开局越级打大牌
- ✅ **正确策略**：队友出小牌，对手顺牌时应该PASS
- 📋 **判断标准**：阶段判断、牌值差距、对手行为
- 💻 **代码实现建议**

**关键原则**：
1. 开局阶段不应该越级打大牌
2. 队友出小牌，对手顺牌时，应该PASS
3. 越级打大牌只在后期冲刺阶段使用
4. 大牌应该保留用于关键时刻

## 🎯 开局阶段特点

- **阶段定义**：第一圈牌，剩余牌数 >= 20
- **关键目标**：试探对手、保留大牌、配合队友
- **常见错误**：开局越级打大牌、打断队友节奏
