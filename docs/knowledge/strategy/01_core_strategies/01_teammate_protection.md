# 队友保护策略

## 📖 概述

队友保护策略是掼蛋中最核心的策略之一，基于**掼蛋四项基本原则**中的"谁打谁收"和"配合至上"原则。当队友控场时，应该让队友继续控场，而不是用大牌或炸弹压制队友。

**核心原则来源**：
- **谁打谁收原则**：搭档先发的牌，你接牌要慎重，避免影响搭档回收
- **配合至上原则**：战略统领战术，战术体现战略
- **强牌弱打弱牌强打原则**：根据牌力配合队友

## ❌ 严重错误案例

### 案例1：用炸弹压队友的大王

#### 案例描述

**对局场景**：开局阶段，第一圈牌（行14-23）

**出牌序列**：
1. 2号位（队友yf2_v4）打出 `Single R`（红桃R，**大王**）✅ 控场
2. 3号位（对手lalala）打出 `PASS` ✅ 正确（没有更大的牌，无法压制）
3. **0号位（队友yf1_v4）打出 `Bomb K`** ❌ **严重错误！**
4. 1号位（对手lalala）打出 `PASS`
5. 2号位（队友yf2_v4）打出 `PASS`

### 问题分析

#### 1. 队友控场时不应该压制

- **队友状态**：2号位用**大王R**控场，这是最大的单张
- **对手反应**：3号位PASS，表示没有更大的牌，无法压制
- **正确策略**：0号位应该PASS，让队友2号位继续控场
- **实际行为**：0号位用炸弹K压了队友的**大王R**

#### 2. 开局阶段不应该用炸弹压队友

- **阶段判断**：这是开局阶段，第一圈牌
- **牌值对比**：
  - 队友出的是 `Single R`（**大王**，最大的单张）
  - 0号位用 `Bomb K`（炸弹K，4张K）
- **问题**：开局阶段用炸弹压队友的**大王**，完全没必要，浪费炸弹资源

#### 3. 浪费炸弹资源

- **炸弹价值**：炸弹是稀缺资源，开局阶段应该保留
- **使用场景**：炸弹应该用于关键时刻，如压制对手、保护队友冲刺
- **错误使用**：用炸弹压队友的单张，浪费了宝贵的炸弹资源

#### 4. 打断队友节奏

- **队友意图**：2号位用**大王R**控场，可能是想继续出牌
- **正确策略**：让队友继续控场，可以更好地配合
- **实际行为**：0号位用炸弹打断队友节奏，破坏了配合

### 正确的策略应该是

```
2号位出R（大王）→ 3号位PASS → 0号位应该PASS → 
让2号位继续控场，或者等1号位出牌后再决定
```

### 案例2：越级打牌和拆对子压小单

#### 案例描述

**对局场景**：开局阶段，第三轮次（行21-50）

**出牌序列**：
1. 0号位（队友yf1_v4）打出 `Bomb K`（炸弹K）→ 获得牌权
2. 0号位打出 `Single 5` ✅ 投喂队友，这个没问题（因为刚才队友2号位起手打的单）
3. 1号位（对手lalala）打出 `Single 6` ✅ 正常跟牌
4. **2号位（队友yf2_v4）打出 `Single A`** ❌ **越级打牌！**（从6直接跳到A，差距8级）
5. 3号位（对手lalala）打出 `Single 2` ✅ 跟了级牌2，正好压制A（lalala表现到位）
6. 0号位（队友yf1_v4）打出 `Single B`（小王）✅ 没问题
7. 1号位（对手lalala）打出 `Single R`（大王）✅ 1号位大王压了小王
8. 2号位（队友yf2_v4）打出 `PASS` ✅ 没问题
9. 0号位（队友yf1_v4）打出 `PASS` ✅ 没问题
10. 1号位（对手lalala）打出 `Single 4` ✅ 获得出牌权，打单4
11. **2号位（队友yf2_v4）打出 `Single A`** ❌ **严重错误！拆对子A压小单4**

#### 问题分析

##### 1. 越级打牌（行32）

**错误行为**：
- 1号位出 `Single 6`
- 2号位直接出 `Single A`（从6跳到A，差距8级）

**问题**：
- **开局阶段不应该越级打大牌**：除非进入后期，自己要冲刺争头游，才用这个手法
- **不清楚队友牌强牌弱**：2号位还不清楚队友0号位牌强牌弱的情况，就直接越级打出A
- **浪费大牌资源**：A是重要的单张，开局阶段应该保留，用于关键时刻

**正确策略**：
- 应该PASS，让对手继续出牌
- 或者如果有7、8、9等中等牌，可以跟牌
- 不应该直接越级打A

##### 2. 拆对子压小单（行50）

**错误行为**：
- 1号位出 `Single 4`（小单张）
- 2号位出 `Single A`（说明原来有对子A，拆了压的单）

**问题**：
- **拆对子毫无道理**：对子A是很好的牌型，不应该拆成单张
- **压小单浪费大牌**：用A压4，浪费了A的价值
- **破坏牌型结构**：拆对子后，手牌结构变差，可能影响后续出牌

**正确策略**：
- 应该PASS，让对手继续出牌
- 或者如果有5、6、7等中等牌，可以跟牌
- **绝对不应该拆对子A来压小单4**

#### 对比：lalala的正确表现

**lalala的表现**（行38、40）：
- 3号位（lalala）出 `Single 2`：跟了级牌2，正好压制A ✅
- 1号位（lalala）出 `Single R`（大王）：1号位大王压了小王 ✅

**说明**：
- lalala的跟牌策略很到位，不会越级打牌
- 用级牌2压制A，既压制了对手，又保留了更大的牌

#### 正确的策略应该是

**行32的正确策略**：
```
1号位出Single 6 → 2号位应该PASS或跟小牌（7、8、9）→ 
不应该越级打A
```

**行50的正确策略**：
```
1号位出Single 4 → 2号位应该PASS或跟小牌（5、6、7）→ 
绝对不应该拆对子A来压小单4
```

#### 核心原则

1. **开局阶段不要越级打大牌**：除非进入后期冲刺阶段
2. **不要拆对子压小单**：对子是很好的牌型，不应该轻易拆掉
3. **保留大牌资源**：A、2、Joker等大牌应该保留，用于关键时刻
4. **配合队友**：队友出牌时，应该让队友继续控场，不要越级压制

## ✅ 正确策略（基于掼蛋四项基本原则）

### 1. 谁打谁收原则（核心原则）

**原则内容**："谁打谁收"是有效的进攻手段，先发的牌路最好有大牌可以收尾，这样一次可以减少2手。

#### 1.1 岗位责任

- **各司其职**：你在那个岗位上，你就得坚守
- **本家回收**：本家主打的牌，本家当然应当回收，不给搭档无谓的压力
- **搭档接牌要慎重**：搭档先发的牌，你接牌要慎重，避免影响搭档回收

#### 1.2 信任关系

- **信任对方**：要信任对方，他既然这样发，肯定有他的道理
- **开局阶段**：在掼蛋过程中，特别是开局阶段，主打方基本都选择打自己的优势牌
- **回接能力**：在这样的客观情况下，主打人是具备回接能力的，不用担心对手方的阻拦

#### 1.3 应用场景

**队友出大牌控场**：
- 队友出大牌（如2、Joker、A等）控场
- 对手PASS，表示无法压制
- ✅ **应该PASS**，让队友继续控场，让队友"谁打谁收"
- ❌ **不应该用炸弹压制**队友的单张
- ❌ **不应该用大牌压制**队友的单张

**队友出炸弹控场**：
- 队友出炸弹控场
- 对手PASS
- ✅ **必须PASS**，让队友继续控场
- ❌ **绝对不能用炸弹压制**队友的炸弹（除非是更大的炸弹且有必要）

### 2. 配合至上原则

**原则内容**：战略统领战术，战术体现战略。

#### 2.1 让道（核心配合技巧）

**原则**：搭档出小单张、小对子，尤其是小顺子的出现，就算能套也最好不要，留顺子可以送回去。

**策略**：
- ✅ **牌好才接**：除非过了这手牌就能争上游
- ✅ **牌不好不接**：牌不好不但不接，上家出牌有时都不要，让搭档接
- ❌ **不要套牌**：搭档出小顺子，就算能套也最好不要，留顺子可以送回去

**应用场景**：
- 队友出 `Single 3`、`Single 4` 等小单张 → 应该PASS，让队友继续
- 队友出 `Pair 3`、`Pair 4` 等小对子 → 应该PASS，让队友继续
- 队友出 `Straight 34567` 等小顺子 → 应该PASS，留顺子可以送回去

#### 2.2 反向喂牌

**原则**：对手已经出了两种牌形，搭档均不要，出炸夺得出牌权，出与对手牌形相反的牌。

**策略**：
- **判断搭档牌型**：如对手出小顺子，搭档不要，可以判断搭档手中牌以"三带二"为主
- **出炸夺权**：判断准后出炸或拆牌组成大顺子压后夺得主动权
- **反向喂牌**：出牌时可出小"三带二"让搭档过牌

**应用场景**：
- 对手出 `Straight 34567`，队友PASS
- 对手出 `Pair 3`，队友PASS
- 判断：队友可能以 `ThreeWithTwo` 为主
- 策略：出炸夺权后，出小 `ThreeWithTwo` 让队友过牌

#### 2.3 拆牌喂牌

**原则**：就是明知搭档需要什么牌形，你手上没有这种牌形，那也要想办法拆牌组成这个牌形也要喂给搭档，甚至拆炸组成搭档需要的牌形，以保证对家争上游。

**策略**：
- **拆牌组成**：没有搭档需要的牌形，也要拆牌组成
- **拆炸喂牌**：甚至拆炸组成搭档需要的牌形
- **目标**：保证对家争上游

**应用场景**：
- 队友需要 `Pair 5`，但自己没有
- 可以拆 `ThreeWithTwo 55566` 中的 `Pair 5` 喂给队友
- 甚至拆炸弹组成 `Pair 5` 喂给队友

#### 2.4 先大后小巧喂牌

**原则**：刚开始喂牌尽量出大一点牌，让下家阻击，你在还击后再出稍大一点牌，几次过后，消耗了下家的阻挡力后，出小牌下家因无力再挡。

**策略**：
- **先出大牌**：刚开始喂牌尽量出大一点牌
- **消耗下家**：让下家阻击，你在还击后再出稍大一点牌
- **出小牌**：几次过后，消耗了下家的阻挡力后，出小牌下家因无力再挡

**应用场景**：
- 想喂队友 `Pair 5`
- 先出 `Pair K`，下家阻击
- 再出 `Pair Q`，下家再阻击
- 最后出 `Pair 5`，下家无力再挡，队友可以过牌

### 3. 强牌弱打弱牌强打原则

**原则内容**：根据牌力配合队友。

#### 3.1 强牌弱打

**目的**：
1. **吸引并消灭对方选手主力**：为了吸引并消灭对方选手主力
2. **给搭档展示牌力和牌型的机会**：给搭档展示牌力和牌型的机会

**策略**：
- **搭档牌力也强**：如果搭档牌力也强，就一起努力获得上游和二游的双升局面
- **搭档牌力一般**：如果搭档牌力一般，就适当支持和配合搭档，避免搭档被对方选手合力阻击成为下游

#### 3.2 弱牌强打

**原则**：牌力一般，下家出的牌型搭档接不住，作为最后的防守方炸弹阻击，然后送出搭档出过的牌型或者搭档需要的牌型，牺牲自己支持搭档争上游。

**策略**：
- **炸弹阻击**：作为最后的防守方炸弹阻击
- **送出搭档需要的牌型**：然后送出搭档出过的牌型或者搭档需要的牌型
- **牺牲自己**：牺牲自己支持搭档争上游
- **出牌选择**：这时候火打第一夯（三带二）或者第一顺

**应用场景**：
- 自己牌力一般
- 下家出 `Single A`，队友接不住
- 用炸弹阻击
- 然后出队友需要的牌型（如 `ThreeWithTwo` 或 `Straight`）

### 4. 炸弹使用的正确场景

**适用场景**（基于"配合至上"和"强牌弱打弱牌强打"原则）：
- ✅ **压制对手**：对手出大牌或炸弹，需要压制
- ✅ **保护队友冲刺**：队友快走完，对手压制时用炸弹保护（弱牌强打）
- ✅ **关键时刻**：残局阶段，需要争夺头游
- ✅ **反向喂牌**：出炸夺得出牌权，出与对手牌形相反的牌，让队友过牌
- ✅ **拆炸喂牌**：甚至拆炸组成搭档需要的牌形，以保证对家争上游

**不适用场景**：
- ❌ **开局阶段压队友**：开局阶段不应该用炸弹压队友（违反"谁打谁收"原则）
- ❌ **队友控场时**：队友控场时不应该用炸弹打断（违反"谁打谁收"原则）
- ❌ **浪费炸弹**：不应该用炸弹压队友的单张（违反"配合至上"原则）

### 5. 判断标准（基于掼蛋原则）

#### 3.1 队友控场判断

```python
def is_teammate_controlling(self, message):
    """
    判断队友是否控场
    
    Returns:
        bool: True表示队友控场
    """
    greater_pos = message.get('greaterPos', -1)
    teammate_pos = (message.get('myPos', 0) + 2) % 4
    
    return greater_pos == teammate_pos
```

#### 3.2 是否应该PASS

```python
def should_pass_for_teammate(self, action, message):
    """
    判断是否应该PASS让队友继续控场
    
    Args:
        action: 当前候选动作
        message: 游戏消息
    
    Returns:
        bool: True表示应该PASS
    """
    # 判断队友是否控场
    if not self.is_teammate_controlling(message):
        return False
    
    # 判断是否开局阶段
    cards_left = message.get('cards_left', 27)
    is_opening = cards_left >= 20
    
    # 开局阶段，队友控场，应该PASS
    if is_opening:
        # 除非是后期冲刺阶段
        teammate_cards = self._get_teammate_cards_left(message)
        if teammate_cards > 5:
            return True  # 应该PASS
    
    # 判断动作类型
    action_type = action[0] if len(action) > 0 else "PASS"
    
    # 如果是炸弹，绝对不应该压队友
    if action_type == "Bomb":
        return True  # 必须PASS
    
    # 如果是大牌（A、2、Joker），开局阶段应该PASS
    if action_type == "Single" and len(action) >= 2:
        card_value = self._get_card_value(action[1])
        if card_value >= 14 and is_opening:  # A=14, 2=15, Joker=16/17
            return True  # 应该PASS
    
    return False
```

    # ========== 规则1：谁打谁收原则 ==========
    # 绝对不能用炸弹压队友
    if action_type == "Bomb":
        return True  # 必须PASS
    
    # 开局阶段，队友控场，不应该用大牌压队友
    if is_opening:
        if action_type == "Single" and len(action) >= 2:
            card_value = self._get_card_value(action[1])
            # A=14, 2=15, Joker=16/17
            if card_value >= 14:
                return True  # 应该PASS
    
    # ========== 规则2：配合至上原则 - 让道 ==========
    # 获取队友出的牌
    cur_action = message.get('curAction', [])
    if cur_action and len(cur_action) >= 2:
        teammate_action_type = cur_action[0]
        teammate_card_value = self._get_card_value(cur_action[1]) if len(cur_action) >= 2 else 0
        
        # 队友出小单张（3、4、5等），应该让道
        if teammate_action_type == "Single" and teammate_card_value <= 5:
            # 就算能套也最好不要，留顺子可以送回去
            if action_type != "PASS":
                return True  # 应该PASS让道
        
        # 队友出小对子（3、4、5等），应该让道
        if teammate_action_type == "Pair" and teammate_card_value <= 5:
            if action_type != "PASS":
                return True  # 应该PASS让道
        
        # 队友出小顺子，应该让道
        if teammate_action_type == "Straight":
            # 就算能套也最好不要，留顺子可以送回去
            if action_type != "PASS":
                return True  # 应该PASS让道
    
    return False

def _should_feed_teammate(self, action, message):
    """
    判断是否应该喂牌给队友（配合至上原则）
    
    策略：
    1. 反向喂牌：出与对手牌形相反的牌
    2. 拆牌喂牌：拆牌组成队友需要的牌形
    3. 先大后小巧喂牌：先出大牌消耗下家，再出小牌
    """
    # 判断队友是否需要过牌
    teammate_pos = (message.get('myPos', 0) + 2) % 4
    teammate_cards = self._get_teammate_cards_left(message)
    
    # 队友快走完时，应该喂牌
    if teammate_cards <= 3:
        # 判断对手出的牌型
        opponent_actions = self._get_recent_opponent_actions(message)
        
        # 反向喂牌：对手出顺子，队友不要，出三带二
        if self._opponent_played_straight(opponent_actions):
            if action[0] == "ThreeWithTwo":
                return True  # 应该喂三带二
        
        # 拆牌喂牌：拆牌组成队友需要的牌形
        teammate_needs = self._infer_teammate_needs(message)
        if self._can_feed_teammate(action, teammate_needs):
            return True
    
    return False

## 🎯 总结（基于掼蛋四项基本原则）

队友保护策略的核心原则：

### 1. 谁打谁收原则
- **队友控场时，应该PASS让队友继续控场**
- **绝对不能用炸弹压队友**（除非是更大的炸弹且有必要）
- **开局阶段不应该用大牌压队友**
- **搭档先发的牌，你接牌要慎重，避免影响搭档回收**

### 2. 配合至上原则
- **让道**：搭档出小单张、小对子、小顺子，就算能套也最好不要
- **反向喂牌**：出炸夺权后，出与对手牌形相反的牌，让队友过牌
- **拆牌喂牌**：甚至拆炸组成搭档需要的牌形，保证对家争上游
- **先大后小巧喂牌**：先出大牌消耗下家，再出小牌让队友过牌

### 3. 强牌弱打弱牌强打原则
- **强牌弱打**：吸引并消灭对方主力，给搭档展示牌力和牌型的机会
- **弱牌强打**：作为最后防守方炸弹阻击，然后送出搭档需要的牌型，牺牲自己支持搭档争上游

### 4. 炸弹使用原则
- **炸弹应该保留用于关键时刻**（压制对手、保护队友冲刺、反向喂牌、拆炸喂牌）
- **绝对不能用炸弹压队友**（违反"谁打谁收"和"配合至上"原则）
