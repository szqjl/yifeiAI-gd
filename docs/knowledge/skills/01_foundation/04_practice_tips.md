# 掼蛋练习建议

> **技巧文档，非规则真源。** 牌型与规则见 [04_card_types_guide.md](../../rules/01_basic_rules/04_card_types_guide.md)、[02_quick_start.md](../../rules/01_basic_rules/02_quick_start.md)。

## 练习建议

### 1. 熟悉牌型

**目标**：熟练掌握各类牌型及其组合方式，确保快速反应

**练习方法**：

- 牌型识别 → [04_card_types_guide.md](../../rules/01_basic_rules/04_card_types_guide.md)
- 平台变量：`Single` … `Bomb`（见牌型专文）

### 2. 练习技巧

**目标**：通过与不同水平的玩家对局，积累丰富的实战经验

**练习方法**：
- 与不同水平的玩家对局
- 观察高手的出牌策略
- 总结自己的失误和经验
- 反复练习 [03_basic_strategy.md](03_basic_strategy.md)

**练习重点**：
- 主攻与助攻的角色转换
- 出牌顺序的合理安排
- 与队友的配合默契
- 灵活应对牌局变化

### 3. 观看教学视频

**目标**：学习高手的出牌策略和战术，取长补短

**学习重点**：开局 / 中局 / 残局 / 团队配合（详见各 phase skills 目录）

### 4. 多加练习

**练习原则**：持续练习、每次总结、逐步提难度

**练习建议**：
- 每天至少练习 1–2 副（或按平台 **N 局**批跑；**N 局 ≠ N 副**）
- 定期回顾对局记录（如 `game_records/`）
- 与不同风格的玩家对局
