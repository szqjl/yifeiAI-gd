# 掼蛋基础策略

> **技巧文档，非规则真源。** 升级、过 A、牌型大小以 [guandan-knowledge.mdc](../../../../.cursor/rules/guandan-knowledge.mdc) 为准；规则见 [07_upgrade_rules.md](../../rules/01_basic_rules/07_upgrade_rules.md)。

> **引擎映射（只读规划）**：[`docs/guandan-brain/PRINCIPLES_MAPPING.md`](../../../guandan-brain/PRINCIPLES_MAPPING.md) §七 — **无 M3 P0**；主攻/助攻/三阶段归 **V5+ / M1**；贡还见 P-G03（[`GUA-030`](../../../guandan-brain/ISSUES.md)）。

## 核心策略要点

### 1. 首圈领牌权

**重要性**：首圈领谁先出牌对于整局比赛的节奏有显著影响

**策略要点**：
- 需合理利用贡牌与还牌策略
- 根据手牌情况决定是否争取首圈领牌权
- 主攻方应争取首圈领牌权，助攻方可以配合

### 2. 出牌策略

**核心原则**：合理安排出牌顺序，尽量压制对手，提高自己和队友的胜率

**策略要点**：
- 根据牌力判断主攻或助攻角色
- 主攻方：优先处理弱路，快速出牌
- 助攻方：配合主攻，控制对手，送队友
- 灵活调整出牌顺序，避免被对手控制

### 3. 灵活应对

**核心原则**：根据实际牌局变化调整策略，灵活变通，提升团队合作

**策略要点**：
- 观察对手出牌习惯和牌力
- 根据牌局变化及时调整策略
- 与队友保持默契，相互配合
- 不要死板执行既定策略

### 4. 升级与打级

**核心原则**：争取头游并帮队友争二游（双上）升档最快；A 级须**双上**才赢局（见 [07_upgrade_rules.md](../../rules/01_basic_rules/07_upgrade_rules.md)）。

**策略要点**：
- 级数从 2 至 A；双上 +3 最快
- A 级只有双上赢局，勿与「头游+三游可过 A」等非标准说法混淆

## 应用场景

### 场景1：开局阶段

- **主攻方**：争取首圈领牌权，优先处理弱路
- **助攻方**：配合主攻，观察对手，准备控制

### 场景2：中局阶段

- **主攻方**：继续冲刺，控制出牌节奏
- **助攻方**：送队友，卡对手，配合主攻

### 场景3：残局阶段

- **主攻方**：快速出牌，争取头游
- **助攻方**：全力配合，送队友，阻止对手

## 注意事项

- 不要盲目出牌，要根据牌局情况灵活调整
- 要与队友保持沟通和配合
- 不要死板执行策略，要根据实际情况变化
- 要观察对手的出牌习惯和牌力
