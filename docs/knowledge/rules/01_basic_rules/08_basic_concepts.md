# 掼蛋基本概念

> **真源**：[guandan-knowledge.mdc](../../../../.cursor/rules/guandan-knowledge.mdc) §8  
> 本文仅作**术语词典**；规则正文见本目录 [README.md](README.md) 索引，勿在本页重复展开。

## 对局层级

| 术语 | 标准含义 |
|------|----------|
| **一圈 / 一轮出牌** | 一人首发 → 三家跟压/过 → 连续三人过则结束；接风者下一圈首发 |
| **一副牌** | 108 张、每人 27 张 →（第二副起进贡/还贡或抗贡）→ 多圈出牌 → 四人完牌顺序确定 → 升级；平台 `episodeOver` |
| **一局** | 从 2 打到 **A**，且在 **A 级本副双上**（头游+二游）赢局 |
| **一手牌** | 牌手一次所出的牌（一张或多张） |
| **比赛一轮** | 编排术语：全体选手普遍出场一次；**≠ 一圈 ≠ 一副** |

## 名次

| 术语 | 说明 |
|------|------|
| 头游 / 上游 | 第 1 名完牌 |
| 二游 | 第 2 名 |
| 三游 | 第 3 名 |
| 末游 / 下游 | 第 4 名 |
| **双上** | 本队头游 + 二游 |
| **双下** | 对方占据头游 + 二游（本队双下则下副可能双进贡） |

## 牌手与方位

- 四人两对：队友**对面**坐（平台 v1006：连入序 0+2 一队，1+3 一队）
- **本家**、**队友**、**上家**、**下家**、**我方**、**对方**
- 实体赛固定方位：东、南、西、北（与平台座位号 0–3 独立）

## 进贡体系（术语）

| 术语 | 说明 |
|------|------|
| 进贡 `tribute` | 末游向头游进最大牌（红桃级牌除外）；双下时两人各进贡 |
| 还贡 `back` | 头游还 ≤10 点或最小牌 |
| 抗贡 | 应进贡者持**双大王** → 免进贡 |

细则 → [06_game_flow.md](06_game_flow.md) §进贡

## 等级术语

| 术语 | 平台字段 |
|------|----------|
| 当前等级 / 级牌基准 | `curRank` |
| 我方等级 | `selfRank` |
| 对方等级 | `oppoRank` |
| 级牌 | 与 `curRank` 同点数四花色 |
| 逢人配 | 红桃级牌 `H`+`curRank` |

升级与过 A → [07_upgrade_rules.md](07_upgrade_rules.md)

## 牌型与操作（术语）

| 类别 | 术语 |
|------|------|
| 牌型 | 单张、对子、三张、三连对、三带二、钢板（二连三）、顺子、同花顺、炸弹（四～八星）、王炸/天王炸 |
| 操作 | 接风、首发、过牌（`PASS`）、封牌、空炸、拆炸 |
| 战术 | 保上游、拦下游、送牌、跑牌、控牌（属策略，非规则真源） |

定义与大小 → [04_card_types_guide.md](04_card_types_guide.md)

## 比赛编排（实体赛）

| 术语 | 含义 |
|------|------|
| **一场** | 两对牌手之间的一次比赛（可能若干副或若干局） |
| **一轮** | 所有选手按编排普遍出场一次 |
