## 四步上手

### 1. 搞清三层

- **一圈**：一轮跟牌/过牌  
- **一副**：发牌 →（第二副起进贡）→ 多圈出牌 → 排名 → 升级  
- **一局**：从 2 打到 A，且在 **A 级双上** 才算赢

### 2. 认牌型与大小

牌型列表、王炸/炸弹总序、逢人配 → **[04_card_types_guide.md](04_card_types_guide.md)**（勿在此处重复列表）

### 3. 跟流程

108 张 / 27 张 → 平台 `stage` → 一圈怎么结束 → `episodeOver`  
→ **[05_card_distribution.md](05_card_distribution.md)** + **[06_game_flow.md](06_game_flow.md)**

### 4. 懂升级与过 A

头游+二游 +3、仅头游队友三游 +2…；A 级**只有双上才赢局**  
→ **[07_upgrade_rules.md](07_upgrade_rules.md)**

## 实体赛补充（可选）

- **场**：两对牌手之间的一次比赛  
- **轮**：全体选手普遍出场一次（编排用语，≠ 一圈牌）
