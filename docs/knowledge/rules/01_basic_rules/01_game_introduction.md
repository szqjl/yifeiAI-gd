# 掼蛋游戏介绍

> 规则真源：[guandan-knowledge.mdc](../../../../.cursor/rules/guandan-knowledge.mdc) · 目录索引 [README.md](README.md)

## 概述

掼蛋是流行于江苏等地的四人结对扑克游戏，兼顾运气与配合，常用于竞技比赛。

## 特点

- 四人两两结对，对面为队友
- 从 2 级升级至 A，A 级双上赢局
- 牌型丰富（顺子、同花顺、多级炸弹、逢人配等）
