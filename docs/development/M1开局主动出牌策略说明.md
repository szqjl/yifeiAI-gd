# M1开局主动出牌策略说明

## 概述

开局主动出牌阶段（剩余牌数 > 20）的策略目标是：**建立牌型结构，观察对手，不急于出完**。

## 策略架构

开局主动出牌使用 `OpeningActiveHandler` 处理，采用**双层策略架构**：

1. **优先级系统策略**（优先使用）：使用 `PrioritySystem` 进行动态优先级选择
2. **降级策略**（备用方案）：基于牌力的三种策略分支

---

## 一、优先级系统策略（PrioritySystem）

### 1.1 工作流程

```python
1. 过滤PASS动作，获取候选动作列表
2. 使用HandStructureAnalyzer分析手牌结构
3. 构建上下文信息（game_phase, my_rest, is_active等）
4. 调用PrioritySystem.select()选择最佳动作
5. 返回选中的动作索引
```

### 1.2 优先级规则

**主动出牌优先级（从高到低）**：

| 优先级 | 动作类型 | 分数 | 说明 |
|--------|---------|------|------|
| 最高 | 一手出完 | 1000 | 如果能一手出完，优先选择 |
| 高 | 两手出完 | 900 | 出牌数超过70%手牌 |
| 高 | 小单张 | 800 | 3-7的小单张 |
| 中高 | 三连对/钢板 | 700 | TwoTrips, ThreePair |
| 中 | 顺子 | 600 | Straight, StraightFlush |
| 中 | 三带二 | 500 | ThreeWithTwo |
| 中低 | 三张 | 400 | Trips |
| 低 | 对子 | 300 | Pair |
| 低 | 单张 | 200 | Single |
| **禁止** | **炸弹** | **0** | ⚠️ 开局禁止主动出炸弹 |

### 1.3 炸弹禁止规则

**阶段判断逻辑**：
- **开局阶段**（剩余牌数>20）或**中局前期**（剩余牌数>15）：炸弹优先级=**0**（禁止使用）
- **中局后期**（剩余牌数10-15）：炸弹优先级=**20**（很低）
- **残局阶段**（剩余牌数≤10）：炸弹优先级=**50**（可以使用，但优先级仍然较低）

**原因**：炸弹是关键时刻的武器，开局不应该浪费。

## 二、降级策略（基于牌力）

当优先级系统不可用时，使用以下三种策略分支：

### 2.1 策略1：牌力强，优先出天然单张

**触发条件**：
- 牌力 ≥ 6 **或**
- 有王（R/B）**或**
- 有级牌

**策略逻辑**：
```python
if (power >= 6 or has_king or has_level_card):
    # 调用single_strategy策略函数
    # 如果返回"出单"或"出天然单"
    # 选择最小的单张（Single）
```

**原因**：牌力强时，出小单张可以：
- 观察对手反应
- 保留大牌和组合牌型
- 建立主动权

### 2.2 策略2：牌力中下，对子先行

**触发条件**：
- 牌力 < 6

**策略逻辑**：
```python
if power < 6:
    # 调用pair_strategy策略函数
    # 如果返回"对子先行"或"出对"
    # 选择最小的对子（Pair）
```

**原因**：牌力中下时，对子先行可以：
- 情况不明时，对子相对安全
- 避免暴露单张弱点
- 保留组合牌型

### 2.3 策略3：牌力弱，助攻定位

**触发条件**：
- 牌力 < 5

**策略逻辑**：
```python
if power < 5:
    # 优先出三连对/钢板（对手难管）
    priority_order = [
        'TwoTrips',      # 钢板
        'ThreePair',     # 三连对
        'Straight',      # 顺子
        'ThreeWithTwo',  # 三带二
        'Trips'          # 三张
    ]
    # 如果没有组合牌型，再考虑对子
    # 最后才考虑单张
```

**原因**：牌力弱时，助攻定位：
- 不出单张，避免暴露弱点
- 优先出组合牌型（对手难管）
- 保留牌型组合，等待配合机会

### 2.4 策略4：牌力正常，常规优先级

**触发条件**：
- 牌力 ≥ 5 且 < 6（不满足策略1和策略3）

**策略逻辑**：
```python
# 按常规优先级：小单张 → 三连对/钢板 → 顺子 → 三带二 → 三张 → 对子
priority_order = [
    'Single',           # 小单张（选择最小的）
    'TwoTrips',         # 钢板
    'ThreePair',        # 三连对
    'Straight',         # 顺子
    'ThreeWithTwo',     # 三带二
    'Trips',            # 三张
    'Pair'              # 对子
]
```

## 三、策略优先级总结

### 3.1 完整决策流程

```
开局主动出牌
    │
    ├─→ 优先级系统可用？
    │   │
    │   ├─→ 是 → 使用PrioritySystem.select()
    │   │        │
    │   │        ├─→ 过滤PASS动作
    │   │        ├─→ 分析手牌结构
    │   │        ├─→ 计算优先级分数
    │   │        ├─→ 禁止开局出炸弹
    │   │        └─→ 返回最佳动作
    │   │
    │   └─→ 否 → 使用降级策略
    │            │
    │            ├─→ 牌力强（≥6或有王/级牌）？
    │            │   └─→ 是 → 策略1：优先出天然单张
    │            │
    │            ├─→ 牌力弱（<5）？
    │            │   └─→ 是 → 策略3：助攻定位，优先组合牌型
    │            │
    │            ├─→ 牌力中下（<6）？
    │            │   └─→ 是 → 策略2：对子先行
    │            │
    │            └─→ 其他 → 策略4：常规优先级
```

### 3.2 牌型优先级对比

| 牌力等级 | 优先级顺序 |
|---------|-----------|
| **强**（≥6或有王/级牌） | 单张（小） → 其他 |
| **中下**（<6） | 对子 → 其他 |
| **弱**（<5） | 钢板/三连对 → 顺子 → 三带二 → 三张 → 对子 → 单张 |
| **正常**（5-6） | 单张（小） → 钢板/三连对 → 顺子 → 三带二 → 三张 → 对子 |

---

## 四、关键策略要点

### 4.1 开局禁止出牌

- ❌ **炸弹**：开局禁止主动出炸弹（优先级=0）
- ❌ **大牌组合**：避免开局就出大牌，保留实力

### 4.2 开局推荐出牌

- ✅ **小单张**：牌力强时，出小单张观察对手
- ✅ **对子**：牌力中下时，对子先行相对安全
- ✅ **组合牌型**：牌力弱时，优先出组合牌型（对手难管）

### 4.3 开局策略目标

1. **建立牌型结构**：优先出能建立良好牌型结构的牌
2. **观察对手**：通过小牌观察对手反应和牌型分布
3. **保留实力**：保留大牌和炸弹，等待关键时刻使用
4. **配合队友**：牌力弱时，助攻定位，等待配合机会
