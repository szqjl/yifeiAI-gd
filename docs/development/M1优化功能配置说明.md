# M1 优化功能配置说明

## 📋 概述

M1 智能体已集成第一阶段优化功能（基于 Agentic Design Patterns），包括：
1. ✅ 路由优化 - 智能路由决策和路由缓存机制
2. ✅ 优先级系统增强 - 多因素优先级计算和动态权重调整
3. ✅ 协作策略优化 - 协作协议设计和增强协作策略

## ⚙️ 配置选项

### 默认配置（已启用所有优化）

在 `src/communication/yf1_m1.py` 和 `src/communication/yf2_m1.py` 中，默认配置已启用所有优化：

```python
config = {
    "max_decision_time": 0.8,  # 最大决策时间（秒）
    "enable_logging": True,     # 启用日志
    
    # 第一阶段优化功能开关（基于 Agentic Design Patterns）
    "use_intelligent_router": True,      # 启用智能路由器（路由优化）
    "route_cache_size": 1000,            # 路由缓存大小
    "use_enhanced_priority": True,        # 启用增强优先级系统（优先级系统增强）
    "priority_history_size": 1000,        # 优先级历史记录大小
    "use_enhanced_collaboration": True,   # 启用增强协作策略（协作策略优化）
}
```

### 配置项说明

#### 1. 路由优化配置

- **`use_intelligent_router`** (bool, 默认: `True`)
  - 是否启用智能路由器
  - 启用后使用 `IntelligentStageRouter` 替代基础 `StageRouter`
  - 提供多因素路由决策和路由缓存机制

- **`route_cache_size`** (int, 默认: `1000`)
  - 路由缓存的最大条目数
  - 使用 LRU（最近最少使用）淘汰策略
  - 建议值：500-2000

#### 2. 优先级系统增强配置

- **`use_enhanced_priority`** (bool, 默认: `True`)
  - 是否启用增强优先级系统
  - 启用后使用 `EnhancedPrioritySystem` 替代基础 `PrioritySystem`
  - 提供7个优先级因素计算和动态权重调整

- **`priority_history_size`** (int, 默认: `1000`)
  - 优先级历史记录的最大条目数
  - 用于优先级学习机制
  - 建议值：500-2000

#### 3. 协作策略优化配置

- **`use_enhanced_collaboration`** (bool, 默认: `True`)
  - 是否启用增强协作策略
  - 启用后使用 `EnhancedCollaborationStrategy` 替代基础 `TeammateProtectionStrategy`
  - 提供协作协议、主动配合和信号策略

## 🔧 如何修改配置

### 方法1：直接修改客户端文件

编辑 `src/communication/yf1_m1.py` 或 `src/communication/yf2_m1.py`：

```python
config = {
    "max_decision_time": 0.8,
    "enable_logging": True,
    
    # 禁用所有优化（使用基础版本）
    "use_intelligent_router": False,
    "use_enhanced_priority": False,
    "use_enhanced_collaboration": False,
}
```

### 方法2：选择性启用

只启用部分优化功能：

```python
config = {
    "max_decision_time": 0.8,
    "enable_logging": True,
    
    # 只启用路由优化
    "use_intelligent_router": True,
    "route_cache_size": 1000,
    
    # 禁用其他优化
    "use_enhanced_priority": False,
    "use_enhanced_collaboration": False,
}
```

### 方法3：调整缓存大小

根据系统资源调整缓存大小：

```python
config = {
    # 小内存系统
    "route_cache_size": 500,
    "priority_history_size": 500,
    
    # 大内存系统
    "route_cache_size": 2000,
    "priority_history_size": 2000,
}
```

## 📊 性能影响

### 启用优化后的预期收益

- **路由性能**：决策时间减少 30-50%
- **决策质量**：准确性提升 20-30%
- **协作效果**：协作质量提升 30-40%
- **胜率提升**：整体胜率提升 10-20%

### 资源消耗

- **内存使用**：增加约 5-10MB（取决于缓存大小）
- **CPU使用**：略微增加（多因素计算）
- **决策时间**：总体减少（缓存机制）

## 🔍 验证配置

### 检查日志输出

启动 M1 客户端后，查看日志输出：

```
[INFO] 🎯 Initializing RuleBasedDecisionEngineM1
[INFO]   - Router: Intelligent Router (with cache)  # 如果启用智能路由器
[INFO]   - Router: Base Router                      # 如果禁用智能路由器
```

### 运行时检查

在决策引擎初始化时，会输出当前使用的组件：

- 智能路由器 vs 基础路由器
- 增强优先级系统 vs 基础优先级系统
- 增强协作策略 vs 基础协作策略

## ⚠️ 注意事项

1. **向后兼容**：所有优化都支持向后兼容，如果导入失败会自动降级到基础版本

2. **性能测试**：建议先进行小规模测试，验证优化效果后再全面启用

3. **配置一致性**：确保 `yf1_m1.py` 和 `yf2_m1.py` 使用相同的配置

4. **缓存清理**：如果需要重置缓存，重启客户端即可
