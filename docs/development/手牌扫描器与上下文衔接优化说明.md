# 手牌扫描器与上下文衔接优化说明

## 📋 优化概述

根据用户反馈，优化了手牌扫描器与上下文构建的衔接流程，确保：
1. **先构建上下文信息**（包含手牌信息）
2. **再扫描最优组合**（使用上下文中的手牌信息）
3. **将扫描结果添加到上下文**（供优先级系统使用）

## 🔧 优化内容

### 1. 优化 `_scan_hand_combination()` 方法

**位置**：`src/decision/stage_router.py`

**优化前**：
```python
def _scan_hand_combination(self, message: Dict) -> Dict:
    handcards = message.get("handCards", [])
    rank = message.get("curRank", "2")
    # 直接从message获取手牌信息
```

**优化后**：
```python
def _scan_hand_combination(self, message: Dict, context: Dict = None) -> Dict:
    # ⚠️ 优先使用context中的手牌信息（如果已构建）
    if context and 'handcards' in context:
        handcards = context['handcards']
        rank = context.get('cur_rank', message.get("curRank", "2"))
        logger.debug("使用context中的手牌信息进行扫描")
    else:
        # 降级：从message中获取
        handcards = message.get("handCards", [])
        rank = message.get("curRank", "2")
        logger.debug("从message中获取手牌信息进行扫描")
```

**优势**：
- 优先使用上下文中的手牌信息，确保一致性
- 如果上下文未构建，降级使用message中的信息
- 添加了日志，便于追踪手牌信息来源

### 2. 优化阶段处理器的执行流程

**优化前**：
```python
# 先扫描（从message获取手牌）
scan_result = self._scan_hand_combination(message)
# 后构建上下文
context = self._build_context(message)
```

**优化后**：
```python
# ⚠️ 先构建上下文信息（包含手牌信息）
context = self._build_context(message)

# ⚠️ 出牌前扫描手牌最优组合 - 使用context中的手牌信息
scan_result = self._scan_hand_combination(message, context)

# 将扫描结果添加到context中，供优先级系统使用
context['scan_result'] = scan_result
context['excess_singles'] = excess_singles
context['combination_score'] = combination_score
```

**优势**：
- 确保手牌信息的一致性（都来自上下文）
- 扫描结果可以被优先级系统使用
- 流程更加清晰：先构建上下文，再扫描，最后使用

## 📊 执行流程

### 优化后的完整流程

```
1. 接收消息（message）
   ↓
2. 构建上下文（context）
   - 从message中提取手牌信息
   - 计算剩余牌数、游戏阶段等
   - 将手牌信息添加到context['handcards']
   ↓
3. 扫描手牌最优组合
   - 使用context['handcards']（优先）
   - 或使用message['handCards']（降级）
   - 识别多余单张、评估组合评分
   ↓
4. 将扫描结果添加到context
   - context['scan_result'] = scan_result
   - context['excess_singles'] = excess_singles
   - context['combination_score'] = combination_score
   ↓
5. 使用优先级系统
   - 可以使用context中的扫描结果
   - 优先选择多余单张
   - 评估拆牌影响
   ↓
6. 返回决策结果
```

## 🎯 优化效果

### 1. 手牌信息一致性

- **优化前**：扫描器从message获取手牌，优先级系统从context获取手牌，可能不一致
- **优化后**：扫描器和优先级系统都使用context中的手牌信息，确保一致性

### 2. 扫描结果可复用

- **优化前**：扫描结果只在当前阶段使用，优先级系统无法访问
- **优化后**：扫描结果添加到context，优先级系统可以使用

### 3. 流程更清晰

- **优化前**：先扫描后构建上下文，逻辑不够清晰
- **优化后**：先构建上下文，再扫描，最后使用，流程更清晰

def _calculate_hand_structure_factor(self, candidate: List, hand_structure: Dict, context: Dict) -> float:
