# M1策略系统快捷测试指南

## 📋 概述

本文档说明如何快捷测试M1策略系统的各个组件，**无需启动游戏服务器**。

**适用场景**：
- ✅ 快速验证策略系统功能是否正常
- ✅ 检查代码修改后是否有语法错误
- ✅ 验证策略引擎、手牌分析器等组件初始化
- ✅ 开发调试时快速检查

---

## 🚀 快速开始

### 方式一：使用批处理脚本（推荐，最简单）

```bash
# Windows系统
TEST_M1_STRATEGY.bat
```

### 方式二：直接运行Python脚本

```bash
python test_m1_strategy_quick.py
```

---

## 📊 测试内容

测试脚本会依次测试以下6个组件：

### 1. 策略引擎（Strategy Engine）
- ✅ `TeammateProtectionStrategy` - 队友保护策略
- ✅ `PrioritySystem` - 优先级系统
- ✅ `CardValueSystem` - 牌值系统

### 2. 手牌结构分析器（Hand Structure Analyzer）
- ✅ 手牌分析功能
- ✅ 组合潜力分析
- ✅ 灵活性评分
- ✅ 威胁等级计算

### 3. 阶段处理器（Phase Handlers）
- ✅ `OpeningActiveHandler` - 开局主动出牌
- ✅ `OpeningPassiveHandler` - 开局被动出牌
- ✅ `EndgameLateActiveHandler` - 残局后期主动出牌

### 4. 牌型处理器（Card Type Handlers）
- ✅ `CardTypeHandlerFactory` - 牌型处理器工厂
- ✅ `SingleHandler` - 单张处理器
- ✅ `PairHandler` - 对子处理器

### 5. 残局策略（Endgame Strategies）
- ✅ `RushStrategy` - 冲刺策略
- ✅ `DefendStrategy` - 防守策略
- ✅ `CooperateStrategy` - 配合策略
- ✅ `ControlStrategy` - 控制策略
- ✅ `EndgameStrategySelector` - 残局策略选择器

### 6. M1决策引擎（Decision Engine）
- ✅ `RuleBasedDecisionEngineM1` - M1决策引擎初始化
- ✅ 阶段信息获取功能

## 🔍 测试失败处理

如果测试失败，会显示详细的错误信息：

```
❌ 策略引擎测试失败: [错误信息]
```

**处理步骤**：
1. 查看错误信息，定位问题模块
2. 检查相关代码文件
3. 修复问题后重新运行测试

**常见问题**：
- **导入错误**：检查Python路径和模块导入
- **初始化错误**：检查配置参数是否正确
- **语法错误**：检查代码缩进和语法

## 🎯 测试建议

### 开发时使用
- 每次修改策略相关代码后，运行此测试快速验证
- 确保没有引入语法错误或导入问题

### 提交前检查
- 提交代码前运行此测试，确保基本功能正常
- 所有测试通过后再进行完整对局测试

### 持续集成
- 可以将此测试集成到CI/CD流程中
- 自动检测代码修改是否破坏基本功能
