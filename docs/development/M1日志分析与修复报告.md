## 🔧 修复内容

### 1. 修复游戏记录保存问题

**问题原因**:
- M1客户端使用 `notifyType` 字段判断通知类型
- 服务器实际发送的是 `stage` 字段（如 `stage == "beginning"`, `stage == "gameResult"`）
- 导致 `gameStart` 和 `gameOver` 通知未被正确处理

**修复方案**:
- ✅ 修改 `handle_notification` 方法，兼容两种格式：
  - `notifyType` 字段（旧格式）
  - `stage` 字段（服务器实际格式）
- ✅ 支持多种游戏开始通知格式：
  - `notifyType == "gameStart"` 或 `stage == "beginning"`
- ✅ 支持多种游戏结束通知格式：
  - `notifyType == "gameOver"` 或 `stage == "gameResult"`
- ✅ 改进 `_handle_game_start` 方法，兼容多种字段格式
- ✅ 改进 `_handle_game_over` 方法，正确提取游戏结果

**修改文件**:
- `src/communication/yf1_m1.py`
- `src/communication/yf2_m1.py`

### 2. 改进日志记录
