回应疑问

是不是真 AI 在打？

不是录屏冒充。四个程序同时连上掼蛋服务器，收到「该你出牌」的消息，自己算出一个序号，再发回平台。

是真 AI（程序自动）

  • WebSocket 长连接
  • JSON 消息收发
  • 返回 {"actIndex": N}
  • 无人替它点鼠标

还不是会掼蛋

  • 决策 = 合法动作里随机选
  • 不懂压牌、配合、保炸
  • 战术意识自评 0 / 10
  • 像新手，不像高手
缘起

从「双上计分王」说起

去年 11 月，和掼蛋高手朋友一起做了掼蛋计分微信小程序。工具做顺了，心里冒出一个念头：能不能让 AI 自己学会掼蛋？

计分小程序

需求明确 → 告诉 IDE 一步步写 → 能用的实用工具。复杂，但目标清楚。

掼蛋 AI

要连比赛平台、要懂规则、要会出牌、还要赢。不是「写个页面」，是造一个牌手。

实拍建议：小程序界面录屏 5–10 秒

最初设想

我以为：把掼蛋知识喂给 AI

灵光一闪——AI 不就是喂知识吗？网上拉规则，自己整理牌力、牌型、开局中局残局怎么打。搞了三天，知识库搭好了。

能力自评 · 首秀报告

会打牌，不会「打掼蛋」

维度得分说明

决策逻辑 · basic_client.py

整个「大脑」，就这几行

def make_decision(self, data):
    # Placeholder: Random decision from actionList
    action_list = data.get("actionList", [])
    if not action_list:
        return 0
    return random.randint(0, len(action_list) - 1)

不是人替它点 —— 是程序每次随机掷骰子选一招。
