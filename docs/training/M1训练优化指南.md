## 快速开始

### 1. 启动训练（使用MLflow监控）

```bash

    --monitor_backend mlflow \
    --epochs 100 \
    --batch_size 32 \
    --learning_rate 0.00005 \
    --monitor_project "m1-vs-client"
```

## 训练参数说明

### 当前推荐配置

| 参数 | 值 | 说明 |
|------|-----|------|
| epochs | 100 | 训练轮数 |
| batch_size | 32 | 批次大小 |
| learning_rate | 0.00005 | 学习率（较低，更稳定） |
| loss_alpha | 0.05 | Focal Loss正样本权重（降低预测过度） |
| loss_gamma | 4.0 | Focal Loss难样本关注度 |
| over_prediction_penalty | 5.0 | 过度预测惩罚权重 |
| sparsity_reward | 2.0 | 稀疏性奖励权重 |
| weight_decay | 0.02 | 权重衰减（正则化） |

### 参数调整建议

根据训练结果自动调整：

1. **预测过度**（预测卡牌数 > 真实卡牌数 * 2）:
   - 增加 `over_prediction_penalty`（当前 * 1.5）
   - 降低 `loss_alpha`（当前 * 0.8）
   - 增加稀疏性正则化

2. **预测不足**（预测卡牌数 < 真实卡牌数 * 0.5）:
   - 降低 `over_prediction_penalty`（当前 * 0.7）
   - 提高 `loss_alpha`（当前 * 1.2）
   - 降低预测阈值

3. **损失不收敛**:
   - 降低学习率（当前 * 0.5）
   - 减小批次大小（当前 * 0.8）

4. **过拟合**:
   - 增加dropout率
   - 增加权重衰减
   - 增加训练数据

## 训练监控指标

### 关键指标

1. **Loss指标**:
   - `loss/total` - 总损失
   - `loss/action` - 动作损失
   - `loss/strategy` - 策略损失
   - `loss/threshold` - 阈值损失

2. **预测指标**:
   - `metrics/predicted_cards` - 预测卡牌数
   - `metrics/true_cards` - 真实卡牌数
   - `metrics/prediction_ratio` - 预测比例

3. **质量指标**:
   - `quality/prediction_quality_score` - 预测质量分数
   - `best/combined_score` - 综合分数

### 目标值

- **预测比例**: 0.8 - 1.2（理想范围）
- **预测质量分数**: > 0.5
- **综合分数**: 持续上升

## 常见问题

### Q1: 训练损失不下降
**解决方案**:
- 检查学习率是否过高
- 增加训练数据
- 调整损失函数权重

### Q2: 预测过度严重
**解决方案**:
- 增加 `over_prediction_penalty`
- 降低 `loss_alpha`
- 增加稀疏性正则化

### Q3: 胜率不达标
**解决方案**:
- 增加训练数据（特别是获胜对局）
- 调整模型架构
- 优化决策策略
