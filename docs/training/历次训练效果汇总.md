#### 关键参数变化说明

**Epochs（训练轮数）**:
- 初始: 5轮 → 过拟合严重
- 中期: 20轮 → 训练不足
- 优化1: 30轮 → 避免过拟合
- 优化2: 50轮 → 效果最佳

**Learning Rate（学习率）**:
- 初始: 0.001 → 过大，训练不稳定
- 中期: 0.0005 → 平衡学习速度
- 优化2: 0.0003 → 更稳定
- **推荐**: 0.0003（稳定学习率）

**Batch Size（批次大小）**:
- 初始: 32 → 训练效率低
- 优化: 64 → 提高效率，训练更稳定
- **推荐**: 64（最优批次大小）

**Dropout（正则化）**:
- 初始: 无 → 过拟合
- 中期: 0.1 → 减少过拟合
- **推荐**: 0.1（平衡过拟合和输出概率）

**学习率衰减**:
- 初始: 无 → 训练不稳定
- 优化: 每10轮衰减50% → 稳定收敛
- **推荐**: StepLR(step_size=10, gamma=0.5)

**损失函数**:
- 初始: BCE → 对预测过少惩罚不足
- 优化: 加权BCE(pos_weight=2.0) → 惩罚预测过少
- **推荐**: 加权BCE(pos_weight=2.0)

    """
    Select action given state.

        state: 状态向量
        deterministic: 是否使用确定性策略
        threshold: 预测阈值（默认0.1，已优化）

    with torch.no_grad():

        probs = torch.sigmoid(logits)

        return action.cpu().numpy()

## 7. 关键经验总结

### 7.1 预训练关键经验

1. **数据量是关键**
   - 小数据量(10样本)容易过拟合，准确率高但泛化差
   - 大数据量(13,409样本)需要更多训练轮数
   - 数据量增加后准确率下降是正常现象

2. **训练轮数要充足**
   - 30轮对于大数据量可能不够
   - 50轮效果明显更好（准确率从1.53%提升到59.67%）
   - 但也要避免过拟合

3. **学习率要稳定**
   - 0.0003比0.0005更稳定
   - 配合学习率衰减效果更好
   - 不要频繁调整学习率

4. **概率缩放很重要**
   - 缩放因子10.0是最优选择
   - 不是越大越好（50.0反而效果差）
   - 需要基于数据分析找到最优值

5. **预测阈值要配合缩放**
   - 阈值0.1配合缩放10.0效果最佳
   - 单独降低阈值效果有限
   - 需要两者配合使用

### 7.2 强化学习关键经验

1. **随机种子必须固定**
   - 确保训练结果可复现
   - 便于对比不同训练的效果
   - 便于调试和问题定位

2. **学习率要足够低**
   - 0.0001比0.0003更稳定
   - 配合学习率衰减效果更好
   - 避免训练后期不稳定

3. **早停机制很重要**
   - 防止训练退化
   - 自动保存最佳模型
   - 节省训练时间

4. **训练轮数要充足**
   - 50轮可能不够
   - 推荐500-1000轮
   - 确保充分训练

5. **监控训练过程**
   - 实时查看奖励曲线
   - 及时发现训练问题
   - 保存最佳模型

### 7.3 避免重复错误

**常见错误**:
1. ❌ 频繁修改参数，没有给模型足够时间
2. ❌ 同时修改多个参数，无法定位问题
3. ❌ 不记录调整历史，重复试错
4. ❌ 忽略历史经验，重复已知错误
5. ❌ 过早放弃，训练几轮就放弃

**正确做法**:
1. ✅ 一次只改一个参数
2. ✅ 至少训练50轮再评估
3. ✅ 记录所有调整和效果
4. ✅ 参考本汇总文档
