## 概述

本项目集成了三个强大的智能训练工具：

1. **Weights & Biases (wandb)**: 训练监控与可视化
2. **Optuna**: 自动超参数优化
3. **PyTorch Lightning**: 训练框架简化

### 安装依赖

```bash
pip install -r requirements.txt
```

或单独安装：

```bash
pip install wandb optuna pytorch-lightning
```

## Weights & Biases (wandb) 使用指南

> ⚠️ **注意**: 如果 wandb 无法登录，请使用 TensorBoard 或 MLflow（见上方推荐）

### 1. 初始化 wandb

首次使用需要登录：

```bash
wandb login
```

会提示输入 API key，可在 https://wandb.ai/settings 获取。

### 2. 在训练脚本中使用 wandb

#### 方法1: 使用已集成的训练脚本（推荐）

`stage7_optimized_training.py` 支持多种监控后端：

```python
from src.train.stage7_optimized_training import train_stage7_optimized_model

# 使用 TensorBoard（推荐，无需登录）
model, history = train_stage7_optimized_model(
    epochs=100,
    batch_size=32,
    learning_rate=0.00005,
    monitor_backend="tensorboard",  # 使用 TensorBoard
    monitor_project="yifei-ai-gd",
    monitor_name="stage7_experiment_1"
)

# 使用 MLflow（功能强大）
model, history = train_stage7_optimized_model(
    epochs=100,
    batch_size=32,
    learning_rate=0.00005,
    monitor_backend="mlflow",  # 使用 MLflow
    monitor_project="yifei-ai-gd",
    monitor_name="stage7_experiment_1"
)

# 使用 wandb（如果可用）
model, history = train_stage7_optimized_model(
    epochs=100,
    batch_size=32,
    learning_rate=0.00005,
    monitor_backend="wandb",  # 使用 wandb
    monitor_project="yifei-ai-gd",
    monitor_name="stage7_experiment_1"
)
```

#### 方法2: 手动集成 wandb

```python
import wandb

# 初始化
wandb.init(
    project="yifei-ai-gd",
    name="my_experiment",
    config={
        "learning_rate": 0.00005,
        "batch_size": 32,
        "epochs": 100,
    }
)

# 训练循环中记录
for epoch in range(epochs):
    loss = train_one_epoch()
    accuracy = evaluate()
    
    wandb.log({
        "epoch": epoch,
        "loss": loss,
        "accuracy": accuracy,
    })

# 保存模型
wandb.save("model.pth")

# 结束运行
wandb.finish()
```

### 4. wandb 记录的内容

- **超参数**: 学习率、批次大小、训练轮数等
- **损失函数**: 总损失、动作损失、策略损失等
- **训练指标**: 预测卡牌数、真实卡牌数、预测比例等
- **模型文件**: 自动保存最佳模型
- **系统信息**: GPU/CPU 使用率、内存使用等

## Optuna 超参数优化指南

### 1. 基本使用

```bash
# 运行超参数优化（50次试验）
python src/train/optuna_hyperparameter_optimization.py --n_trials 50
```

### 2. 高级选项

```bash
# 指定研究名称（用于恢复优化）
python src/train/optuna_hyperparameter_optimization.py \
    --n_trials 100 \
    --study_name "stage7_optimization_v2"

# 指定存储路径
python src/train/optuna_hyperparameter_optimization.py \
    --n_trials 50 \
    --storage "sqlite:///optuna_studies/my_study.db"
```

### 3. 优化参数范围

当前优化的超参数包括：

- **学习率**: 1e-5 到 1e-3（对数尺度）
- **批次大小**: 16, 32, 64, 128
- **训练轮数**: 30 到 100（步长10）
- **损失函数参数**:
  - `loss_alpha`: 0.01 到 0.2
  - `loss_gamma`: 2.0 到 6.0
  - `over_prediction_penalty`: 1.0 到 10.0
  - `sparsity_reward`: 0.5 到 5.0
- **模型参数**:
  - `dropout_rate`: 0.1 到 0.6
- **优化器参数**:
  - `weight_decay`: 0.001 到 0.1（对数尺度）

### 4. 查看优化结果

优化完成后，结果保存在：

- **最佳参数**: `optuna_results/{study_name}_best_params.json`
- **优化历史图表**: `optuna_results/{study_name}_optimization_history.html`（需要安装 plotly）

### 5. 使用优化后的参数

```python
import json

# 加载最佳参数
with open("optuna_results/stage7_optimization_best_params.json", 'r') as f:
    best_params = json.load(f)["best_params"]

# 使用最佳参数训练
from src.train.stage7_optimized_training import train_stage7_optimized_model

model, history = train_stage7_optimized_model(
    learning_rate=best_params["learning_rate"],
    batch_size=best_params["batch_size"],
    epochs=best_params["epochs"],
    # ... 其他参数
)
```

## PyTorch Lightning 使用指南

### 1. 基本使用

```bash
# 使用默认参数训练
python src/train/stage7_lightning_training.py

# 指定参数
python src/train/stage7_lightning_training.py \
    --max_epochs 100 \
    --batch_size 64 \
    --learning_rate 0.00005 \
    --use_wandb \
    --wandb_project "yifei-ai-gd"
```

### 2. 在代码中使用

```python
from src.train.stage7_lightning_training import train_with_lightning

model, trainer = train_with_lightning(
    data_dir="game_records",
    model_save_dir="models/lightning_checkpoints",
    max_epochs=100,
    batch_size=32,
    learning_rate=0.00005,
    use_wandb=True,
    wandb_project="yifei-ai-gd",
    accelerator="cpu",  # 或 "gpu", "cuda"
    devices=1,
    precision="32",  # 或 "16" 用于混合精度训练
)
```

### 3. PyTorch Lightning 的优势

#### 自动功能

- ✅ **自动混合精度训练**: 设置 `precision="16"` 即可
- ✅ **分布式训练**: 设置 `devices=4` 自动支持多GPU
- ✅ **模型检查点**: 自动保存最佳模型
- ✅ **早停机制**: 自动停止训练
- ✅ **学习率调度**: 自动应用学习率调度器
- ✅ **梯度裁剪**: 自动防止梯度爆炸

#### 与 wandb 集成

PyTorch Lightning 自动与 wandb 集成，无需额外代码：

```python
from pytorch_lightning.loggers import WandbLogger

wandb_logger = WandbLogger(project="yifei-ai-gd", name="experiment_1")

trainer = pl.Trainer(
    logger=wandb_logger,
    # ... 其他参数
)
```

### 4. 加载训练好的模型

```python
import torch
from src.train.stage7_lightning_training import GuandanLightningModule

# 加载检查点
checkpoint_path = "models/lightning_checkpoints/best-epoch=50-val_prediction_quality=0.8234.ckpt"

# 方法1: 直接加载（推荐）
model = GuandanLightningModule.load_from_checkpoint(checkpoint_path)

# 方法2: 使用 Trainer 加载
from pytorch_lightning import Trainer
trainer = Trainer()
model = trainer.model.load_from_checkpoint(checkpoint_path)

# 使用模型
model.eval()
with torch.no_grad():
    predictions = model(state_vec)
```

## 常见问题

### Q1: wandb 登录失败

**A**: 检查网络连接，或使用离线模式：

```python
import os
os.environ["WANDB_MODE"] = "offline"
```

### Q2: Optuna 优化时间太长

**A**: 减少试验次数或使用更少的训练样本：

```python
# 在 optuna_hyperparameter_optimization.py 中修改
train_epochs = min(epochs, 10)  # 减少到10轮
max_samples=1000  # 减少样本数
```

### Q3: PyTorch Lightning 训练时内存不足

**A**: 减少批次大小或使用梯度累积：

```python
trainer = pl.Trainer(
    accumulate_grad_batches=4,  # 梯度累积
    # ... 其他参数
)
```

### Q4: 如何恢复中断的训练？

**A**: PyTorch Lightning 支持自动恢复：

```python
trainer = pl.Trainer(
    resume_from_checkpoint="models/lightning_checkpoints/last.ckpt",
    # ... 其他参数
)
```

### Q5: 如何对比不同实验？

**A**: 使用 wandb 的对比功能：

1. 在 wandb 网页界面选择多个运行
2. 点击 "Compare" 按钮
3. 查看对比图表和表格

## 最佳实践

### 1. 实验命名规范

```python
# 好的命名
wandb_name = f"stage7_lr{lr}_bs{batch_size}_{datetime.now().strftime('%Y%m%d')}"

# 不好的命名
wandb_name = "test"  # 太模糊
```

### 2. 超参数记录

始终记录所有重要超参数：

```python
wandb.config.update({
    "learning_rate": 0.00005,
    "batch_size": 32,
    "loss_alpha": 0.05,
    "loss_gamma": 4.0,
    # ... 所有相关参数
})
```

### 3. 定期保存检查点

```python
# PyTorch Lightning 自动处理
# 手动训练时：
if epoch % 10 == 0:
    torch.save(model.state_dict(), f"checkpoint_epoch_{epoch}.pth")
    wandb.save(f"checkpoint_epoch_{epoch}.pth")
```

### 4. 使用 Optuna 前先手动调参

建议先用少量试验（如10次）快速验证优化方向，再进行大规模优化。
