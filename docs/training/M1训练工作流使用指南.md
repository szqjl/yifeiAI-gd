# M1训练工作流使用指南

## 概述

M1训练工作流是一个自动化训练系统，能够：
1. 自动训练模型
2. 分析训练结果
3. 评估M1 vs Client胜率
4. 根据结果优化参数
5. 迭代训练直到达到目标胜率（>50%）

## 快速开始

### 方式1: 使用批处理脚本（Windows推荐）

```bash
START_M1_WORKFLOW_FULL.bat
```

### 方式2: 使用Python脚本

```bash
python src/train/m1_training_workflow.py \
    --max_iterations 10 \
    --target_win_rate 0.50 \
    --min_games 50
```

## 工作流参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--max_iterations` | 10 | 最大迭代次数 |
| `--target_win_rate` | 0.50 | 目标胜率（50%） |
| `--min_games` | 50 | 评估所需最少对局数 |

## 工作流程

### 迭代循环

每次迭代包含以下步骤：

1. **训练模型**
   - 使用Stage7优化训练框架
   - MLflow监控训练过程
   - 自动保存最佳模型

2. **分析训练结果**
   - 分析损失趋势
   - 识别预测过度/不足问题
   - 生成优化建议

3. **评估胜率**
   - 评估M1 vs Client的胜率
   - 分析决策质量
   - 对比基线性能

4. **检查目标**
   - 如果胜率 ≥ 50%：停止迭代，工作流成功
   - 如果胜率 < 50%：继续下一步

5. **优化参数**
   - 根据训练分析和胜率结果
   - 自动调整训练参数
   - 准备下一轮训练

### 终止条件

工作流在以下情况停止：

1. **成功**: 胜率 ≥ 目标胜率（默认50%）
2. **达到最大迭代次数**: 完成所有迭代但未达标
3. **训练失败**: 某次迭代训练失败

## 优化策略

### 自动优化

工作流会根据以下情况自动优化：

1. **预测过度**（预测比例 > 2.0）:
   - 增加过度预测惩罚
   - 降低正样本权重

2. **预测不足**（预测比例 < 0.5）:
   - 降低过度预测惩罚
   - 提高正样本权重

3. **胜率过低**（< 30%）:
   - 建议增加训练数据
   - 建议调整模型架构

4. **损失过高**（> 1,000,000）:
   - 建议降低学习率
   - 建议增加正则化

### 手动优化

如果自动优化效果不佳，可以：

1. **查看工作流历史**:
   ```bash
   cat models/m1_training_workflow_history.json
   ```

2. **分析训练结果**:
   ```bash
   python src/train/training_optimizer.py --history models/bc_model_stage7_optimized_training_history.json
   ```

3. **手动调整参数**:
   - 编辑 `src/train/stage7_optimized_training.py`
   - 调整损失函数参数
   - 重新运行工作流

## 注意事项

### 1. 需要游戏记录

评估胜率需要M1与client的对战记录。如果工作流提示"需要先进行对战测试"：

1. 运行M1客户端与client进行对战
2. 生成足够的游戏记录（至少50局）
3. 重新运行工作流

### 2. 训练时间

每次迭代训练时间：
- 约100个epoch
- 根据数据量和硬件，可能需要10-30分钟

### 3. 资源消耗

- CPU/GPU资源：训练期间会占用
- 磁盘空间：模型文件和历史记录
- 内存：根据批次大小调整

## 故障排除

### 问题1: 训练失败

**症状**: 工作流在训练步骤失败

**解决方案**:
- 检查数据文件是否存在
- 检查依赖是否安装完整
- 查看错误日志

### 问题2: 无法评估胜率

**症状**: 提示"需要先进行对战测试"

**解决方案**:
- 运行M1客户端与client对战
- 确保生成足够的游戏记录
- 检查游戏记录文件格式

### 问题3: 胜率不提升

**症状**: 多次迭代后胜率仍不达标

**解决方案**:
- 查看工作流历史分析趋势
- 手动调整训练参数
- 考虑增加训练数据
- 检查模型架构是否合适
