## ✅ 新增文件

### 1. `src/train/enhanced_self_play.py`

**功能**: 增强版自我对弈训练脚本

**新增功能**:
- ✅ **模型评估和选择**: 训练过程中定期评估，自动保存最佳模型
- ✅ **检查点保存**: 定期保存训练检查点，支持恢复训练
- ✅ **经验回放**: 实现经验回放缓冲区，充分利用历史经验
- ✅ **训练监控**: 详细的训练统计和日志记录

**关键类**:
- `ExperienceReplayBuffer`: 经验回放缓冲区
- `evaluate_agent()`: 模型评估函数
- `train_enhanced_self_play()`: 增强版训练主函数

**使用示例**:
```python
from src.train.enhanced_self_play import train_enhanced_self_play

train_enhanced_self_play(
    max_episodes=1000,
    eval_interval=100,         # 每100回合评估一次
    checkpoint_interval=200,   # 每200回合保存检查点
    replay_buffer_size=10000   # 经验回放缓冲区大小
)
```

### 2. `src/train/continuous_learning.py`

**功能**: 持续学习模块

**新增功能**:
- ✅ **在线学习**: 支持运行时持续学习
- ✅ **增量更新**: 从新数据中增量更新模型
- ✅ **版本管理**: 模型版本控制和回滚

**关键类**:
- `ModelVersionManager`: 模型版本管理器
- `ContinuousLearner`: 持续学习器

**使用示例**:
```python
from src.train.continuous_learning import ContinuousLearner, ModelVersionManager
from src.rl_agent.agent import PPOAgent

agent = PPOAgent(input_dim=512, action_dim=512)
learner = ContinuousLearner(agent, replay_buffer_size=5000)
version_manager = ModelVersionManager()

# 添加经验
learner.add_experience(state, action, log_prob, reward, next_state, done, info)

# 保存版本
version_manager.save_version(agent, "v1.0", metadata={"win_rate": 0.65})
```

## 🎯 使用建议

### 1. 训练流程

**推荐流程**:
1. **预训练**（Behavior Cloning）
   - 使用专家数据预训练
   - 快速获得基础策略

2. **增强版训练**（Enhanced Self-Play）
   - 使用 `enhanced_self_play.py`
   - 自动评估和保存最佳模型
   - 定期保存检查点

3. **持续学习**（Continuous Learning）
   - 从新对局中学习
   - 增量更新模型

### 2. 参数配置

**推荐配置**:
```python
train_enhanced_self_play(
    max_episodes=1000,        # 最大训练回合数
    eval_interval=100,         # 每100回合评估一次
    checkpoint_interval=200,   # 每200回合保存检查点
    replay_buffer_size=10000  # 经验回放缓冲区大小
)
```

### 3. 模型选择

- **最佳模型**: `models/best_ppo_model.pth`（胜率最高，用于生产环境）
- **最终模型**: `models/ppo_model_final.pth`（最新状态，用于继续训练）
- **检查点**: `models/checkpoint_ep{episode}.pth`（特定回合，用于恢复训练）
