## 1. 策略标注概述

### 1.1 什么是策略标注？

策略标注是从游戏记录中提取每个动作的策略信息：
- **策略类型**：组牌、顺牌、跟牌、控牌、过牌
- **策略子类型**：具体策略（如"出第二小的单"、"配炸弹"等）
- **策略原因**：为什么这样选择
- **策略效果**：这样选择的效果评估

### 1.2 为什么需要策略标注？

- ✅ 让模型学习"为什么这样选择"（策略逻辑）
- ✅ 让模型学习"这样选择的效果如何"（策略评估）
- ✅ 为方案B（模型学习策略）做准备

## 2. 数据格式设计

### 2.1 策略标签格式

```json
{
  "strategy_type": "grouping" | "following" | "controlling" | "passing",
  "strategy_subtype": "具体子类型",
  "strategy_reason": "策略原因",
  "strategy_effect": {
    "rounds_reduced": 0,
    "singles_reduced": 0,
    "score": 0.0
  }
}
```

### 2.2 完整标注数据格式

```json
{
  "game_id": "20251214201258210817",
  "player_id": 2,
  "labeled_actions": [
    {
      "action_index": 6,
      "timestamp": "2025-12-14T20:12:59.001394",
      "state": {
        "hand_cards": [...],
        "game_phase": "opening",
        "power": 7.5,
        "opponent_rest_cards": 27,
        ...
      },
      "action": ["Single", "5", ["C5"]],
      "strategy_label": {
        "strategy_type": "grouping",
        "strategy_subtype": "起始出天然单",
        "strategy_reason": "开局阶段，有王/级牌保护，优先出天然单张",
        "strategy_effect": {
          "rounds_reduced": 0,
          "singles_reduced": 0,
          "score": 50.0
        }
      }
    }
  ]
}
```

## 3. 自动标注流程

### 3.1 使用策略函数自动标注

利用现有的策略函数（`single_card_strategy`、`pair_strategy`等）自动分析每个动作的策略。

**步骤**：
1. 加载游戏记录
2. 对每个动作，提取游戏状态
3. 调用对应的策略函数分析
4. 提取策略标签
5. 保存标注数据

## 6. 使用示例

### 6.1 单个文件标注

```python
from src.knowledge_processor.strategy_labeler import StrategyLabeler
from pathlib import Path

labeler = StrategyLabeler()
record_path = Path("game_records/20251214201258210817.json")
labels = labeler.label_game_record(record_path)
```

### 6.2 批量标注

```python
labeler = StrategyLabeler()
records_dir = Path("game_records")
output_path = Path("labeled_data/strategy_labels.json")
labeler.batch_label(records_dir, output_path)
```

## 7. 常见问题

### Q1: 策略函数返回"未知"怎么办？
A: 需要手动标注或改进策略函数。

### Q2: 标注数据量需要多少？
A: 建议至少10,000个标注样本，越多越好。

### Q3: 如何评估标注质量？
A: 使用验证工具检查完整性、准确性和分布性。
