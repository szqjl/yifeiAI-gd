# 使用平台.rep文件进行预训练

## 概述

平台提供的`.rep`文件（XML格式）包含真实的人类对战数据，可以用于预训练模型。

## 数据格式

平台`.rep`文件格式：
- XML格式
- 包含玩家信息、初始手牌、所有动作
- 卡牌格式：`RR`（大王）、`rr`（小王）、`S3`（黑桃3）等

## 转换步骤

### 步骤1：转换.rep文件为训练格式

使用转换脚本将`.rep`文件转换为训练数据：

```python
from src.knowledge_processor.platform_replay_converter import convert_rep_directory

# 转换整个目录
convert_rep_directory(
    rep_dir=r"C:\Program Files (x86)\gdgame\MobileGD\replay",
    output_dir="game_records",
    target_player_id=None  # None表示提取所有玩家的数据
)
```

或者转换单个文件：

```python
from src.knowledge_processor.platform_replay_converter import convert_rep_to_training_format

result = convert_rep_to_training_format(
    rep_path=r"C:\Program Files (x86)\gdgame\MobileGD\replay\szqjl_2024-02-04_12_20_23_\_2024-02-04_12_15_56.rep",
    target_player_id=2  # seat=2是szqjl
)
```

### 步骤2：转换为ReplayParser期望的格式

转换后的JSON格式需要进一步转换为`ReplayParser`期望的格式：

```python
import json
from src.knowledge_processor.replay_parser import ReplayParser

# 读取转换后的JSON文件
with open("game_records/_2024-02-04_12_15_56.json", 'r', encoding='utf-8') as f:
    training_data = json.load(f)

# 转换为ReplayParser格式
replay_format = {
    "player_id": training_data["training_samples"][0]["player_seat"],
    "initial_hand": training_data["training_samples"][0]["state"]["hand"],
    "actions": []
}

# 添加动作
for sample in training_data["training_samples"]:
    action_type = "PASS" if len(sample["action"]) == 0 else "Discard"
    action_str = f"['{action_type}', '{action_type}', {sample['action']}]"
    replay_format["actions"].append({
        "cur_pos": sample["player_seat"],
        "cur_action": action_str
    })

# 保存为ReplayParser格式
with open("game_records/formatted_replay.json", 'w', encoding='utf-8') as f:
    json.dump(replay_format, f, ensure_ascii=False, indent=2)
```

### 步骤3：运行预训练

```bash
python src/train/pretrain.py
```

## 数据质量评估

从测试结果看，单个`.rep`文件可以提取：
- **5个训练样本**（seat=2的玩家）
- 包含完整的手牌状态和动作历史
- 卡牌格式已正确转换（RR→R, rr→B）

## 注意事项

### 1. 卡牌格式转换

平台格式：
- `RR` → 标准格式：`R`（大王）
- `rr` → 标准格式：`B`（小王）
- `S3` → 标准格式：`S3`（黑桃3）

### 2. 数据量

- 单个对局通常包含**5-20个训练样本**（取决于玩家出牌次数）
- 建议收集**至少100个对局**（约500-2000个训练样本）

### 3. 数据质量

- ✅ 包含真实人类决策
- ✅ 包含完整游戏状态
- ✅ 包含动作历史
- ⚠️ 需要验证手牌更新是否正确

### 4. 数据验证

转换后建议验证：
- [ ] 手牌数量是否正确（27张）
- [ ] 卡牌格式是否正确
- [ ] 动作序列是否完整
- [ ] 手牌更新是否正确

## 数据统计

转换完成后，检查数据：

```python
import os
import json

game_records_dir = "game_records"
total_samples = 0
total_files = 0

for file in os.listdir(game_records_dir):
    if file.endswith(".json"):
        with open(os.path.join(game_records_dir, file), 'r', encoding='utf-8') as f:
            data = json.load(f)
            if "training_samples" in data:
                total_samples += len(data["training_samples"])
                total_files += 1

print(f"总文件数: {total_files}")
print(f"总训练样本数: {total_samples}")
print(f"平均每局样本数: {total_samples / total_files if total_files > 0 else 0}")
```
