# 掼蛋AI模型训练指南

## 概述

本指南说明如何正确训练掼蛋AI的强化学习模型。训练分为两个阶段：
1. **预训练（Behavior Cloning）**：从人类对局数据中学习
2. **强化学习训练（Self-Play）**：通过自我对弈提升

## 统一的编码方式

所有地方现在都使用相同的编码方式：`suit * 15 + rank` 编码（0-59范围）：

```python
def card_to_index(card_code):
    suit_map = {'S': 0, 'H': 1, 'C': 2, 'D': 3}
    rank_map = {
        '2': 0, '3': 1, '4': 2, '5': 3, '6': 4, '7': 5, '8': 6, '9': 7,
        'T': 8, 'J': 9, 'Q': 10, 'K': 11, 'A': 12,
        'B': 13,  # 小王
        'R': 14   # 大王
    }
    if len(card_code) >= 2:
        suit = card_code[0]
        rank = card_code[1]
        suit_val = suit_map.get(suit, 0)
        rank_val = rank_map.get(rank, 0)
        idx = suit_val * 15 + rank_val
        return min(idx, 59)  # 确保在0-59范围内
    return 0
```

## 训练步骤

### 步骤1：准备训练数据

1. **收集对局数据**：
   - 将游戏对局记录保存到 `game_records/` 目录
   - 格式：JSON文件，包含每局的手牌、动作、结果等信息

2. **数据格式要求**：
   ```json
   {
     "hand": ["H2", "C2", "S3", ...],
     "action": ["H2", "C2"],
     "result": "win"
   }
   ```

### 步骤2：预训练（Behavior Cloning）

```bash
cd D:/YiFeiAI-GD
python src/train/pretrain.py
```

**预期输出**：
- 加载对局数据
- 训练模型（5个epoch）
- 保存模型到 `models/bc_model_v1.pth`

**注意事项**：
- 确保有足够的训练数据（建议至少1000局）
- 检查损失是否下降
- 如果损失不下降，可能是数据质量或编码问题

### 步骤3：强化学习训练（Self-Play）

```bash
python src/train/self_play.py
```

**预期输出**：
- 加载预训练模型（如果存在）
- 进行自我对弈训练
- 每10局输出一次奖励
- 保存模型到 `models/ppo_model_v1.pth`

**注意事项**：
- 训练时间较长（可能需要数小时到数天）
- 监控奖励是否提升
- 定期保存检查点

### 步骤4：验证模型

训练完成后，检查模型文件：
```bash
ls -lh models/ppo_model_v1.pth
```

在 `rl_decision_engine.py` 中，模型路径应该是：
```python

```

## 常见问题

### Q1: 模型输出无效索引（如102、91等）

**原因**：
- 状态编码不一致
- 模型未正确训练
- 动作空间定义错误

**解决**：
1. 确保训练和推理使用相同的编码
2. 检查模型是否正确加载
3. 验证动作空间维度是否匹配

### Q2: 训练损失不下降

**原因**：
- 数据质量差
- 学习率过高/过低
- 编码问题

**解决**：
1. 检查训练数据质量
2. 调整学习率
3. 验证状态编码是否正确

### Q3: 模型性能差

**原因**：
- 训练数据不足
- 训练时间不够
- 奖励函数设计不当

**解决**：
1. 增加训练数据
2. 延长训练时间
3. 优化奖励函数
