# M1工作流自动训练指南

## 📋 概述

M1训练工作流是一个**全自动化**的训练系统，能够：
- ✅ 自动监控训练进度（MLflow实时指标）
- ✅ 自动评估M1 vs Client胜率
- ✅ 根据训练结果自动优化参数
- ✅ 持续迭代直到达成目标
- ✅ **达成目标时自动通知用户**

## 🎯 目标

**唯一目标：M1战胜client（胜率 > 50%）**

## 🚀 快速开始

### 方法1：使用批处理脚本（推荐）

```bash
START_M1_WORKFLOW_FULL.bat
```

### 方法2：直接运行Python脚本

```bash
python src/train/m1_training_workflow.py --max_iterations 10 --target_win_rate 0.50 --min_games 50
```

## 📊 工作流程

工作流会自动执行以下步骤（循环迭代）：

```
┌─────────────────────────────────────┐
│  1. 自动运行M1与client对战生成记录   │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  2. 训练模型（MLflow实时监控）      │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  3. 从MLflow读取实时指标并分析      │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  4. 根据MLflow指标自动优化代码      │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  5. 评估M1 vs Client胜率            │
└──────────────┬──────────────────────┘
               │
               ├─ 胜率 ≥ 50% ──→ ✅ 达成目标，发送通知
               │
               └─ 胜率 < 50% ──→ 🔄 优化参数，继续下一轮
```

## 🔔 通知机制

### 达成目标时的通知

当M1胜率 ≥ 50% 时，工作流会：

1. **控制台输出**：显示醒目的成功消息
   ```
   🎉🎉🎉 目标达成！M1已能战胜client！🎉🎉🎉
   最终胜率: XX.XX%
   迭代次数: X
   ```

2. **创建成功标记文件**：`models/M1_TARGET_ACHIEVED.txt`
   - 包含详细的成功信息
   - 胜率、迭代次数、完成时间等

3. **Windows系统通知**（如果可用）：
   - 弹出系统通知窗口
   - 显示成功消息

4. **保存工作流历史**：`models/m1_training_workflow_history.json`
   - 记录所有迭代的详细信息

### 未达成目标时的提示

如果达到最大迭代次数仍未达成目标：

1. **控制台警告**：显示当前胜率和距离目标的差距
2. **创建未完成标记**：`models/M1_TARGET_NOT_ACHIEVED.txt`
3. **保存工作流历史**：记录所有迭代信息

## 📈 实时监控

### 方法1：MLflow UI（推荐）

在新终端运行：

```bash
mlflow ui --backend-store-uri file:///d:/YiFeiAI-GD/logs/mlruns
```

然后在浏览器打开：`http://localhost:5000`

**查看内容**：
- 实时训练指标（损失、预测质量等）
- 训练参数
- 指标随时间变化的图表

### 方法2：检查工作流状态

```bash
python check_workflow_notification.py
```

**显示内容**：
- 工作流当前状态
- 是否达成目标
- 迭代历史记录
- 当前胜率和目标差距

### 方法3：查看状态文件

```bash
# 查看当前状态
type models\m1_workflow_status.txt

# 查看是否达成目标
type models\M1_TARGET_ACHIEVED.txt
```

## ⚙️ 配置参数

### 命令行参数

```bash
python src/train/m1_training_workflow.py \
    --max_iterations 10 \      # 最大迭代次数
    --target_win_rate 0.50 \   # 目标胜率（50%）
    --min_games 50 \           # 评估所需最少对局数
    --server_path PATH \       # 游戏服务器路径（可选）
    --no_auto_optimize          # 禁用自动代码优化
```

### 默认配置

- **最大迭代次数**：10
- **目标胜率**：50%
- **评估对局数**：50
- **自动优化**：启用

## 📁 输出文件

工作流会生成以下文件：

| 文件 | 说明 |
|------|------|
| `models/m1_training_workflow_history.json` | 完整的工作流历史记录 |
| `models/m1_workflow_status.txt` | 当前工作流状态 |
| `models/M1_TARGET_ACHIEVED.txt` | 目标达成标记（如果成功） |
| `models/M1_TARGET_NOT_ACHIEVED.txt` | 未达成标记（如果失败） |
| `models/bc_model_stage7_optimized.pth` | 训练好的模型文件 |
| `models/bc_model_stage7_optimized_training_history.json` | 训练历史记录 |

## 🎯 使用场景

### 场景1：从头开始训练

```bash
# 直接运行完整工作流
START_M1_WORKFLOW_FULL.bat
```

工作流会自动：
1. 检查/生成游戏记录
2. 开始训练
3. 持续迭代直到达成目标

### 场景2：继续之前的训练

如果之前的工作流未完成，可以直接重新运行：

```bash
START_M1_WORKFLOW_FULL.bat
```

工作流会：
1. 读取之前的训练历史
2. 从上次停止的地方继续
3. 使用优化后的参数继续训练

### 场景3：调整目标胜率

```bash
python src/train/m1_training_workflow.py \
    --target_win_rate 0.60 \  # 目标60%胜率
    --max_iterations 20       # 增加迭代次数
```

## ⚠️ 注意事项

1. **确保有足够的游戏记录**：
   - 工作流会自动运行对战生成记录
   - 但建议至少有50局记录用于评估

2. **MLflow监控**：
   - 建议在新终端启动MLflow UI实时查看
   - 不影响工作流运行

3. **训练时间**：
   - 每轮训练可能需要较长时间
   - 工作流会自动进行，无需人工干预

4. **达成目标后**：
   - 工作流会自动停止
   - 创建成功标记文件
   - 可以通过 `check_workflow_notification.py` 查看详情

## 🐛 故障排查

### 问题1：工作流没有通知

**检查**：
```bash
python check_workflow_notification.py
```

**解决**：
- 确认工作流是否正常运行
- 检查 `models/M1_TARGET_ACHIEVED.txt` 是否存在

### 问题2：看不到MLflow数据

**检查**：
```bash
python check_mlflow_runs.py
```

**解决**：
- 确认MLflow UI使用正确的URI启动
- 刷新浏览器页面

### 问题3：胜率评估失败

**检查**：
- 是否有足够的游戏记录
- 游戏记录格式是否正确

**解决**：
- 工作流会自动运行对战生成记录
- 如果失败，检查游戏服务器配置
