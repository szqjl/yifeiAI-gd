## 📋 策略分析

### 1. 顺牌策略（Follow Card Strategy）

#### 当前实现
- **位置**: `src/decision/single_card_strategy.py`
- **逻辑**: "顺上家出单" - 上家的单牌，对自己有利，应该顺牌
- **规则**: 
  - 上家出单张，如果对自己有利，应该顺牌
  - 初期上家出单，跟出天然小单

#### 核心决策点
1. **何时顺牌**：判断上家出牌是否对自己有利
2. **顺什么牌**：选择合适大小的牌顺牌（不能太大，不能太小）
3. **顺牌时机**：开局、中期、残局不同阶段的顺牌策略

### 2. 跟牌策略（Follow-Up Strategy）

#### 当前实现
- **位置**: `src/decision/cooperation.py`
- **逻辑**: "初期跟牌逻辑" - 初期对手出单，应该积极跟牌
- **规则**:
  - 初期对手出单，优先跟天然小单
  - 价值差异不大时，积极跟牌
  - 中后期，对手出单必须压制

#### 核心决策点
1. **何时跟牌**：判断是否应该跟牌（初期vs中后期）
2. **跟牌大小**：选择合适大小的牌跟牌
3. **跟牌vs压制**：判断是跟牌还是应该压制

### 3. 控牌策略（Control Strategy）

#### 当前实现
- **位置**: `src/decision/bomb_strategy.py`, `src/decision/cooperation.py`
- **逻辑**: "炸常规牌型的控牌" - 通过炸弹获得控牌权
- **规则**:
  - 炸单牌的控牌大王，比较划算
  - 炸一对小王，比较划算
  - 炸顺子的控牌10JQKA，比较划算
  - 中后期，对手出单必须压制

#### 核心决策点
1. **何时控牌**：判断是否需要控牌（对手快走完、队友需要帮助等）
2. **如何控牌**：选择合适的方式控牌（炸弹、大牌等）
3. **控牌代价**：评估控牌的代价和收益

## 🎯 训练可行性分析

### ✅ 适合训练的原因

1. **决策复杂度高**
   - 顺牌、跟牌、控牌涉及多个因素：牌力、游戏阶段、对手行为、队友状态等
   - 规则难以覆盖所有情况，需要学习最优策略

2. **长期收益**
   - 这些策略的收益往往在长期对局中体现
   - 强化学习适合学习长期策略

3. **状态空间丰富**
   - 游戏状态包含手牌、桌牌、历史、对手行为等丰富信息
   - 适合神经网络学习复杂模式

4. **奖励信号明确**
   - 对局胜负可以作为最终奖励
   - 可以设计中间奖励（如成功控牌、成功顺牌等）

### ⚠️ 训练挑战

1. **多智能体环境**
   - 掼蛋是4人游戏，涉及队友和对手
   - 需要处理合作和竞争关系

2. **稀疏奖励**
   - 对局胜负是稀疏奖励
   - 需要设计shaping reward来引导学习

3. **策略多样性**
   - 不同牌力、不同阶段需要不同策略
   - 需要学习策略的多样性

## 🚀 训练方案设计

### 方案1：端到端训练（推荐）⭐⭐⭐

#### 思路
直接训练RL模型学习顺牌、跟牌、控牌策略，通过大量对局学习最优决策。

#### 实现步骤

1. **状态表示增强**
   ```python
   # 在现有512维状态向量基础上，增加顺牌/跟牌/控牌相关特征
   state_features = {
       'hand_cards': 512维,  # 现有
       'table_cards': 512维,  # 现有
       'game_phase': 3维,  # 开局/中期/残局
       'opponent_rest_cards': 4维,  # 4个玩家的剩余牌数
       'last_action_type': 10维,  # 上一步动作类型
       'last_action_rank': 15维,  # 上一步动作牌点
       'can_follow': 1维,  # 是否能跟牌
       'can_control': 1维,  # 是否能控牌
       'teammate_power': 1维,  # 队友牌力
       'opponent_power': 2维,  # 对手牌力（2个对手）
   }
   ```

2. **奖励函数设计**
   ```python
   def calculate_reward(state, action, next_state, done):
       reward = 0.0
       
       # 1. 最终奖励（最重要）
       if done:
           if won:
               reward += 100.0
           else:
               reward -= 100.0
       
       # 2. 顺牌奖励（Shaping Reward）
       if action_type == "follow":
           if follow_successful:  # 成功顺牌
               reward += 5.0
           if follow_optimal:  # 顺牌大小合适
               reward += 2.0
       
       # 3. 跟牌奖励
       if action_type == "follow_up":
           if follow_up_successful:  # 成功跟牌
               reward += 3.0
           if follow_up_timing_good:  # 跟牌时机好
               reward += 2.0
       
       # 4. 控牌奖励
       if action_type == "control":
           if control_successful:  # 成功控牌
               reward += 10.0
           if control_necessary:  # 控牌必要（对手快走完）
               reward += 5.0
           if control_cost_high:  # 控牌代价高（用炸弹）
               reward -= 3.0  # 惩罚过度使用炸弹
       
       # 5. 策略奖励
       if action_helps_teammate:  # 帮助队友
           reward += 5.0
       if action_blocks_opponent:  # 阻止对手
           reward += 3.0
       
       return reward
   ```

3. **训练流程**
   ```python
   # 1. 初始化环境
   env = GuandanEnv()
   agent = PPOAgent()
   
   # 2. 训练循环
   for episode in range(num_episodes):
       state = env.reset()
       done = False
       
       while not done:
           # 选择动作（包含顺牌/跟牌/控牌决策）
           action = agent.select_action(state)
           
           # 执行动作
           next_state, reward, done, info = env.step(action)
           
           # 计算shaping reward
           shaping_reward = calculate_shaping_reward(
               state, action, next_state, info
           )
           total_reward = reward + shaping_reward
           
           # 存储经验
           agent.store_experience(state, action, total_reward, done)
           
           state = next_state
       
       # 更新策略
       if episode % update_frequency == 0:
           agent.update()
   ```

#### 优点
- ✅ 端到端学习，不需要人工设计规则
- ✅ 可以学习复杂的策略组合
- ✅ 适应性强，可以应对各种情况

#### 缺点
- ⚠️ 训练时间长，需要大量对局
- ⚠️ 需要精心设计奖励函数
- ⚠️ 可能学习到次优策略

## 📊 训练指标设计

### 1. 顺牌策略指标

- **顺牌成功率**: 成功顺牌次数 / 总顺牌次数
- **顺牌大小合适率**: 顺牌大小合适的次数 / 总顺牌次数
- **顺牌收益**: 顺牌后减少的手数

### 2. 跟牌策略指标

- **跟牌成功率**: 成功跟牌次数 / 总跟牌次数
- **跟牌时机准确率**: 跟牌时机准确的次数 / 总跟牌次数
- **跟牌收益**: 跟牌后获得的优势

### 3. 控牌策略指标

- **控牌成功率**: 成功控牌次数 / 总控牌次数
- **控牌必要性**: 控牌必要的次数 / 总控牌次数
- **控牌收益**: 控牌后获得的优势

### 4. 综合指标

- **胜率**: 对局胜率
- **平均手数**: 平均剩余手数

```python
def _encode_follow_control_features(self, game_state):
    """编码顺牌/跟牌/控牌相关特征"""
    features = []
    
    # 1. 是否能顺牌
    can_follow = self._can_follow(game_state)
    features.append(1.0 if can_follow else 0.0)
    
    # 2. 是否能跟牌
    can_followup = self._can_followup(game_state)
    features.append(1.0 if can_followup else 0.0)
    
    # 3. 是否需要控牌
    need_control = self._need_control(game_state)
    features.append(1.0 if need_control else 0.0)
    
    # 4. 上一步动作类型
    last_action_type = self._encode_action_type(game_state.get('last_action'))
    features.extend(last_action_type)
    
    # 5. 对手剩余牌数
    opponent_cards = game_state.get('opponent_rest_cards', [27, 27, 27])
    features.extend([c / 27.0 for c in opponent_cards])
    
    return features
```

```python
# 在 src/train/train_follow_control.py 中
def train_follow_control_strategy():
    """训练顺牌/跟牌/控牌策略"""
    
    # 1. 初始化
    env = GuandanEnv()
    agent = PPOAgent()
    
    # 2. 训练参数

    # 3. 训练循环
    for episode in range(num_episodes):
        state = env.reset()
        done = False
        episode_reward = 0.0
        
        while not done:
            # 选择动作
            action = agent.select_action(state)
            
            # 执行动作
            next_state, reward, done, info = env.step(action)
            
            # 计算shaping reward

            total_reward = reward + shaping_reward
            
            # 存储经验
            agent.store_experience(state, action, total_reward, done)
            
            state = next_state
            episode_reward += total_reward
        
        # 更新策略
        if episode % update_frequency == 0:
            agent.update()
        
        # 记录日志
        if episode % 100 == 0:
            print(f"Episode {episode}, Reward: {episode_reward:.2f}")
```
