## 📋 问题背景

yf_v5经过训练后，出牌有了明显改善，但在行牌过程中，组牌如何动态优化还有问题。

### 原有问题

1. **静态组牌评估**：组牌策略只在决策时评估一次，没有根据游戏进程动态调整
2. **缺乏动态调整机制**：没有根据剩余手牌、对手出牌情况等动态重新评估组牌
3. **"把牌配死"问题**：组牌策略缺乏灵活性，无法根据牌局形势灵活调整

### 核心需求

根据组牌技巧文档中的核心原理：
> "组牌，切忌一开始就把牌配死，拟好出牌计划，然后守株待兔。有同类型牌出现，如鱼得水，神气活现；一旦同类型牌不出现，只能眼睁睁看着对手冲牌、清牌。"

> "掼蛋组牌，本质上强调的是动态组合，要求把每张牌在合适时间，放在最合适位置，发挥其最大的效用。"

---

## 🎯 解决方案

### 动态组牌优化模块

创建了 `DynamicGroupingOptimizer` 类，实现行牌过程中的动态组牌优化。

**文件位置**: `src/decision/dynamic_grouping_optimizer.py`

### 核心功能

#### 1. 动态触发机制

在以下情况下触发组牌重新优化：

- ✅ **手牌数显著变化**：手牌数减少3张以上
- ✅ **游戏阶段变化**：开局→中局→残局
- ✅ **进入关键区间**：剩余手牌数≤10张（残局）
- ✅ **对手出牌后**：需要根据对手行为调整组牌策略
- ✅ **牌力显著变化**：牌力变化≥2.0

#### 2. 动态调整策略

根据游戏状态动态调整组牌评分：

1. **残局阶段优化**
   - 优先减少手数（轮次减少加分+30）
   - 优先减少单牌（单牌减少加分+25）

2. **对手行为分析**
   - 记录对手出牌行为
   - 如果对手多次不吃某种牌型，可以调整组牌策略
   - 对手不吃某种牌型时，可以拆成这种牌型打出（加分+20）

3. **手牌数优化**
   - 手牌数≤10张时，优先减少单牌
   - 手牌数≤5张时，优先出能走完的牌型（加分+40）

4. **牌力变化调整**
   - 牌力增强：更激进组牌，优先减少轮次（加分+15）
   - 牌力减弱：更保守组牌，优先保留炸弹（加分+20）

5. **游戏阶段调整**
   - 开局阶段：优先减少轮次和单牌
   - 中局阶段：根据牌局形势灵活调整
   - 残局阶段：优先减少手数，优先出能走完的牌型

```python
class DynamicGroupingOptimizer:
    def __init__(self):
        self.last_hand_count = 27  # 上次手牌数
        self.last_power = 0.0  # 上次牌力
        self.grouping_history = []  # 组牌历史记录
        self.opponent_behavior = {}  # 对手行为记录
    
    def should_reoptimize(self, game_state: Dict) -> bool:
        """判断是否需要重新优化组牌"""
        
    def optimize_grouping(self, hand_cards, action_list, game_state) -> Dict:
        """动态优化组牌策略"""
        
    def get_grouping_recommendation(self, hand_cards, action_list, game_state) -> Optional[Dict]:
        """获取组牌推荐"""
```

### 集成到yf_v5

#### 1. 初始化

在 `yf1_v5.py` 和 `yf2_v5.py` 的 `__init__` 方法中：

```python
# Initialize Dynamic Grouping Optimizer (动态组牌优化器)
self.grouping_optimizer = DynamicGroupingOptimizer()
```

#### 2. 在决策流程中使用

在 `_apply_strategy_suggestions` 方法中，在调用 `grouping_strategy` 之后：

```python
# 1. 组牌策略（优先：减少轮次、减少单牌）
grouping_sugg = grouping_strategy(...)

# 1.1. 动态组牌优化（在行牌过程中动态调整组牌策略）
dynamic_grouping_rec = self.grouping_optimizer.get_grouping_recommendation(
    hand_cards=hand_cards,
    action_list=action_list,
    game_state=game_state
)

# 如果动态优化器建议调整，应用动态优化结果
if dynamic_grouping_rec:
    # 更新grouping_sugg中的对应建议
    # 应用动态优化评分调整
    # 记录动态优化信息
```

## 🚀 使用说明

### 自动触发

动态组牌优化器会在以下情况自动触发：

1. **手牌数变化**：手牌数减少3张以上
2. **阶段变化**：游戏阶段从开局→中局→残局
3. **关键区间**：剩余手牌数≤10张
4. **对手出牌**：对手出牌后（非PASS）
5. **牌力变化**：牌力变化≥2.0

### 日志输出

动态优化器会输出详细的日志信息：

```
[动态组牌优化] 建议动作索引: 5, 评分: 85.50, 原因: 残局阶段优先减少手数, 减少轮次（胜负规则优先）
[动态组牌优化] 优化原因: 残局阶段优先减少手数, 手牌较少时优先减少单牌
```
