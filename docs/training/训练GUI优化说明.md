## 使用说明

### 启动训练GUI

1. **双击运行** `run_training_gui.bat`

2. **或命令行运行**：
   ```bash
   run_training_gui.bat
   ```

### 训练步骤

1. **选择数据目录**
   - 点击"选择数据目录"
   - 选择 `game_records` 目录（包含训练数据）

2. **确认训练参数**（已自动设置为优化值）
   - 训练轮数：50
   - 批次大小：64
   - 学习率：0.0003

3. **选择训练类型**
   - 预训练（Behavior Cloning）

4. **点击"开始训练"**

5. **观察训练进度**
   - 进度条实时更新
   - 日志窗口显示训练过程

### 训练完成后

1. **查看训练日志**
   - 日志保存在 `training_logs\` 目录
   - 文件名格式：`training_log_YYYYMMDD_HHMMSS.txt`

2. **评估模型效果**
   ```bash
   python src/train/evaluate_model.py
   ```

3. **分析训练效果**
   ```bash
   python src/train/analyze_training_effectiveness.py
   ```

## 注意事项

### 1. Python环境

- 需要Python 3.7或更高版本
- 需要安装必要的包：`torch`, `numpy`, `gymnasium`, `tkinter`

### 2. 训练数据

- 确保 `game_records\` 目录中有训练数据（JSON文件）
- 建议至少100个对局（约1000个训练样本）

### 3. 训练时间

- **数据量**: 13,409个样本
- **批次大小**: 64
- **训练轮数**: 50
- **预计时间**: 约30-40分钟（CPU）

### 4. 模型输出问题

如果训练完成后发现模型输出概率偏低（预测过少），建议：

1. **调整模型输出**（优先级最高）
   - 修改 `src/rl_agent/model.py` 中的 `get_action` 方法
   - 添加概率缩放（放大50倍）

2. **降低预测阈值**
   - 从0.3降低到0.05或0.01

3. **重新训练**
   - 减少Dropout比率：0.2 → 0.1
   - 调整学习率：0.0003 → 0.0005

## 故障排除

### 问题1：无法启动GUI

**症状**: 双击bat文件后立即关闭

**解决方案**:
1. 检查Python是否安装：`python --version`
2. 检查依赖是否安装：`pip list | findstr torch`
3. 查看错误信息（在命令行中运行bat文件）

### 问题2：训练过程中出错

**症状**: 训练开始后立即失败

**解决方案**:
1. 检查训练数据是否存在
2. 检查模型目录是否可写
3. 查看训练日志中的错误信息

### 问题3：训练速度慢

**症状**: 训练时间过长

**解决方案**:
1. 减少训练轮数（用于测试）
2. 减少批次大小（如果内存不足）
3. 使用GPU（如果可用）
