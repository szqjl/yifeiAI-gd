# 训练GUI使用指南

## 概述

训练GUI工具提供了一个图形界面，可以方便地：
1. 导入和转换平台.rep文件
2. 配置训练参数
3. 启动训练
4. 查看训练日志
5. 保存训练结果

## 启动GUI

### Windows系统

**方法1：双击运行（推荐）**
- 双击 `run_training_gui.bat` 文件即可启动GUI

**方法2：命令行运行**
```bash
cd D:/YiFeiAI-GD
run_training_gui.bat
```

### 其他系统

```bash
cd D:/YiFeiAI-GD
python src/train/training_gui.py
```

## 使用步骤

### 步骤1：导入数据

1. **选择.rep文件或目录**
   - 点击"浏览"按钮选择.rep文件或包含.rep文件的目录
   - 支持单个文件或整个目录
   - **批量转换时**：如果留空，会自动使用默认目录 `C:\Program Files (x86)\gdgame\MobileGD\replay`

2. **设置输出目录**
   - 默认：`game_records`
   - 可以点击"浏览"选择其他目录

3. **设置目标玩家ID（可选）**
   - 留空：提取所有玩家的数据
   - 填写数字（如2）：只提取指定seat的玩家数据
   - **注意**：批量转换时，此选项会被忽略（自动识别获胜玩家）

4. **优先选择获胜玩家（推荐）**
   - 勾选：自动识别每个对局的获胜玩家，只提取获胜玩家的数据
   - 不勾选：提取所有玩家的数据

4. **选择转换方式**
   - **转换数据**：转换单个文件或目录（适合少量文件）
   - **批量转换**：批量转换大量.rep文件（适合1000+文件）
   
5. **点击"转换数据"或"批量转换"**
   - **转换数据**：转换过程会在日志区域显示
   - **批量转换**：
     - 会弹出对话框询问转换数量（默认1000）
     - 转换过程会在日志区域实时显示
     - 显示转换进度、速度、预计剩余时间
     - 转换完成后显示统计信息

### 步骤2：配置训练

1. **选择训练类型**
   - 预训练 (Behavior Cloning)：从人类数据学习
   - 强化学习 (Self-Play)：自我对弈训练

2. **设置训练参数**
   - **训练轮数**：默认5，建议10-20
   - **批次大小**：默认32，可以增加到64
   - **学习率**：默认0.001，可以尝试0.0005

3. **设置模型保存路径**
   - 默认：`models/bc_model_v1.pth`
   - 可以点击"浏览"选择其他路径

### 步骤3：开始训练

1. **点击"开始训练"按钮**
   - 训练过程会在日志区域实时显示
   - 状态栏会显示当前状态（训练中/完成/失败）

2. **查看训练日志**
   - 日志区域会显示：
     - 训练进度
     - 损失值
     - 训练速度
     - 错误信息（如果有）

3. **训练完成**
   - 训练日志会自动保存到 `training_logs/` 目录
   - 文件名格式：`training_log_YYYYMMDD_HHMMSS.txt`

## 日志文件格式

训练日志文件包含：
- 训练开始时间
- 模型路径
- 训练参数
- 完整的训练输出
- 训练结束时间

日志文件可用于：
- 分析训练过程
- 调试问题
- 为下一步改进提供依据

## 功能特点

### 1. 实时日志显示
- 训练过程中的所有输出都会实时显示在日志区域
- 支持滚动查看历史日志

### 2. 后台线程处理
- 数据转换和训练都在后台线程中运行
- 不会阻塞GUI界面

### 3. 自动日志保存
- 训练完成后自动保存日志到文件
- 方便后续分析和改进

### 4. 错误处理
- 转换或训练失败时会显示错误信息
- 包含详细的错误堆栈

## 注意事项

### 1. 数据转换
- 确保.rep文件格式正确
- 转换前检查输出目录是否有写入权限

### 2. 训练参数
- 训练轮数不要设置太大（建议10-20）
- 批次大小根据内存调整
- 学习率建议从0.001开始

### 3. 模型保存
- 确保模型保存路径的目录存在
- 建议使用有意义的文件名（如包含日期）

### 4. 资源使用
- 训练会占用CPU/GPU资源
- 建议在训练时不要运行其他占用资源的程序

## 常见问题

### Q1: 转换数据时没有输出

**解决**：
- 检查.rep文件路径是否正确
- 检查输出目录是否有写入权限
- 查看日志区域的错误信息

### Q2: 训练时没有输出

**解决**：
- 检查训练数据目录是否有JSON文件
- 检查模型保存路径是否正确
- 查看日志区域的错误信息

### Q3: 训练速度慢

**解决**：
- 检查是否使用GPU（日志会显示）
- 减少批次大小
- 减少训练数据量

### Q4: 训练失败

**解决**：
- 查看日志区域的错误信息
- 检查训练数据格式是否正确
- 检查依赖包是否安装完整

## 日志分析

训练日志文件可以用于：

1. **分析训练过程**
   - 损失值变化趋势
   - 训练速度
   - 资源使用情况

2. **调试问题**
   - 查找错误原因
   - 分析性能瓶颈
   - 优化训练参数

3. **改进建议**
   - 根据损失值调整学习率
   - 根据训练速度调整批次大小
   - 根据资源使用调整训练轮数

## 下一步

训练完成后：
1. 查看训练日志文件
2. 分析训练结果
3. 根据日志调整参数
4. 重新训练或继续强化学习训练
