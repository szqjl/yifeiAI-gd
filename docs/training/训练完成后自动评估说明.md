# 训练完成后自动评估说明

## ✅ 功能说明

训练完成后，系统可以自动运行三个评估步骤：

1. **验证训练结果** - 检查训练是否正常完成
2. **评估模型效果** - 评估模型的准确率
3. **分析训练效果** - 详细分析训练效果和改进建议

---

## 🚀 使用方法

### 方法1：GUI自动评估（推荐）

1. **启动训练GUI**：
   ```bash
   run_training_gui.bat
   ```

2. **勾选"训练完成后自动评估模型效果"**（默认已勾选）

3. **开始训练**

4. **训练完成后**，系统会自动运行三个评估步骤，结果会显示在日志窗口中

### 方法2：手动运行评估脚本

如果训练时未勾选自动评估，可以手动运行：

```bash
evaluate_after_training.bat
```

## 📊 评估内容

### 1. 验证训练结果

**脚本**: `src/train/check_training_completion.py`

**检查内容**:
- ✅ 模型文件是否存在
- ✅ 模型结构是否正常
- ✅ 训练日志是否完整
- ✅ 模型输出概率是否正常

**输出示例**:

### 2. 评估模型效果

**脚本**: `src/train/evaluate_model.py`

**评估指标**:
- 完全匹配准确率
- 卡牌级别准确率
- 平均预测卡牌数

**输出示例**:
```
============================================================

============================================================
总样本数: 13409

完全匹配准确率: 1.40%
卡牌级别准确率: 99.35%
平均预测卡牌数: 1.74
```

### 3. 分析训练效果

**脚本**: `src/train/analyze_training_effectiveness.py`

**分析内容**:
- 模型输出概率分析
- 预测分布分析
- 历史对比
- 改进建议

**输出示例**:
```

  完全匹配: 2554 (19.0%)
  预测过多: 856 (6.4%)
  预测过少: 9999 (74.6%)
```

## ⚙️ 配置选项

### GUI中的选项

在训练GUI中，有一个复选框：
- **"训练完成后自动评估模型效果"**（默认：已勾选）

如果取消勾选，训练完成后不会自动评估，可以稍后手动运行 `evaluate_after_training.bat`

## 📝 评估结果

### 结果位置

1. **GUI日志窗口**：评估结果会实时显示在训练GUI的日志窗口中

2. **控制台输出**：如果使用批处理脚本，结果会显示在控制台

3. **详细报告**：建议查看以下文档：
   - `docs/training/训练完成最终报告.md`
   - `docs/training/训练效果最终分析.md`

## 🎯 使用建议

### 推荐流程

1. **训练时**：勾选"训练完成后自动评估模型效果"
2. **训练完成后**：查看GUI日志窗口中的评估结果
3. **根据评估结果**：决定是否需要调整模型输出或重新训练

### 如果评估发现问题

1. **模型输出概率偏低**：
   - 调整模型输出（概率缩放）
   - 降低预测阈值

2. **预测过少问题**：
   - 调整模型输出（概率缩放）
   - 进一步降低预测阈值

3. **完全匹配准确率低**：
   - 调整模型输出（概率缩放）
   - 重新训练，调整训练参数

## 🔧 故障排除

### 问题1：评估脚本运行失败

**症状**: GUI中显示评估失败

**解决方案**:
1. 检查模型文件是否存在
2. 检查评估脚本是否存在
3. 查看错误信息

### 问题2：评估时间过长

**症状**: 评估过程很慢

**解决方案**:
1. 这是正常的，评估需要处理所有测试数据
2. 可以取消自动评估，稍后手动运行

### 问题3：评估结果不显示

**症状**: 评估完成后看不到结果

**解决方案**:
1. 检查GUI日志窗口是否滚动到底部
2. 查看是否有错误信息
3. 手动运行 `evaluate_after_training.bat`
