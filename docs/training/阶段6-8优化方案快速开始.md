## 🚀 快速开始

### 前置条件

1. **完成阶段5训练**：确保有基础模型
2. **准备游戏数据**：`game_records`目录下有足够的对局数据
3. **Python环境**：Python 3.8+，已安装所需依赖

### 阶段6优化版训练

```bash
# 运行阶段6优化版训练（两阶段训练）
python train_stage6_optimized.py
```

**训练流程**：
1. 第一阶段：冻结主干，训练决策头（30 epochs）
2. 轨迹收集：收集高胜率对局轨迹
3. 第二阶段：全量微调（50 epochs）

**输出文件**：
- `models/bc_model_stage6_stage1_YYYYMMDD_HHMMSS.pth` - 第一阶段模型
- `models/bc_model_stage6_stage2_YYYYMMDD_HHMMSS.pth` - 第二阶段模型
- `trajectories/stage6_trajectories_YYYYMMDD_HHMMSS.json` - 收集的轨迹

### 阶段7在线强化学习

```bash
# 运行阶段7在线强化学习（探索-内化循环）
python train_stage7_online_rl.py
```

**训练流程**：
1. 加载阶段6优化版模型
2. 进行5个循环的探索-内化训练
3. 每个循环：20局对局 → 收集轨迹 → 内化训练

**输出文件**：
- `models/bc_model_stage7_cycle_N_YYYYMMDD_HHMMSS.pth` - 每个循环的模型
- `trajectories/stage7_cycle_N_YYYYMMDD_HHMMSS.json` - 每个循环的轨迹

### 阶段8完整强化学习

```bash
# 运行阶段8完整强化学习（PPO算法）
python train_stage8_full_rl.py
```

**训练流程**：
1. 加载阶段7模型作为初始化
2. 使用PPO算法进行500个episode训练
3. 每20个episode更新一次策略和价值网络

**输出文件**：
- `models/stage8_ppo_best_YYYYMMDD_HHMMSS.pth` - 最佳模型
- `models/stage8_ppo_checkpoint_N_YYYYMMDD_HHMMSS.pth` - 检查点

## 🔧 注意事项

### 1. 模型路径

- 阶段7需要阶段6的模型路径：`models/bc_model_stage6_stage2_latest.pth`
- 阶段8需要阶段7的模型路径：`models/bc_model_stage7_cycle_5_latest.pth`

如果路径不存在，脚本会使用随机初始化。

### 2. 数据要求

- 阶段6：需要`game_records`目录下的对局数据
- 阶段7：可以使用阶段6收集的轨迹，也可以重新收集
- 阶段8：需要环境支持（`GuandanEnv`）

### 3. 训练时间

- 阶段6：约2-3小时（取决于数据量）
- 阶段7：约3-4小时（5个循环）
- 阶段8：约5-6小时（500个episode）

## 🐛 常见问题

### Q1: 训练过程中出现"训崩"怎么办？

**A**: 使用阶段6优化版的两阶段训练，第一阶段冻结主干，避免"训崩"。

### Q2: 轨迹收集数量为0怎么办？

**A**: 检查：
1. 游戏数据中是否有高胜率对局（≥60%）
2. 轨迹质量分数阈值是否过高（默认0.7）
3. 可以降低`min_win_rate`和`min_trajectory_score`阈值

### Q3: 阶段7/8训练时找不到前置模型？

**A**: 脚本会自动使用随机初始化，但效果可能不如使用前置模型。建议先完成阶段6训练。

### Q4: 训练时间过长怎么办？

**A**: 可以：
1. 减少训练轮数（epochs/episodes）
2. 减少数据量（max_samples）
3. 使用GPU加速（如果可用）
