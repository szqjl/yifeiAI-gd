# 增强功能使用说明

**创建时间**: 2025-01-27  
**版本**: v1.0

---

## 📋 新增功能概览

训练系统已添加以下增强功能：

### ✅ 1. 模型评估和选择
- **自动评估**: 训练过程中定期评估模型
- **最佳模型保存**: 自动保存胜率最高的模型
- **评估指标**: 胜率、平均奖励

### ✅ 2. 检查点保存
- **定期保存**: 每N回合自动保存检查点
- **版本管理**: 支持多个检查点版本
- **恢复训练**: 可以从检查点恢复训练

### ✅ 3. 经验回放（Experience Replay）
- **经验缓冲区**: 存储历史经验
- **随机采样**: 从缓冲区随机采样训练
- **提高效率**: 充分利用历史经验

### ✅ 4. 持续学习（Continuous Learning）
- **在线学习**: 支持运行时持续学习
- **增量更新**: 从新数据中增量更新模型
- **版本管理**: 模型版本控制和回滚

### ✅ 5. 课程学习（Curriculum Learning）
- **难度递增**: 从简单到复杂的训练策略
- **自适应调整**: 根据胜率自动调整难度
- **阶段划分**: 简单→中等→困难→专家

## 🚀 使用方法

### 方法1：使用增强版训练脚本

```bash
python src/train/enhanced_self_play.py
```

**参数配置**:
```python
train_enhanced_self_play(
    max_episodes=1000,        # 最大训练回合数
    eval_interval=100,         # 每100回合评估一次
    checkpoint_interval=200,  # 每200回合保存检查点
    replay_buffer_size=10000  # 经验回放缓冲区大小
)
```

### 方法2：使用训练GUI

1. 运行 `run_training_gui.bat`
2. 选择 **"增强版训练 (Enhanced)"**
3. 配置训练参数
4. 点击 **"开始训练"**

### 方法3：使用持续学习模块

```python
from src.train.continuous_learning import ContinuousLearner, ModelVersionManager
from src.rl_agent.agent import PPOAgent

# 初始化
agent = PPOAgent(input_dim=512, action_dim=512)
learner = ContinuousLearner(agent, replay_buffer_size=5000)
version_manager = ModelVersionManager()

# 添加经验
learner.add_experience(state, action, log_prob, reward, next_state, done, info)

# 保存版本
version_manager.save_version(agent, "v1.0", metadata={"win_rate": 0.65})
```

### 方法4：使用课程学习

```python
from src.train.curriculum_learning import CurriculumScheduler

# 初始化课程调度器
scheduler = CurriculumScheduler()

# 获取当前课程配置
curriculum = scheduler.get_current_curriculum(episode=500)
opponent_strength = scheduler.get_opponent_strength(episode=500)
stage_name = scheduler.get_stage_name(episode=500)
```

## 🔧 配置说明

### 评估间隔（eval_interval）

- **推荐值**: 100回合
- **说明**: 每100回合评估一次模型，保存最佳模型
- **影响**: 值越小，评估越频繁，但训练时间越长

### 检查点间隔（checkpoint_interval）

- **推荐值**: 200回合
- **说明**: 每200回合保存一次检查点
- **影响**: 值越小，检查点越多，但占用存储空间越大

### 经验回放缓冲区大小（replay_buffer_size）

- **推荐值**: 10000
- **说明**: 存储最近10000条经验
- **影响**: 值越大，训练效果越好，但内存占用越大

## 🎯 最佳实践

### 1. 训练流程

1. **预训练**（Behavior Cloning）
   - 使用专家数据预训练
   - 快速获得基础策略

2. **增强版训练**（Enhanced Self-Play）
   - 使用增强版训练脚本
   - 自动评估和保存最佳模型
   - 定期保存检查点

3. **持续学习**（Continuous Learning）
   - 从新对局中学习
   - 增量更新模型

### 2. 参数调优

- **评估间隔**: 根据训练时间调整（100-500回合）
- **检查点间隔**: 根据存储空间调整（200-1000回合）
- **缓冲区大小**: 根据内存调整（5000-20000）

### 3. 模型选择

- **最佳模型**: 用于生产环境（胜率最高）
- **最终模型**: 用于继续训练（最新状态）
- **检查点**: 用于恢复训练（特定回合）

## 🔍 故障排除

### 问题1：内存不足

**解决方案**:
- 减小 `replay_buffer_size`
- 增加 `checkpoint_interval`（减少检查点数量）

### 问题2：训练速度慢

**解决方案**:
- 增加 `eval_interval`（减少评估频率）
- 减小 `replay_buffer_size`

### 问题3：模型不收敛

**解决方案**:
- 检查学习率设置
- 使用课程学习（从简单到复杂）
- 增加训练回合数
