## 优化背景

### 文章核心观点

1. **从"模仿"到"自主进化"**
   - 机器人不能只靠"抄作业"（监督微调SFT）
   - 需要"试错+总结"（在线强化学习RL）

2. **两阶段训练策略（iRe-VLA方法）**
   - 第一阶段：冻结主干，只训练轻量级动作头
   - 第二阶段：收集成功轨迹，混合原始数据，全量微调

3. **稳定性优先**
   - 训练曲线平稳上升，避免震荡
   - 兼顾稳定性、效率与泛化能力

4. **探索-内化循环**
   - 探索：在真实环境中尝试不同策略
   - 内化：将成功经验内化成模型能力

### 项目现状

- **阶段6**：已实现游戏导向训练，但训练稳定性有待提升
- **阶段7**：规划中，需要引入在线强化学习
- **阶段8**：规划中，需要完整RL框架

## 核心启发点

### 1. 两阶段训练（iRe-VLA方法）

**文章方法**：
- 第一阶段：冻结大模型主干（VLM），只训练轻量级的动作头（Action Head）
- 第二阶段：收集成功轨迹，混合原始专家数据，在云端对整个模型做全量微调

**项目应用**：
- 第一阶段：冻结特征提取层（fc1, fc2），只训练决策头（fc3, fc_strategy）
- 第二阶段：收集高胜率轨迹，混合原始数据，全量微调所有层

**优势**：
- ✅ 训练稳定，避免"训崩"
- ✅ 单张4090显卡即可运行第一阶段
- ✅ 将临时技巧内化成肌肉记忆

### 2. 轨迹收集与回放

**文章方法**：
- 收集探索中成功的轨迹
- 混合原始专家数据

**项目应用**：
- 收集高胜率对局的完整轨迹
- 标记关键决策点
- 计算轨迹质量分数
- 混合原始数据和成功轨迹进行训练

### 3. 中间奖励设计

**文章问题**：
- 任务周期长、奖励稀疏（如拧瓶盖要连续10步才算成功）

**项目对应**：
- 掼蛋一局多轮，最终胜率是稀疏奖励
- 需要设计中间奖励（压制成功、配合得分等）

**解决方案**：
- 压制成功奖励: +0.1
- 配合奖励: +0.15
- 控场奖励: +0.1
- 出牌效率奖励: +0.05
- 关键牌使用奖励: +0.2

### 4. 探索-内化循环

**文章方法**：
- 探索：机器人在真实环境中尝试不同策略
- 内化：将成功经验内化成模型能力

**项目应用**：
- 探索阶段：AI在真实对局中尝试不同策略，收集轨迹
- 内化阶段：筛选高胜率轨迹，混合原始数据，更新模型

## 阶段6优化方案

### 优化前（原阶段6）

- 一次性训练所有层
- 训练稳定性一般
- 容易"训崩"

### 优化后（阶段6优化版）

#### 架构设计

```
阶段6优化版训练流程：
┌─────────────────────────────────────┐
│  第一阶段：冻结主干，训练决策头      │
│  - 冻结：fc1, fc2（特征提取层）      │
│  - 训练：fc3（动作头）, fc_strategy │
│  - 目标：安全探索，避免"训崩"        │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  轨迹收集：收集高胜率对局轨迹        │
│  - 胜率阈值：≥60%                    │
│  - 质量分数：≥0.7                     │
│  - 标记关键决策点                     │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  第二阶段：全量微调                  │
│  - 解冻所有层                        │
│  - 混合原始数据+成功轨迹             │
│  - 目标：内化临时技巧                │
└─────────────────────────────────────┘
```

#### 训练配置

**第一阶段**：
- 冻结层：fc1, fc2
- 训练层：fc3, fc_strategy
- Epochs: 30
- Batch Size: 32
- Learning Rate: 0.0002（决策头专用）

**第二阶段**：
- 全量微调：所有层
- 数据混合：原始数据 + 成功轨迹
- Epochs: 50
- Batch Size: 64
- Learning Rate: 0.0001（全量微调）

#### 新增组件

1. **轨迹收集器** (`src/train/trajectory_collector.py`)
   - 收集高胜率对局轨迹
   - 计算轨迹质量分数
   - 标记关键决策点
   - 支持轨迹筛选和过滤

2. **中间奖励计算**
   - 压制成功奖励
   - 配合奖励
   - 控场奖励
   - 出牌效率奖励
   - 关键牌使用奖励

#### 实施文件

- `train_stage6_optimized.py` - 优化版训练脚本
- `src/train/trajectory_collector.py` - 轨迹收集器

## 关键技术点

### 1. 两阶段训练稳定性

**问题**：直接微调大模型容易"训崩"

**解决**：
- 第一阶段冻结主干，只训练决策头
- 第二阶段收集成功轨迹后再全量微调
- 训练曲线平稳上升，避免震荡

### 2. 稀疏奖励问题

**问题**：一局游戏只有最终胜率，奖励稀疏

**解决**：
- 设计中间奖励（压制、配合、控场等）
- 提供丰富的学习信号
- 缓解稀疏奖励问题

### 3. 探索-内化平衡

**问题**：探索不足导致策略单一，探索过度导致不稳定

**解决**：
- epsilon-greedy探索策略
- 定期内化成功经验
- 维持策略多样性

### 4. 轨迹质量评估

**问题**：如何筛选高质量轨迹

**解决**：
- 多维度轨迹质量分数
- 关键决策点标记
- 胜率和轨迹长度综合考虑
