# 快速开始训练模型

## 前置条件

1. **安装依赖**：
```bash
pip install torch numpy gymnasium
```

2. **准备训练数据**：
   - 将游戏对局记录保存到 `game_records/` 目录
   - 格式：JSON文件

3. **创建模型目录**：
```bash
mkdir -p models
```

## 训练步骤

### 步骤1：预训练（Behavior Cloning）

从人类对局数据中学习基础策略：

## 关键修复说明

### 1. 状态编码统一

**问题**：训练和推理使用不同的编码方式

**修复**：
- 所有地方统一使用 `suit * 15 + rank` 编码（0-59范围）
- 预训练代码已修复
- 环境状态编码已实现
- 推理代码保持不变

### 2. 动作空间统一

**问题**：模型定义中action_dim不一致

**修复**：
- 所有地方统一使用512维动作空间
- 模型输出512维向量
- 环境动作空间改为512维

### 3. 模型维度统一

**修复**：
- `GuandanPolicyNet`: output_dim=512（默认）
- `PPOAgent`: action_dim=512（默认）
- 所有训练脚本已更新

## 训练参数建议

### 预训练参数

```python
epochs = 10          # 增加到10轮（如果数据量大）
batch_size = 64     # 可以增加到64
lr = 0.001          # 可以尝试0.0005
```

### 强化学习参数

```python
max_episodes = 1000     # 增加到1000局（需要更长时间）
max_timesteps = 500     # 增加到500步
update_timestep = 1000  # 调整更新频率
```

### PPO参数

```python
lr = 0.0003         # 可以尝试0.0001（更稳定）
gamma = 0.99        # 保持不变
eps_clip = 0.2      # 保持不变
K_epochs = 4        # 可以增加到8
```

## 常见问题

### Q1: 训练时出现编码错误

**解决**：确保所有文件使用相同的编码函数

### Q2: 模型输出维度不匹配

**解决**：检查模型定义中的output_dim是否为512

### Q3: 训练速度慢

**解决**：
- 使用GPU（如果可用）
- 减少batch_size
- 减少训练数据量（用于测试）
