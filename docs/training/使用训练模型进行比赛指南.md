## 📊 模型在决策中的作用

### 决策权重

yf2_v5使用混合决策系统：

| 决策源 | 权重 | 说明 |
|--------|------|------|
| **规则引擎** | **60%** | 基于规则和策略的决策 |
| **RL引擎** | **15%** | **使用训练好的模型** |
| **知识库** | **25%** | 基于历史对局数据 |

### 决策流程

```
1. 规则引擎决策 → 评分 × 0.6
2. RL引擎决策（使用bc_model_v1.pth） → 评分 × 0.15
3. 知识库决策 → 评分 × 0.25
4. 融合所有决策 → 选择最高分的动作
```

## 🔍 如何验证模型是否生效

### 方法1：查看日志

启动yf2_v5后，查看日志文件（`logs/yf2_v5_*.log`）：

```
[INFO] ✓ RL Engine initialized
[INFO] RL Engine loaded model from models/bc_model_v1.pth
[RL Debug] Hand cards (27): ['H2', 'C2', 'D2', ...]
[RL Debug] Model selected 2 indices: [15, 34]
[RL Debug] Desired cards: ['H3', 'DJ']
```

如果看到 `[RL Debug]` 开头的日志，说明RL引擎正在工作。

### 方法2：观察决策统计

在日志中查找统计信息：

```
[INFO] Decision Statistics:
[INFO]   - RL decisions: 45
[INFO]   - Knowledge decisions: 78
[INFO]   - Strategy decisions: 120
```

如果 `RL decisions` 大于0，说明RL引擎参与了决策。

## ⚙️ 调整模型权重（可选）

### 如果模型效果很好

可以增加RL权重，让模型发挥更大作用：

**修改文件**: `src/communication/yf2_v5.py`

```python
# 修改前
self.rl_weight = 0.15  # RL决策权重（15%）
self.knowledge_weight = 0.25  # 知识库权重（25%）
self.rule_weight = 0.6  # 规则引擎权重（60%）

# 修改后（增加RL权重）
self.rl_weight = 0.3  # RL决策权重（30%）
self.knowledge_weight = 0.2  # 知识库权重（20%）
self.rule_weight = 0.5  # 规则引擎权重（50%）
```

**注意**：权重总和应该等于1.0

### 如果模型效果不好

可以降低RL权重或暂时禁用：

```python
self.rl_weight = 0.05  # 降低到5%
# 或者
self.rl_available = False  # 暂时禁用RL引擎
```

## 🎯 总结

### 关系说明

1. **训练模型** (`bc_model_v1.pth`) = RL引擎的神经网络模型
2. **RL引擎** = yf2_v5的决策组件之一（权重15%）
3. **yf2_v5** = 混合决策系统（规则60% + RL15% + 知识库25%）

### 使用流程

1. ✅ **训练模型** → `models/bc_model_v1.pth`
2. ✅ **RL引擎已配置** → 默认使用 `bc_model_v1.pth`
3. ✅ **启动比赛** → `START_V5_GUI.bat`
4. ✅ **模型自动生效** → 在决策中发挥作用（15%权重）

### 重要提示

- **训练好的模型不会完全替代规则引擎**，而是作为决策的一部分
- **如果模型效果很好**，可以增加RL权重到30%或更高
- **如果模型效果不好**，可以降低RL权重或暂时禁用
