# 批量转换.rep文件指南

## 概述

批量转换脚本用于将平台目录中的大量.rep文件转换为训练数据格式。

## 功能特点

- ✅ **批量转换**：自动处理大量.rep文件
- ✅ **进度显示**：实时显示转换进度和速度
- ✅ **错误处理**：自动跳过失败的文件，继续转换
- ✅ **跳过已转换**：自动跳过已转换的文件，节省时间
- ✅ **优先选择获胜玩家**：自动识别并提取获胜玩家的数据
- ✅ **日志记录**：详细记录转换过程到 `batch_convert.log`

## 使用方法

### 方法1：使用批处理文件（推荐）

#### 转换前1000个文件（推荐）

```bash
batch_convert_replays.bat 1000
```

#### 转换所有文件

```bash
batch_convert_replays.bat
```

### 方法2：使用Python脚本

#### 转换前1000个文件

```bash
python src/knowledge_processor/batch_convert_replays.py --max_files 1000
```

#### 转换所有文件

```bash
python src/knowledge_processor/batch_convert_replays.py
```

#### 自定义参数

```bash
python src/knowledge_processor/batch_convert_replays.py \
    --rep_dir "C:\Program Files (x86)\gdgame\MobileGD\replay" \
    --output_dir "game_records" \
    --max_files 1000 \
    --prefer_winner \
    --skip-existing
```

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--rep_dir` | .rep文件目录 | `C:\Program Files (x86)\gdgame\MobileGD\replay` |
| `--output_dir` | 输出目录 | `game_records` |
| `--max_files` | 最大转换文件数 | `None`（全部） |
| `--prefer_winner` | 优先选择获胜玩家 | `True` |
| `--skip-existing` | 跳过已转换的文件 | `True` |

## 转换过程

### 1. 查找文件

脚本会自动查找指定目录及其子目录中的所有.rep文件。

### 2. 检查已转换

如果启用 `--skip-existing`，脚本会检查文件是否已转换，跳过已转换的文件。

### 3. 转换文件

对每个.rep文件：
1. 解析XML格式
2. 识别获胜玩家（如果启用 `--prefer_winner`）
3. 提取训练数据
4. 转换为ReplayParser格式
5. 保存为JSON文件

### 4. 进度显示

每转换100个文件，会显示：
- 当前进度
- 已转换样本数
- 转换速度
- 预计剩余时间

### 5. 转换总结

转换完成后，显示：
- 总文件数
- 成功转换数
- 跳过文件数
- 失败文件数
- 总训练样本数
- 总耗时
- 平均速度

## 注意事项

### 1. 转换时间

- **1000个文件**：约5-10分钟
- **10000个文件**：约1-2小时
- 转换速度取决于文件大小和系统性能

### 2. 存储空间

- 每个对局约生成1-4个JSON文件（取决于玩家数）
- 1000个对局约需要50-100MB空间
- 10000个对局约需要500MB-1GB空间

### 3. 建议分批转换

- 先转换1000个文件测试
- 检查转换结果
- 再转换剩余文件

### 4. 错误处理

- 脚本会自动跳过失败的文件
- 错误信息记录在 `batch_convert.log`
- 可以查看日志了解失败原因

## 故障排除

### 问题1：转换速度慢

**解决**：
- 减少 `--max_files` 数量
- 关闭其他占用资源的程序
- 使用SSD硬盘

### 问题2：内存不足

**解决**：
- 分批转换（每次1000个）
- 增加系统内存
- 关闭其他程序

### 问题3：文件已存在

**解决**：
- 使用 `--skip-existing` 跳过已转换的文件
- 或使用 `--no-skip-existing` 强制重新转换

### 问题4：找不到.rep文件

**解决**：
- 检查 `--rep_dir` 路径是否正确
- 确认.rep文件确实存在
- 检查文件权限

## 转换后检查

转换完成后，检查数据：


或检查1000个对局目标：

```bash
python src/train/check_1000_games.py
```

## 总结

批量转换脚本提供了便捷的方式来处理大量.rep文件：

- ✅ **简单易用**：一条命令即可批量转换
- ✅ **智能处理**：自动识别获胜玩家，跳过已转换文件
- ✅ **进度可视**：实时显示转换进度和速度
- ✅ **错误容错**：自动处理错误，继续转换

建议先转换1000个文件测试，确认无误后再转换全部文件。
