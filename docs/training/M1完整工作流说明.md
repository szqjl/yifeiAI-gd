# M1完整训练工作流说明

## 🎯 唯一目标
**M1战胜client（胜率 > 50%）**

## 🚀 完整工作流功能

### 1. 自动运行M1与client对战
- 自动检查游戏记录数量
- 如果记录不足，自动运行M1客户端与client对战
- 生成足够的游戏记录用于评估

### 2. 训练模型（MLflow实时监控）
- 使用Stage7优化训练框架
- MLflow实时监控训练指标
- 自动保存最佳模型

### 3. 从MLflow读取实时指标
- 自动从MLflow Tracking Server读取训练指标
- 分析预测比例、损失趋势、预测质量等
- 识别训练问题（预测过度、损失不收敛等）

### 4. 根据MLflow指标自动优化训练代码
- 根据实时指标分析结果
- 自动调整训练代码中的参数：
  - `over_prediction_penalty` - 过度预测惩罚
  - `loss_alpha` - 正样本权重
  - `sparsity_reward` - 稀疏性奖励
  - `learning_rate` - 学习率
- 自动备份原代码，确保可回滚

### 5. 评估M1 vs Client胜率
- 自动评估训练后模型的胜率
- 如果记录不足，自动运行对战生成记录
- 分析决策质量

### 6. 迭代训练直到胜率 > 50%
- 如果胜率未达标，根据分析结果优化参数
- 重新训练，重复上述步骤
- 直到胜率 ≥ 50% 自动停止

## 📋 工作流程

```
开始
  ↓
[步骤0] 检查/生成游戏记录
  ├─ 记录不足 → 自动运行M1与client对战
  └─ 记录足够 → 继续
  ↓
[步骤1] 训练模型（MLflow实时监控）
  ├─ 启动训练
  ├─ MLflow记录指标
  └─ 保存最佳模型
  ↓
[步骤1.5] 从MLflow读取实时指标
  ├─ 读取训练指标
  ├─ 分析训练进度
  └─ 识别问题
  ↓
[步骤2] 分析训练结果
  ├─ 分析训练历史
  └─ 生成优化建议
  ↓
[步骤3] 评估M1 vs Client胜率
  ├─ 评估胜率
  ├─ 如果记录不足 → 自动运行对战
  └─ 分析决策质量
  ↓
[步骤4] 检查目标
  ├─ 胜率 ≥ 50% → ✅ 成功，停止
  └─ 胜率 < 50% → 继续
  ↓
[步骤5] 优化参数和代码
  ├─ 根据MLflow指标优化代码
  ├─ 根据训练分析优化参数
  └─ 准备下一轮训练
  ↓
[迭代] 重复步骤0-5
  ↓
结束（达到目标或最大迭代次数）
```

## 📊 MLflow实时监控

### 启动MLflow UI

工作流运行期间，在新终端运行：

```bash
mlflow ui --backend-store-uri file:///d:/YiFeiAI-GD/logs/mlruns
```

然后在浏览器打开：**http://localhost:5000**

### 查看的指标

1. **Loss指标**:
   - `loss/total` - 总损失
   - `loss/action` - 动作损失
   - `loss/strategy` - 策略损失
   - `loss/threshold` - 阈值损失

2. **预测指标**:
   - `metrics/predicted_cards` - 预测卡牌数
   - `metrics/true_cards` - 真实卡牌数
   - `metrics/prediction_ratio` - 预测比例

3. **质量指标**:
   - `quality/prediction_quality_score` - 预测质量分数
   - `best/combined_score` - 综合分数

### 自动优化触发条件

工作流会根据MLflow指标自动优化代码：

1. **预测过度**（预测比例 > 2.0）:
   - 自动增加 `over_prediction_penalty` (x1.5)
   - 自动降低 `loss_alpha` (x0.8)

2. **预测不足**（预测比例 < 0.5）:
   - 自动降低 `over_prediction_penalty` (x0.7)
   - 自动增加 `loss_alpha` (x1.2)

3. **损失上升**:
   - 自动降低 `learning_rate` (x0.5)

4. **预测质量低**（质量分数 < 0.3）:
   - 自动增加 `sparsity_reward` (x1.5)

## 🔄 自动代码优化

### 优化机制

工作流会自动修改 `src/train/stage7_optimized_training.py` 中的参数：

- 自动备份原代码到 `.py.backup`
- 根据MLflow分析结果调整参数值
- 保存优化后的代码

### 代码备份

每次优化前会自动备份：
```
src/train/stage7_optimized_training.py.backup
```

如果需要回滚：
```bash
cp src/train/stage7_optimized_training.py.backup src/train/stage7_optimized_training.py
```

## ⚠️ 注意事项

### 1. 游戏服务器路径
如果未自动找到服务器，需要手动指定：
```bash
python src/train/m1_training_workflow.py --server_path "D:/guandan_offline_v1006/windows/guandan_offline_v1006.exe"
```

### 2. 训练时间
- 每次迭代训练：10-30分钟（取决于数据量和硬件）
- 自动对战：每50局约5-10分钟
- 完整工作流：可能需要数小时

### 3. 资源消耗
- CPU/GPU：训练期间会占用
- 磁盘空间：模型文件、游戏记录、MLflow数据
- 内存：根据批次大小调整

### 4. MLflow UI
建议在工作流运行期间保持MLflow UI打开，实时查看训练指标

## 🎯 成功标准

工作流在以下情况停止：

1. **✅ 成功**: 胜率 ≥ 目标胜率（默认50%）
2. **⚠️ 未达标**: 达到最大迭代次数但未达标
3. **❌ 失败**: 某次迭代训练失败
