### 1. 策略模式识别架构
```python
class StrategyPatternRecognizer(nn.Module):
    def __init__(self, input_dim=512, pattern_types=8):
        super().__init__()
        self.pattern_encoder = nn.Sequential(
            nn.Linear(input_dim, 256),
            nn.LayerNorm(256),
            nn.ReLU(),
            nn.Dropout(0.1)
        )
        self.pattern_classifier = nn.Linear(256, pattern_types)

    def forward(self, state_features):
        pattern_features = self.pattern_encoder(state_features)
        pattern_logits = self.pattern_classifier(pattern_features)
        return pattern_logits
```

### 2. 对手建模系统
```python
class OpponentModel(nn.Module):
    def __init__(self, state_dim=512, action_dim=512, opponent_types=5):
        super().__init__()
        self.opponent_encoder = nn.Sequential(
            nn.Linear(state_dim + action_dim, 256),
            nn.LayerNorm(256),
            nn.ReLU(),
            nn.Dropout(0.1)
        )
        self.opponent_classifier = nn.Linear(256, opponent_types)
        self.opponent_predictor = nn.Linear(256, action_dim)

    def forward(self, state, opponent_history):
        combined_input = torch.cat([state, opponent_history], dim=-1)
        opponent_features = self.opponent_encoder(combined_input)
        opponent_type = self.opponent_classifier(opponent_features)
        predicted_action = self.opponent_predictor(opponent_features)
        return opponent_type, predicted_action
```

### 3. 动态策略调整器
```python
class DynamicStrategyAdjuster(nn.Module):
    def __init__(self, strategy_count=7):
        super().__init__()
        self.situation_encoder = nn.Sequential(
            nn.Linear(512, 128),
            nn.LayerNorm(128),
            nn.ReLU(),
            nn.Dropout(0.1)
        )
        self.strategy_weights = nn.Linear(128, strategy_count)
        self.strategy_switcher = nn.Linear(128, strategy_count)

    def forward(self, game_state, current_strategy):
        situation_features = self.situation_encoder(game_state)
        strategy_weights = F.softmax(self.strategy_weights(situation_features), dim=-1)
        switch_logits = self.strategy_switcher(situation_features)
        return strategy_weights, switch_logits
```

**核心参数**:

| **dropout_rate** | 0.1 | 平衡过拟合和输出概率 | 历次训练效果汇总 |
| **model_path** | `models/bc_model_stage5_final.pth` | 阶段5模型保存路径 | 阶段5集成要求 |

**学习率调度**:
- **调度器**: `CosineAnnealingLR`（阶段0方案I-1修复）
- **T_max**: epochs（训练总轮数）
- **eta_min**: 1e-6（最小学习率）
- **预期效果**: 稳定收敛，避免学习率过早降到0，训练后期更稳定
- **注意**: 代码中实际使用的是CosineAnnealingLR，而非StepLR（基于阶段0方案I-1修复）

**损失函数**:
- **类型**: 加权BCE (`BCEWithLogitsLoss`)
- **pos_weight**: 2.0（惩罚预测过少）
- **预期效果**: 鼓励模型积极预测，减少预测过少问题

#### 2.2 阶段5特有参数

**多任务学习配置**:
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **enable_strategy_head** | `True` | 启用策略分类头（阶段2功能） |
| **action_loss_weight** | 1.5 | 动作预测损失权重（主要任务） |
| **strategy_loss_weight** | 0.3 | 策略分类损失权重（辅助任务） |
| **enable_strategy_pattern** | `True` | 启用策略模式识别（阶段5新增） |
| **strategy_pattern_weight** | 0.2 | 策略模式识别损失权重 |
| **enable_opponent_modeling** | `True` | 启用对手建模（阶段5新增） |
| **opponent_model_weight** | 0.15 | 对手建模损失权重 |
| **enable_dynamic_strategy** | `True` | 启用动态策略调整（阶段5新增） |
| **dynamic_strategy_weight** | 0.1 | 动态策略调整损失权重 |

**模型架构参数**:
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **use_improved_model** | `True` | 使用阶段4改进模型（注意力机制+残差连接） |
| **attention_heads** | 8 | 多头注意力头数（阶段4优化） |
| **input_dim** | 512 | 状态空间维度 |
| **hidden_dim** | 256 | 隐藏层维度（阶段3优化后回退） |
| **output_dim** | 512 | 动作空间维度 |

**损失权重平衡说明**:
```
总损失 = action_loss_weight × 动作预测损失
      + strategy_loss_weight × 策略分类损失
      + strategy_pattern_weight × 策略模式识别损失
      + opponent_model_weight × 对手建模损失
      + dynamic_strategy_weight × 动态策略调整损失

权重分配原则:
- 动作预测是主要任务，权重最高(1.5)
- 策略分类是核心辅助任务，权重中等(0.3)
- 阶段5新增任务权重较低(0.2, 0.15, 0.1)，避免干扰主任务
```

#### 5.3 问题排查

**问题1: 训练损失不下降**

**可能原因**:
- 学习率过大或过小
- 数据质量问题
- 模型架构问题

**排查步骤**:
1. 检查学习率是否合理（0.0001-0.0005范围）
2. 检查数据加载是否正常（数据量、格式）
3. 检查模型初始化是否正常（权重是否合理）
4. 尝试降低学习率重新训练

**问题2: 策略理解率未达到目标**

**可能原因**:
- 策略相关任务权重过低
- 训练数据中策略标签不足
- 模型容量不足

**排查步骤**:
1. 检查策略标签数据质量
2. 增加策略相关任务权重
3. 检查模型是否使用了阶段4改进架构（注意力机制）
4. 尝试增加训练轮数

**问题3: 完全匹配准确率下降**

**可能原因**:
- 阶段5任务干扰主任务
- 损失权重不平衡
- 训练数据变化

**排查步骤**:
1. 降低阶段5任务权重
2. 增加动作预测任务权重
3. 检查数据是否与阶段4一致
4. 对比阶段4和阶段5的训练日志

**问题4: 模型文件无法加载**

**可能原因**:
- 模型架构不匹配
- 文件损坏
- 路径错误

**排查步骤**:
1. 检查模型文件是否存在且完整
2. 验证模型架构是否与训练时一致
3. 检查PyTorch版本兼容性
4. 尝试使用 `strict=False` 加载
