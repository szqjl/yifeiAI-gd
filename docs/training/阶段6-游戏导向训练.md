## 🔧 技术实现要点

### 评估框架设计
```python
class GameOrientedEvaluator:
    def __init__(self):
        self.win_rate_weight = 0.5
        self.strategy_weight = 0.2
        self.decision_weight = 0.2
        self.prediction_weight = 0.1

    def evaluate_model(self, model, game_records):
        """计算综合评估分数"""
        win_rate = self._calculate_win_rate(game_records)
        strategy_effectiveness = self._analyze_strategy_effectiveness(game_records)
        decision_quality = self._assess_decision_quality(game_records)
        prediction_accuracy = self._measure_prediction_accuracy(game_records)

        total_score = (win_rate * self.win_rate_weight +
                      strategy_effectiveness * self.strategy_weight +
                      decision_quality * self.decision_weight +
                      prediction_accuracy * self.prediction_weight)

        return total_score
```

### 胜率导向损失函数
```python
class GameOrientedLoss(nn.Module):
    def __init__(self):
        super().__init__()
        self.action_loss = ActionPredictionLoss()
        self.strategy_loss = StrategyClassificationLoss()
        self.win_rate_loss = WinRatePredictionLoss()

        # 动态权重调整
        self.action_weight = nn.Parameter(torch.tensor(1.0))
        self.strategy_weight = nn.Parameter(torch.tensor(0.3))
        self.win_weight = nn.Parameter(torch.tensor(2.0))

    def forward(self, predictions, targets, game_results):
        action_loss = self.action_loss(predictions['actions'], targets['actions'])
        strategy_loss = self.strategy_loss(predictions['strategy'], targets['strategy'])
        win_loss = self.win_rate_loss(predictions['win_prob'], game_results['win'])

        total_loss = (self.action_weight * action_loss +
                     self.strategy_weight * strategy_loss +
                     self.win_weight * win_loss)

        return total_loss
```

## 🚀 2025-12-15 重大突破：策略原因学习 + 胜率导向损失

### 核心问题发现
通过分析游戏对局，发现当前训练存在根本性问题：
- **行为克隆的局限性**：只能学习"看到X牌型，出Y动作"，无法理解"为什么在某种局面下该出某种牌"
- **策略原因未被学习**：虽然提取了策略原因（`strategy_reason`），但没有用于训练损失函数
- **缺乏泛化能力**：掼蛋千变万化，极少出现完全一样的牌型，需要学习策略原理才能泛化

### 实现方案

#### 1. 策略原因学习任务（任务7）
**目标**：让AI学习"为什么这样选择"，而不仅仅是"选择什么"

**实现细节**：
- **模型架构**：在`ImprovedGuandanPolicyNet`中添加策略原因预测头（26类原因类型）
  - 原因类型包括：`bomb_urgent`, `bomb_endgame`, `suppress_urgent`, `protect_teammate_urgent`, `control_urgent`, `group_reduce_hands`, `follow_counter`, `discard_endgame`等
- **数据提取**：在`GuandanDataset.__getitem__`中提取策略原因标签
  - 从`state_dict['strategy_reason']['reason_type']`中提取原因类型
  - 映射到0-25的标签（25表示unknown）
- **损失计算**：在训练循环中添加策略原因学习损失
  - 使用交叉熵损失，忽略unknown类别（索引25）
  - 权重：平均每个任务约0.071（7个任务）

**代码位置**：
- `src/rl_agent/model.py`: 添加`reason_processor`和`reason_head`
- `src/train/pretrain.py`: 添加策略原因标签提取和损失计算

#### 2. 胜率导向损失函数
**目标**：让AI学习"什么有效"，而不仅仅是"模仿行为"

**实现细节**：
- **基于策略有效性的权重调整**：
  - 策略有效性越高，学习权重越大（归一化到[0.5, 2.0]范围）
  - 鼓励模型优先学习有效的策略模式
- **损失函数设计**：
  ```python
  # 策略有效性权重
  effectiveness_weights = 0.5 + 1.5 * strategy_effectiveness
  # 加权损失
  weighted_action_loss = action_loss * effectiveness_weights.mean()
  weighted_strategy_loss = strategy_loss * effectiveness_weights.mean()
  # 胜率导向损失
  win_rate_oriented_loss = (weighted_action_loss + weighted_strategy_loss) * 0.3
  ```
- **权重设置**：胜率导向损失权重为0.3

**代码位置**：
- `src/train/pretrain.py`: 在损失计算中添加`win_rate_oriented_loss`

### 预期效果

通过这些改进，AI将能够：
1. **理解策略原理**：通过策略原因学习任务，理解"为什么在某种局面下该出某种牌"
2. **学习有效策略**：通过胜率导向损失，优先学习有效的策略模式
3. **提高泛化能力**：理解策略原理后，能够应对新的牌型组合

## 📊 2025-12-17 测试记录：YF客户端表现弱智问题分析

### 问题现象

在V6版本实际对战中，观察到YF客户端表现明显弱智，主要表现：

1. **过度PASS**：频繁选择PASS，缺乏主动出牌
2. **决策质量差**：出牌时机不当，牌型选择不合理
3. **与client客户端对比明显**：client客户端有完整的行牌过程记录，决策更合理

### 根本原因分析

#### 1. RL模型输出无效（核心问题）

**现象**：

- 即使有数据，模型也可能学到错误的模式
- 模型输出不稳定，需要大量调试

- 规则直接来自游戏逻辑，不需要训练
- 行为可预测、可调试
- 性能稳定可靠

**当前问题**：
- RL模型输出无效（索引不在手牌中）
- 即使修复了索引映射，模型可能仍然输出不合理决策
- 需要大量回退机制和规则引擎兜底

**硬编码的优势**：

- 性能可预期
