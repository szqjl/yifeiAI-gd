# 训练监控工具替代方案

**创建时间**: 2025-01-XX  
**目的**: 介绍 wandb 的替代方案，解决无法登录的问题  
**状态**: ✅ 已完成

---

## 📋 概述

如果 wandb 无法登录或使用，本项目提供了多个替代方案：

1. **TensorBoard**（推荐）⭐ - 免费，本地，无需登录
2. **MLflow**（推荐）⭐ - 免费，开源，功能强大
3. **wandb** - 需要登录（如果可用）

---

## 🎯 TensorBoard（最推荐）

### 优点

- ✅ **完全免费**，无需登录
- ✅ **本地运行**，数据不离开你的电脑
- ✅ **PyTorch 内置支持**，无需额外配置
- ✅ **轻量级**，安装简单
- ✅ **功能完整**，支持所有常用功能

### 安装

```bash
pip install tensorboard
```

### 使用方法

#### 1. 训练时使用 TensorBoard

```python
from src.train.stage7_optimized_training import train_stage7_optimized_model

# 使用 TensorBoard（默认）
model, history = train_stage7_optimized_model(
    epochs=100,
    batch_size=32,
    learning_rate=0.00005,
    monitor_backend="tensorboard",  # 使用 TensorBoard
    monitor_project="yifei-ai-gd",
    monitor_name="stage7_experiment_1"
)
```

#### 2. 启动 TensorBoard 查看

训练开始后，在**新终端**运行：

```bash
# 查看 TensorBoard
tensorboard --logdir logs/tensorboard

# 或者指定端口
tensorboard --logdir logs/tensorboard --port 6006
```

然后在浏览器打开：**http://localhost:6006**

#### 3. 查看的内容

- 📊 **损失曲线**: 总损失、动作损失、策略损失等
- 📈 **训练指标**: 预测卡牌数、真实卡牌数、预测比例等
- 📉 **学习率变化**: 学习率调度曲线
- 📋 **配置信息**: 所有超参数

### 示例截图说明

TensorBoard 界面包含：
- **SCALARS**: 所有数值指标的时间序列图
- **GRAPHS**: 模型结构图（如果记录）
- **HISTOGRAMS**: 权重分布（如果记录）

## 🔬 MLflow（功能强大）

### 优点

- ✅ **完全免费**，开源
- ✅ **本地运行**，数据存储在本地
- ✅ **实验管理**，支持多实验对比
- ✅ **模型版本管理**，自动记录模型
- ✅ **Web UI**，友好的可视化界面

### 安装

```bash
pip install mlflow
```

### 使用方法

#### 1. 训练时使用 MLflow

```python
from src.train.stage7_optimized_training import train_stage7_optimized_model

# 使用 MLflow
model, history = train_stage7_optimized_model(
    epochs=100,
    batch_size=32,
    learning_rate=0.00005,
    monitor_backend="mlflow",  # 使用 MLflow
    monitor_project="yifei-ai-gd",
    monitor_name="stage7_experiment_1"
)
```

#### 2. 启动 MLflow UI

训练开始后，在**新终端**运行：

```bash

mlflow ui

# 或者指定端口和存储路径
mlflow ui --port 5000 --backend-store-uri file:///path/to/logs/mlruns
```

然后在浏览器打开：**http://localhost:5000**

#### 3. MLflow 功能

- 📊 **实验对比**: 对比多个训练运行
- 📦 **模型注册**: 自动记录和版本管理模型
- 📈 **指标可视化**: 交互式图表
- 🔍 **参数搜索**: 查看超参数影响
- 📝 **运行详情**: 查看每次运行的详细信息

## 🔄 切换监控工具

### 方法1: 修改训练脚本参数

```python
# TensorBoard（推荐，最简单）
monitor_backend="tensorboard"

# MLflow（功能强大）
monitor_backend="mlflow"

# wandb（如果可用）
monitor_backend="wandb"

# 不使用监控
monitor_backend="none"
```

### 方法2: 使用命令行参数

```bash
# 使用 TensorBoard
python src/train/stage7_optimized_training.py --monitor_backend tensorboard

# 使用 MLflow
python src/train/stage7_optimized_training.py --monitor_backend mlflow
```

## 🔧 常见问题

### Q1: TensorBoard 无法启动？

**A**: 检查端口是否被占用：

```bash
# Windows
netstat -ano | findstr :6006

# Linux/Mac
lsof -i :6006
```

更换端口：
```bash
tensorboard --logdir logs/tensorboard --port 6007
```

### Q2: MLflow UI 无法访问？

**A**: 检查防火墙设置，或使用本地地址：

```bash
mlflow ui --host 127.0.0.1 --port 5000
```

### Q3: 如何同时使用多个监控工具？

**A**: 目前不支持同时使用多个，但可以：
1. 先使用 TensorBoard 训练
2. 训练完成后，使用 MLflow 记录结果
3. 或修改代码支持多后端

### Q4: 监控数据存储在哪里？

- **TensorBoard**: `logs/tensorboard/`
- **MLflow**: `logs/mlruns/`
- **wandb**: `logs/wandb/`（本地缓存）+ 云端

## 📝 代码示例

### 使用通用监控接口

```python
from src.train.training_monitor import create_monitor

# 创建 TensorBoard 监控器
monitor = create_monitor(
    backend="tensorboard",
    project_name="my-project",
    run_name="experiment-1"
)

# 记录指标
monitor.log({
    "loss": 0.5,
    "accuracy": 0.9,
}, step=1)

# 记录配置
monitor.log_config({
    "learning_rate": 0.001,
    "batch_size": 32,
})

# 保存模型
monitor.save_model("model.pth")

# 结束
monitor.finish()
```
