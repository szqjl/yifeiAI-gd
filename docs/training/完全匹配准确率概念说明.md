# 完全匹配准确率概念说明

**创建时间**: 2025-12-08  
**目的**: 解释"完全匹配准确率"的概念和计算方法

---

## 📊 什么是完全匹配准确率？

### 基本概念

**完全匹配准确率（Exact Match Accuracy）**是指：模型预测的动作与专家动作**完全一致**的样本比例。

### 具体含义

在掼蛋AI中，一个"动作"是一个512维的向量，每个维度表示是否选择对应的卡牌索引位置：
- `1` 表示选择这张卡牌
- `0` 表示不选择这张卡牌

**完全匹配**意味着：
- ✅ 预测要出的**所有卡牌**必须和专家动作**完全一致**
- ✅ **一张不多**：不能预测专家没有出的卡牌
- ✅ **一张不少**：不能漏掉专家出的任何一张卡牌
- ✅ **位置也要对**：每张卡牌在512维向量中的位置必须正确

---

## 🔍 计算方式

### 代码实现

```python
# 1. 模型预测动作（512维向量）
action_predictions = model.get_action(state)  # shape: (batch_size, 512)

# 2. 专家真实动作（512维向量）
actions = ground_truth_actions  # shape: (batch_size, 512)

# 3. 计算完全匹配
exact_match = (action_predictions == actions).all(dim=1)
# 对于每个样本，检查所有512个维度是否都相等

# 4. 统计完全匹配的样本数
correct_predictions = exact_match.sum().item()

# 5. 计算准确率
exact_accuracy = correct_predictions / total_samples
```

### 示例说明

假设有一个样本：

**专家动作**（真实要出的卡牌）：
```
[0, 0, 1, 1, 0, 0, 0, ...]  # 第3、4张卡牌被选中（比如：红桃3、红桃4）
```

**模型预测1**（完全匹配 ✅）：
```
[0, 0, 1, 1, 0, 0, 0, ...]  # 完全一致
```
结果：**完全匹配** ✅

**模型预测2**（多预测了一张 ❌）：
```
[0, 0, 1, 1, 1, 0, 0, ...]  # 多选了第5张卡牌
```
结果：**不完全匹配** ❌（多了一张）

**模型预测3**（少预测了一张 ❌）：
```
[0, 0, 1, 0, 0, 0, 0, ...]  # 少选了第4张卡牌
```
结果：**不完全匹配** ❌（少了一张）

**模型预测4**（预测了不同的卡牌 ❌）：
```
[0, 1, 0, 1, 0, 0, 0, ...]  # 选了第2、4张，而不是第3、4张
```
结果：**不完全匹配** ❌（卡牌不同）

## 📈 与其他指标的区别

### 1. 完全匹配准确率 vs 卡牌级别准确率

| 指标 | 计算方式 | 含义 | 示例 |
|------|---------|------|------|
| **完全匹配准确率** | `(predictions == actions).all(dim=1)` | 预测的动作必须**完全一致** | 0.01% |
| **卡牌级别准确率** | `(predictions == actions).sum() / total_cards` | 预测的**每张卡牌**是否正确 | 99.13% |

**区别**：
- **完全匹配**：要求所有卡牌都正确，且不能多不能少
- **卡牌级别**：只关心每张卡牌是否正确，不要求完全一致

**示例**：
- 专家动作：选择第3、4、5张卡牌
- 模型预测：选择第3、4、6张卡牌
  - 卡牌级别准确率：2/3 = 66.7%（第3、4张正确，第6张错误）
  - 完全匹配准确率：0%（因为第6张错误，且缺少第5张）

### 2. 为什么完全匹配准确率这么低？

**当前问题**：
- 完全匹配准确率：0.01%（33,023样本）或 0.36%（796样本）
- 卡牌级别准确率：99.13%（优秀）

**原因分析**：
1. **预测过多**：模型平均预测10.30张卡牌，真实平均3.33张
   - 即使大部分卡牌预测正确，但多预测的卡牌导致不完全匹配
   
2. **预测过少**：模型可能漏掉一些卡牌
   - 即使预测的卡牌都正确，但缺少的卡牌导致不完全匹配

3. **卡牌组合错误**：预测的卡牌集合与真实动作不同
   - 例如：真实是"对子3"，预测是"单张3+单张4"

## 🎯 为什么完全匹配准确率很重要？

### 1. 实际应用意义

在掼蛋游戏中，AI必须：
- ✅ 准确预测要出的**所有卡牌**
- ✅ 不能多出牌（违反规则）
- ✅ 不能少出牌（策略不完整）

**完全匹配准确率低意味着**：
- AI可能预测了错误的卡牌组合
- AI可能多预测或少预测了卡牌
- 在实际对局中，AI可能做出不合法的动作

### 2. 策略理解率的基础

**策略理解率** = (动作预测正确 AND 策略分类正确) / 总样本数

如果完全匹配准确率为0.01%，那么：
- 即使策略分类准确率100%
- 策略理解率也只能是0.01%（因为动作预测几乎都错误）

**因此**：要提高策略理解率，必须先提高完全匹配准确率。

## 🔧 如何提高完全匹配准确率？

### 阶段3的改进方向

1. **调整损失函数权重**
   - 增加动作预测损失权重（α=1.5-2.0）
   - 减少策略分类损失权重（β=0.1-0.3）
   - 让模型更关注动作预测精度

2. **优化模型架构**
   - 增加模型容量
   - 改进特征提取
   - 提高动作预测精度

3. **优化训练方法**
   - 分阶段训练
   - 课程学习
   - 任务权重自适应调整

4. **调整推理参数**
   - 优化概率缩放因子（当前3.0）
   - 优化预测阈值（当前0.8）
   - 减少预测过多问题

## 📝 总结

**完全匹配准确率**是衡量AI动作预测精度的**最严格指标**：
- ✅ 要求预测的动作与专家动作**完全一致**
- ✅ 不能多一张，不能少一张，位置也要对
- ✅ 是策略理解率的基础
- ✅ 直接影响AI在实际对局中的表现

**当前问题**：
- 完全匹配准确率极低（0.01-0.36%）
- 主要原因是预测过多（平均10.30张 vs 真实3.33张）
- 需要阶段3重点解决
