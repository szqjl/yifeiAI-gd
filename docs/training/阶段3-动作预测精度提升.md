## 📋 问题分析

### 当前问题

根据快速验证结果（2025-12-08）：

| 指标 | 796样本训练 | 33,023样本训练 | 目标 | 差距 |
|------|------------|---------------|------|------|
| **完全匹配准确率** | 0.36% | 0.01% | >30% | ❌ 严重不足 |
| **策略理解率** | 0.36% | 0.00% | >50% | ❌ 严重不足 |
| **策略分类准确率** | 99.96% | 100.00% | >70% | ✅ 已达成 |
| **卡牌级别准确率** | 99.24% | 99.13% | >95% | ✅ 已达成 |

### 根本原因分析

1. **完全匹配准确率过低（0.01-0.36%）**
   - **问题**：模型预测的卡牌组合与真实动作完全匹配的概率极低
   - **可能原因**：
     * 损失函数权重不平衡（策略分类权重过高，动作预测权重过低）
     * 模型输出概率分布不合理（预测过多或过少）
     * 多任务学习导致动作预测精度下降
     * 模型容量不足或架构问题

2. **策略理解率为0（0.00-0.36%）**
   - **问题**：策略理解率 = (动作预测正确 AND 策略分类正确) / 总样本数
   - **根本原因**：由于完全匹配准确率过低，导致策略理解率也为0
   - **解决方向**：必须先解决完全匹配准确率问题

### 验证结论

**快速验证结果**（796样本 vs 33,023样本）：
- 796样本上完全匹配准确率0.36%，比33,023样本的0.01%提升了36倍
- 但即使使用796样本，准确率仍然很低（<5%）
- **结论**：主要是**模型或训练方法问题**，数据量有一定影响但不是决定性的

## 📋 任务清单

### 任务1：调整损失函数权重（第1周）

**目标**：增加动作预测损失权重，减少策略分类损失权重，提高动作预测精度

**依据**：当前配置（α=1.0, β=0.5）可能过于偏向策略分类，导致动作预测精度下降

**步骤**：
1. **分析当前损失权重**
   - 当前配置：action_loss_weight=1.0, strategy_loss_weight=0.5
   - 总损失 = 1.0 * action_loss + 0.5 * strategy_loss
   - 策略分类损失占比：0.5 / (1.0 + 0.5) = 33.3%

2. **设计新的损失权重**
   - 方案1：action_loss_weight=1.5, strategy_loss_weight=0.3
     - 总损失 = 1.5 * action_loss + 0.3 * strategy_loss
     - 策略分类损失占比：0.3 / (1.5 + 0.3) = 16.7%
   - 方案2：action_loss_weight=2.0, strategy_loss_weight=0.2
     - 总损失 = 2.0 * action_loss + 0.2 * strategy_loss
     - 策略分类损失占比：0.2 / (2.0 + 0.2) = 9.1%
   - 方案3：action_loss_weight=1.0, strategy_loss_weight=0.1
     - 总损失 = 1.0 * action_loss + 0.1 * strategy_loss
     - 策略分类损失占比：0.1 / (1.0 + 0.1) = 9.1%

3. **修改训练代码**
   - 文件：`src/train/pretrain.py`
   - 修改`train_bc`函数的默认参数
   - 添加损失权重测试功能

4. **测试不同权重组合**
   - 使用796样本快速测试（10 epochs）
   - 评估完全匹配准确率和策略理解率
   - 选择最优权重组合

**测试标准**：
- ✅ 完全匹配准确率 > 5%（快速测试目标）
- ✅ 策略分类准确率 > 80%（不能下降太多）

## 🔄 回退方案

### 如果完全匹配准确率仍然很低（<10%）

1. **进一步增加动作预测损失权重**
   - action_loss_weight=3.0, strategy_loss_weight=0.1
   - 或完全禁用策略分类任务，只训练动作预测

2. **简化模型架构**
   - 移除策略分类头，只保留动作预测
   - 或使用更简单的架构

3. **使用更小的数据集**
   - 使用796样本训练，避免数据量过大导致的问题

### 如果策略分类准确率大幅下降（<70%）

1. **调整损失权重**
   - 增加策略分类损失权重
   - 或使用任务权重自适应调整

2. **分阶段训练**
   - 先训练动作预测，再训练策略分类
   - 或使用不同的学习率

### 如果训练不稳定

1. **降低学习率**
   - 从0.0003降低到0.0001
   - 或使用更小的批次大小

2. **增加正则化**
   - 增加dropout率（0.1 → 0.2）
   - 或添加权重衰减
