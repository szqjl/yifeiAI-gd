## 🔧 问题根源

### 1. 模型输出概率偏低

**现象**: 平均概率只有0.0017，远低于正常值（0.3-0.5）

**可能原因**:
1. **训练过度**: 模型可能训练过度，导致输出概率值被压缩
2. **Dropout影响**: 虽然推理时应该关闭Dropout，但可能没有正确设置
3. **损失函数**: BCEWithLogitsLoss可能导致模型输出概率偏低
4. **学习率衰减**: 学习率衰减过快，导致模型过早收敛

### 2. 预测过少问题

**现象**: 97.1%的样本预测不足，平均少2.27张卡牌

**分析**:
- 即使阈值降低到0.3，仍然预测过少
- 模型输出概率值整体偏低
- 需要进一步降低阈值或调整模型输出

## 💡 解决方案

### 方案1：进一步降低预测阈值（临时方案）

**当前**: 0.3  
**建议**: **0.1**或**0.05**

**优点**: 快速解决预测过少问题  
**缺点**: 可能预测过多，准确率可能下降

### 方案2：调整模型输出（根本方案）

**方法1**: 在推理时对输出概率进行缩放

```python
probs = torch.sigmoid(logits)
# 缩放概率值，使其更接近训练时的分布
probs = probs * 2.0  # 或使用其他缩放因子
probs = torch.clamp(probs, 0, 1)
```

**方法2**: 使用温度缩放

```python
probs = torch.sigmoid(logits / temperature)  # temperature > 1 增加概率值
```

### 方案3：重新训练（长期方案）

**调整训练参数**:
1. **减少训练轮数**: 50轮 → 30轮（避免过拟合）

3. **调整损失函数**: 使用加权损失，增加对预测过少的惩罚
