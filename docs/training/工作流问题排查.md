# M1工作流问题排查指南

## 常见问题及解决方案

### 问题1：模型文件不存在

**错误信息**：
```
WARNING - 模型文件不存在: models/bc_model_stage7_optimized.pth
WARNING - 无法评估胜率且游戏运行器未初始化，跳过本次迭代
```

**原因**：
- 首次运行工作流，模型文件尚未生成
- 训练过程被中断，模型文件未保存

**解决方案**：
✅ **已修复**：工作流现在会自动处理这种情况
- 如果模型文件不存在，会跳过评估但继续下一轮训练
- 训练完成后会自动生成模型文件

**手动检查**：
```bash
# 检查模型文件是否存在
ls models/bc_model_stage7_optimized.pth

# 如果不存在，等待训练完成
# 训练脚本会自动保存模型文件
```

### 问题2：游戏运行器未初始化

**错误信息**：
```
WARNING - 游戏运行器未初始化，跳过自动对战
```

**原因**：
- `AutoGameRunner` 模块导入失败
- 游戏服务器路径配置错误
- 依赖模块缺失

**解决方案**：
✅ **已修复**：工作流现在会继续使用现有游戏记录
- 即使游戏运行器未初始化，工作流也会继续
- 会尝试使用 `game_records` 目录中的现有记录

**手动检查**：
```bash
# 检查游戏记录目录
ls game_records/

# 检查AutoGameRunner是否可以导入
python -c "import sys; sys.path.insert(0, 'src/train'); from auto_game_runner import AutoGameRunner; print('OK')"
```

### 问题3：无法评估胜率

**错误信息**：
```
WARNING - 无法评估胜率
```

**可能原因**：
1. 游戏记录不足或格式不正确
2. 模型文件存在问题
3. 评估器配置错误

**解决方案**：
1. **检查游戏记录**：
   ```bash
   # 查看游戏记录数量
   ls game_records/*.json | wc -l
   
   # 检查记录格式
   python -c "import json; f=open('game_records/某个文件.json'); print(json.load(f))"
   ```

2. **检查模型文件**：
   ```bash
   # 检查模型文件是否存在且可读
   python -c "import torch; torch.load('models/bc_model_stage7_optimized.pth', map_location='cpu')"
   ```

3. **手动运行评估器**：
   ```bash
   python src/train/m1_vs_client_evaluator.py \
       --num_games 50 \
       --opponent client \
       --model_path models/bc_model_stage7_optimized.pth
   ```

### 问题4：训练失败

**错误信息**：
```
ERROR - 迭代 X 训练失败
```

**可能原因**：
1. 训练数据不足
2. 内存不足
3. CUDA/设备配置错误

**解决方案**：
1. **检查训练数据**：
   ```bash
   # 检查训练数据目录
   ls game_records/*.json | wc -l
   ```

2. **检查设备配置**：
   ```bash
   # 检查CUDA是否可用
   python -c "import torch; print(torch.cuda.is_available())"
   ```

3. **查看训练日志**：
   - 查看控制台输出的详细错误信息
   - 检查MLflow日志

### 问题5：MLflow监控器未初始化

**错误信息**：
```
WARNING - MLflow监控器未初始化，跳过实时指标分析
```

**原因**：
- MLflow模块导入失败
- MLflow tracking URI配置错误

**解决方案**：
1. **检查MLflow安装**：
   ```bash
   pip install mlflow
   ```

2. **检查MLflow数据目录**：
   ```bash
   ls logs/mlruns/
   ```

3. **手动启动MLflow UI**：
   ```bash
   mlflow ui --backend-store-uri file:///d:/YiFeiAI-GD/logs/mlruns
   ```
