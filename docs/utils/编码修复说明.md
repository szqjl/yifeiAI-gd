# Windows控制台编码修复说明

## 问题描述

在Windows系统下运行Python脚本时，控制台输出中文可能会出现乱码，例如：
```
׶21ģͼܹ޸Ĳܽ
```

这是因为Windows控制台默认使用GBK编码，而Python脚本使用UTF-8编码。

## 解决方案

项目提供了统一的编码修复工具：`src/utils/encoding_fix.py`

### 使用方法

#### 方法1：自动修复（推荐）

在脚本的最开始导入并调用：

```python
# -*- coding: utf-8 -*-
import sys
import os

# 在导入其他模块之前先修复编码
try:
    from src.utils.encoding_fix import fix_windows_console_encoding
    fix_windows_console_encoding()
except ImportError:
    pass

# 其他代码...
```

#### 方法2：手动修复

如果无法导入工具模块，可以使用备用方案：

```python
# -*- coding: utf-8 -*-
import sys
import io

if sys.platform == 'win32':
    try:
        if hasattr(sys.stdout, 'buffer'):
            sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8', errors='replace')
        if hasattr(sys.stderr, 'buffer'):
            sys.stderr = io.TextIOWrapper(sys.stderr.buffer, encoding='utf-8', errors='replace')
    except:
        pass
```

## 注意事项

1. **导入顺序**：编码修复应该在脚本的最开始执行，在导入其他模块之前
2. **错误处理**：如果编码修复失败，不应该影响程序继续运行
3. **跨平台**：编码修复只在Windows系统下执行，其他系统不需要处理

## 测试

运行以下命令测试编码修复是否成功：

```bash
python -c "from src.utils.encoding_fix import fix_windows_console_encoding; fix_windows_console_encoding(); print('测试中文输出：阶段2任务1：修改模型架构')"
```

如果中文显示正常，说明编码修复成功。
