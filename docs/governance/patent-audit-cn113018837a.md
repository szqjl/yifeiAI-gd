## 2. 权利要求要点摘要

### 独立权利要求 1（方法核心）

> 一种掼蛋扑克的机器博弈出牌方法，包含：
> 1) 计算每种拆牌方式的拆牌损失 E1 + 拆牌价值 E2 → 能量值 Ea = E1 + E2
> 2) 比较能量值 → minEa
> 3) 计算价值 Eb = (k·E1 + 1/minEa)，k 为常量
> 4) 根据 Eb 值选择出牌牌型

**通俗解释**：通过对 26 张手牌的不同拆分方式计算"能量"（损失+价值），选取最优拆分后出牌。

### 从属权利要求 2-8

| 编号 | 限定内容 |
|------|----------|
| **2** | E1（拆牌损失）= 所持牌个数 |
| **3** | Value 值定义：三同牌 V3(i+1)=V3(i)+1；二同牌 V2(i+1)=V2(i)+1；炸弹 V4(2)=V3(A)+1；同花顺 V5(2)=V4(A)+1；红心级牌可替代 |
| **4** | 三类有效牌：C1（降低组数）、C2（增加价值）、C3（帮助对家） |
| **5** | k 值训练方法：从 k=2 或 1/2 开始增减 0.5，找到最大赢率的 k 值 |
| **6** | 每个 k 值训练 20 次自动测试 |
| **7** | 神经网络为基于蒙特卡洛树搜索（MCTS）的神经网络 |
| **8** | 网络结构：3 Conv + Flatten + 4 Dense + Softmax |

### 独立权利要求 9（系统）

> 含存储器、处理器及计算机程序的掼蛋出牌系统。

### 独立权利要求 10（介质）

> 计算机可读存储介质。

## 4. 规避设计建议

### ⚠️ 边界模块：动态分组优化

**风险**：V7 的 `dynamic_grouping_optimizer.py` 涉及不同组牌方式的比较和评价（选择最优分组）。专利权利要求 1 保护的核心是「通过能量值 Ea=E1+E2 选择最优拆牌方式」。如果 V7 的分组优化采用了类似的「损失+价值」加权评分公式，可能落入专利保护范围。

**规避方案**：

| 方案 | 方法 | 工作量 |
|------|------|--------|
| **A（推荐）** | 分组评价采用基于牌型价值（如炸弹 > 同花顺 > 顺子 > 三带二）的离散分级，而非连续的「能量公式」 | 低 |
| **B（推荐）** | 分组评价使用神经网络输出的 win_rate 增量（即：分组 A 的决策 win_rate vs 分组 B 的决策 win_rate），完全避开 E1+E2 模式 | 中 |
| **C（备选）** | 若使用公式计算，确保公式形式与专利中的 Ea=E1+E2 及 Eb=k·E1+1/minEa 在数学上完全不同（如使用乘积而非和、非线性函数而非线性加权） | 低 |

### ✅ 无风险模块

- V7 四头网络架构和特征工程（完全不同）
- V7 的 BC 热启动 + RL 自对弈管线
- V7 的 WebSocket 通信和批跑基础设施

## 5. 决策建议

| 选项 | 建议 | 理由 |
|------|------|------|
| **继续实施** | ✅ **推荐** | V7 Phase 1-3 的核心技术路径与 CN113018837A 专利保护范围无实质重叠 |
| ⚠️ **需注意** | 分组优化模块做规避设计 | 见 §4 规避方案（推荐 A/B） |
| 暂停等专利失效 | ❌ 不推荐 | 专利实审中，失效时间不确定（通常 2026+），且 V7 路径不受显著限制 |

**结论**：**继续实施**，对 `dynamic_grouping_optimizer.py` 做规避设计即可。
