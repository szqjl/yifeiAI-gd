# 回放工具改进建议（参考 guandan 项目）

## 参考项目分析

参考项目：https://github.com/746505972/guandan

### 项目特点
1. **多种可视化方式**：
   - Streamlit 可视化前端
   - 控制台可视化（display.py）
   - Vue 前端 + FastAPI 后端

2. **状态编码**：
   - 108维手牌编码（两副牌）
   - 历史动作记录
   - 协作状态、压制状态等

3. **回放功能**：
   - 可视化游戏过程
   - 胜率统计
   - 动作分析
