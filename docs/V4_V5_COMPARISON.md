# YF_V4 vs YF_V5 对比说明

## 版本共存

✅ **V4 和 V5 可以同时存在并运行**

- V4 文件：`yf1_v4.py`, `yf2_v4.py`（保留不变）
- V5 文件：`yf1_v5.py`, `yf2_v5.py`（新增）

## 核心差异

### V4 特性

- ✅ 4层决策架构（YF → DecisionEngine → Knowledge → Random）
- ✅ 知识库集成（44条规则）
- ⚠️ RL引擎（部分集成，未启用）

### V5 特性（在V4基础上增强）

- ✅ 保留V4所有功能
- ✅ **智能混合决策**：融合RL + 知识库 + 规则引擎
- ✅ **可配置权重**：RL(30%) + 知识库(50%) + 规则(20%)
- ✅ **增强统计**：分别追踪RL和知识库决策
- ✅ **自动降级**：RL不可用时自动回退

## 决策流程对比

### V4 决策流程

```
1. 关键规则检查
2. 生成候选（Layer 1 + Layer 2）
3. 知识库增强（Layer 3）
4. 选择最优动作
5. 随机回退（Layer 4）
```

### V5 决策流程

```
1. 关键规则检查（同V4）
2. 混合决策融合：
   ├─ 知识库增强决策（权重50%）
   ├─ RL决策（权重30%，如果可用）
   └─ 规则引擎决策（权重20%）
3. 加权评分排序
4. 选择最优动作
5. 随机回退（同V4）
```

## 使用场景

### 使用 V4

- ✅ 稳定可靠，经过验证
- ✅ 知识库完整集成
- ✅ 适合生产环境

### 使用 V5

- ✅ 需要RL增强决策
- ✅ 需要更智能的决策融合
- ✅ 适合实验和优化

## 配置说明

### V5 权重配置

```python
# 在 yf1_v5.py 或 yf2_v5.py 中
self.rl_weight = 0.3          # RL决策权重（30%）
self.knowledge_weight = 0.5   # 知识库权重（50%）
self.rule_weight = 0.2        # 规则引擎权重（20%）
```

### 启用/禁用混合决策

```python
self.use_hybrid_decision = True   # 启用V5混合决策
self.use_hybrid_decision = False  # 禁用（回退到V4逻辑）
```
