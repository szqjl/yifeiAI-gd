# 掼蛋 AI Agent 工作流（真源）

> **用途**：新会话、换机、接续时 **Agent 自启动**，人类不必重复解释项目/规范/格式。  
> **与 AGENTS.md 分工**：根目录 `AGENTS.md` = Cursor 自动加载的**入口索引**；**本文件 = 完整工作流**。  
> **与 Wiki 分工**：Wiki = 综合知识地图；**ITERATIONS / ISSUES / handoff = 实时 GPS**（见 WF-09）。

---

## 1. 新会话 30 秒（WF-01 · 默认自启动）

**人类只需发**：[`AGENT_FIRST_MESSAGE.md`](./AGENT_FIRST_MESSAGE.md) 默认句（或任意带「按工作流」的短指令）。

**Agent 必须按序执行**（无需人类再解释）：

| 步 | 动作 | 真源 |
|----|------|------|
| 1 | `git branch -vv` 确认分支（V7 → `v7-dev`；M3 日常 → `m-dev`） | 本文件 §3 |
| 2 | 读 **实时** 状态（禁止只用 Wiki） | `ITERATIONS.md` **最新一行**；`ISSUES.md` **open + P0** |
| 3 | 可选加速（综合背景，非实时） | `python scripts/wiki.py query "V7 当前 P0"` |
| 4 | 向人类 **3 行汇报** 后等待派活 | 格式见 §2.1 |

**禁止**：凭聊天历史假设「上次修了什么」；未读 ITERATIONS 就改决策代码。

**Skill**：`.cursor/skills/guandan-session-start/`

## 2. 输出格式约定

### 2.1 会话启动汇报（WF-01 产出）

```text
分支：<branch> @ <短 hash>
当前迭代：<ITERATIONS 最新一行摘要>
open P0：<GUA-id 列表或「无」>
等你派：<一句>
```

### 2.2 改代码 / 修 GUA 完成汇报

```text
目标 GUA / 迭代行：<id>
改动摘要：<1～3  bullet>
验证：<pytest / check_xxx / 批跑命令 + 结果>
文档：<ISSUES / ITERATIONS 是否已更新>
```

### 2.3 批跑 / 数据分析汇报（WF-04）

必须含：**局胜**（`victoryNum[0]` vs `[1]`，同队 [0]=[2]、[1]=[3]）、**副数**（`game_records` 文件数或 `total_rounds`）、**口径声明**（`--target-games`、batch_games 真源）。禁止用副数当局数。

### 2.6 决策链路分析汇报（WF-12）

必须含：**圈况**（步号、greaterPos/Action、角色/手牌数）、**实际出牌**（type、actIndex）、**命中决策层**（GUA-075 / 残局 / mask 拦截 / Guard / NN / heuristic，附日志或 `my_decisions` 证据）、**根因标签**（R-D01～R-D08 至少一项）、**建议**（GUA / pytest / 是否需批跑复验）。详版：[`workflows/WF-12-yf-decision-trace.md`](./workflows/WF-12-yf-decision-trace.md)。

### 2.4 通用

- 简体中文；代码引用用 `` `path:line` `` 或 fenced block。
- 仅用户明确要求时 `git commit` / `push`（WF-08）。
- 新脚本（非临时调试）须登记 [`SCRIPT_INDEX.md`](./SCRIPT_INDEX.md)。
