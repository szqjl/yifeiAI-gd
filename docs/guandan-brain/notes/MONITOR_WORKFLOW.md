# M1训练工作流监控指南

## ✅ 工作流已启动

完整训练工作流正在后台运行，目标：**M1战胜client（胜率 > 50%）**

## 📊 实时监控方法

### 方法1: MLflow UI（推荐）

在新终端运行：

```bash
mlflow ui --backend-store-uri file:///d:/YiFeiAI-GD/logs/mlruns
```

然后在浏览器打开：**http://localhost:5000**

**查看内容**：
- 实时训练指标（Loss、预测比例、质量分数等）
- 训练进度
- 参数对比
- 模型版本

### 方法2: 检查工作流状态

```bash
python scripts/checks/check_workflow_status.py
```

**查看内容**：
- 工作流历史
- 当前迭代次数
- 最新胜率
- 训练历史

### 方法3: 查看日志文件

工作流日志会输出到控制台，也可以查看：
- `logs/` 目录下的日志文件
- MLflow运行记录

## 🔄 工作流当前状态

### 正在执行的步骤

工作流会按以下顺序执行：

1. **检查/生成游戏记录**
   - 如果记录不足，自动运行M1与client对战
   - 生成足够的游戏记录（默认50局）

2. **训练模型**
   - 使用Stage7优化训练框架
   - MLflow实时监控训练指标
   - 训练100个epoch（或早停）

3. **从MLflow读取实时指标**
   - 自动分析训练进度
   - 识别问题（预测过度、损失不收敛等）

4. **分析训练结果**
   - 分析训练历史
   - 生成优化建议

5. **评估M1 vs Client胜率**
   - 评估训练后模型的胜率
   - 如果记录不足，自动运行对战

6. **检查目标**
   - 如果胜率 ≥ 50%：✅ 成功，停止
   - 如果胜率 < 50%：继续优化

7. **根据MLflow指标自动优化训练代码**
   - 根据实时指标分析结果
   - 自动调整训练参数
   - 准备下一轮训练

8. **迭代**
   - 重复步骤1-7
   - 直到胜率 ≥ 50% 或达到最大迭代次数

## 📈 预期时间

- **每次迭代**：约20-40分钟
  - 游戏对战：5-10分钟（如果需要）
  - 模型训练：10-30分钟
  - 评估和优化：1-2分钟

- **完整工作流**：根据迭代次数
  - 如果第1次就达标：约20-40分钟
  - 如果需要多次迭代：可能需要数小时

## ⚠️ 注意事项

1. **保持MLflow UI打开**：建议在新终端运行MLflow UI，实时查看训练指标

2. **不要中断工作流**：工作流会自动优化和迭代，请勿手动中断

3. **检查游戏服务器**：如果自动对战失败，可能需要手动指定服务器路径

4. **查看工作流历史**：所有迭代结果保存在 `models/m1_training_workflow_history.json`

## 🔍 故障排查

### 如果工作流停止

1. **检查错误日志**：查看控制台输出
2. **检查工作流历史**：`models/m1_training_workflow_history.json`
3. **检查训练历史**：`models/bc_model_stage7_optimized_training_history.json`
4. **检查MLflow运行**：在MLflow UI中查看最新运行

### 如果胜率不提升

1. **查看MLflow指标**：检查预测比例、损失趋势等
2. **查看优化建议**：工作流会自动生成优化建议
3. **检查游戏记录**：确保有足够的M1 vs client对战记录
4. **手动调整参数**：如果自动优化效果不佳，可以手动调整
