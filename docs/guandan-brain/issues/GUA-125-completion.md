## 0. 牌理定音（人类 · 2026-07-07 · 须与实现对齐）

### 0.0 掼蛋第一目标：头游

**掼蛋 = 谁先把手牌打光 = 头游 = 本副胜利。** 残局一切决策须先问：**还要几手到 0 张？哪几手几乎必过？能否比主敌先出完？**

**冲刺**（sprint）在实现与牌谱中的可操作定义：

```text
冲刺 = 以头游为目标的「出完序」：数清从当前手牌到 0 张的最短可靠路径，
      而非抽象「省炸」「赢这一圈」。
```

**一手清空 vs 接力清空（§0.0 定音 · 与 ITERATIONS `v7-gua125-chain-clean-two-form-def` 一致）**：

| 情形 | 定义 | 是否叫「冲刺」 |
|------|------|----------------|
| **一手清空** | 手牌只剩 **一手** 可出的整牌（6J / 6 张炸 / 5 张 TWT / 4 张炸 / 3 张 / 对 / 单 / 顺 / 钢板 / 三连对 / SF 等），出完且无人压 → 0 张 | **否**（单次清牌） |
| **接力清空** | **两圈**内连续出完：**第一圈**出 A（常为 ≥6 星炸等必过手）→ **下一圈**出 B（任意 ≤5 张整牌 X）→ 0 张 | **是**（GUA-125 所称 sprint） |

**冲刺真闭环**：仅 **两手接力清空**；**3+ 手**在掼蛋中通常不可清。**6J 单独一手清空 ≠ sprint**；**6J + 下一圈 X** = sprint。

评估候选时优先：**(a) 出完步数** → **(b) 关键一手是否不可拦** → **(c) 牌力交换是否划算**。

**跟压 `@1` 控牌时（如 `@1` 出 `333+22`）—— 本圈四家各出一手**：

### 0.1 6 星炸与冲刺主道（与 `_bomb_beats` 一致）

`endgame_decide._bomb_beats` 已定阶：**同花顺 > ≤5 星炸；≥6 星炸 > 同花顺**（实战中同花顺极少）。

| 资源 | 在冲刺中的角色 |
|------|----------------|
| **≥6 星炸**（如 6×J） | **冲刺主道**：打出后 practically 不可拦，是抢头游的核心一手，**不是**「仅留终局控场、能省则省」 |
| **同花顺**（敌） | 可压 **三带二 / 顺子 / 对子** 等非炸整牌；**压不了 ≥6 星炸**，也通常 **压不了单「三张」型**（牌型不对） |
| **≤5 星炸 / min 三带二** | 交换结构、跟压、逼敌深牌；**勿用 6 星炸抢低价值敌 TWT**（步 51 锚点） |

**定音**：有 6 星冲刺路径时，应规划 **「整牌跟压/领出 → 6 星炸（必过）→ 收尾三张/单张」**，而不是在敌 `333+22` 上裸交 6 星炸。

### 0.2 锚点场景 A — 敌 rem≈8 散深牌（WF-12 步 50–51）

#### 头游（本 GUA 统一用语）

**头游** = **本副牌第一个把手牌全部出完的人**（四人中的第一名）。掼蛋比的不是「赢某一圈」，而是 **谁先出完**（见 **§0.0**）。

| 名次 | 叫法 | 含义 |
|------|------|------|
| 第 1 个出完 | **头游** | **yf2 阻击路径(§0.6)** | 本副最早清牌（手牌 → **0 张**） |
| 第 2 个 | 二游 | |
| 第 3 个 | 三游 | |
| 最后出完 | **末游** | 本副最晚清牌 |

**2v2 队分**：yf1+yf2 对 @1+@3；单方两人名次越好，本副得分越高（如 **双上** = 头游 + 二游）。**头游**通常是本副最关键的一档。

**与本节锚点的对应**：冲刺序「手 3 → **0 张**」= yf2 **头游**；@1 finish 顺走 → **0 张** = **@1 头游**（见 **§0.5 C1** 反例）。牌谱上某席 **手牌变 0** 即已出完；**第一个变 0 的席 = 头游**（**副**内名次，≠ 批跑 `victoryNum` 的 **局**胜负，口径见 `guandan-context.mdc`）。

**局面**：步 **50/89** @1 出 `ThreeWithTwo/3`（333+22）→ 剩 **~8 张**（深牌、结构未明）；步 **51/89** yf2 应 **跟** `777+22` 或 `888+22`（用户口述「59」即本副 **51**，非步 59 PASS）。

**yf2 手牌（14）**：`S2 D2 | 777 | 888 | 6×J`。

**冲刺序（3 手到头游）**（`@1→yf2→…`，见 **§0.0a**）：

```text
① @1  ThreeWithTwo/3（333+22）
② yf2 777+22 或 888+22  跟压 min 三带二     → 剩 9（888+6J 或 777+6J）
     （@1 若再压一手 TWT，8→3，难再组织有效冲刺）
     ③ @3 / ④ yf1  本圈后续席（通常 PASS 或无力同型压）
手2  yf2 6J 炸               跟压敌结构 / 冲刺主道  → 剩 3（888 或 777）
手3  yf2 888 或 777          一手清               → 0，头游
```

**理由 ①（我方）**：跟完即 **3 手冲刺**；手 2 的 6J 是 **主道**而非备用；**禁止**在步 51 用 6J 炸 `333+22`（错对象、错时机，拆掉出完序）。

**理由 ②（敌方）**：8 张出 5 张结构 → **8→3**；3 张难组炸、难再冲刺，跟三带二 **交换划算**。

**PASS**：敌 rem=8 且牌力分散时可略增让队友权重（**125-P1-a**）；**非**步 51 默认（有同型 min 压且 sprint 在握）。

### 0.3 场景 B — 敌 rem=10 但 **两手成型**（`999+44` + 10–A 同花顺）

**局面**：@1 出 `333+22` 后剩 **10 张**，且已知（或记牌推断）为 **`999+44` + 同花顺** 两手清，**不是**场景 A 的散深牌。

**错误线（须写进反例）**（`@1→yf2 PASS→@3→yf1→@1` 续控，见 **§0.0a**）：

```text
① @1  333+22
② yf2 PASS → ③ @3 PASS → ④ yf1 PASS → ⑤ @1 续控
   @1 999+44 → yf2 6J 炸 → yf2 777+22 → @1 同花顺压 → @1 头游，yf2 剩 888 末游
```

炸完若仍剩 **三带二结构**（777+888+22），下一手三带二会被敌 SF 点杀；**不是**「请牌」，是 **出完序多一手且末手可被 SF 拦**。

**正解线（仍 3 手到头游，② yf2 必须跟）**：

```text
① @1  333+22
② yf2 777+22（跟，勿 PASS）  → 剩 888+6J
     @1 999+44（同圈或下圈跟压，视平台 greater 链）
③ yf2 6J 炸（≥6 星，SF 压不住）     → 剩 888
④ yf2 888（SF 过不了「三张」）       → 0，头游
```

**与场景 A 的差别**：

| 维度 | A：敌 ~8 张散深 | B：敌 10 张两手成型 |
|------|-----------------|---------------------|
| 第一拍 | 跟 min TWT | **跟 min TWT**（勿 PASS） |
| 理由 ② | 8→3 交换赚 | 弱；靠 **出完序** 取胜 |
| 炸完收尾 | 888/777 一手 | **必须** 888/777，**禁** 再出三带二 |
| 6J 含义 | 冲刺手 2 | 同左：**主道**，非省炸 |

**实现提示**：`_select_two_turn_sprint_structure` 须按 **residue 出完步数 + 末手是否可被敌 SF 拦** 评分，而非仅「两组 group」；≥6 星 residue 应视为 **必过冲刺手**（对齐 Q0 / `_bomb_beats`）。

#### §0.5.1 C1 决策树（队友视角 · 终版 · 2026-07-07）

**核心原则**：
- 掼蛋不是一个人在战斗，是 yf 队（yf1+yf2）联合阻击 @ 队（@1+@3）
- 拦截 @1 finish 任务**主要由上家 yf1 完成**
- 「具备冲刺能力」是 yf2 圈 1 跟 TWT 后剩 2 手（炸弹+单手）= **结构上具备冲刺条件**
- 「具备冲刺能力」**不等于** yf2 自己闭合冲刺，**闭合由 yf1 接力完成**（yf1 头游 = yf 队头游）

**前提条件**：
- @1 出 333+22（5 张 TWT），剩 finish 5 张 = 更大 TWT（点 > 7）
- yf2 整手 14 张 = JJJJJJ + 777 + 888 + 22（炸弹 + 三张 + 三张 + 对）
- @3 是 @1 队友（lalala 队），@3 不会拦截 @1 finish
- yf1 是 yf2 队友（v7 队），yf1 拦截 @1 finish = yf 队头游
