## 0. 术语

- **头游** = 本副第一个把手牌全部出完的人
- **双进** = 同队两人占头游 + 二游 = **双上**（最优队结果）
- **双下** = 同队两人占三游 + 末游（最差队结果）
- **双进优先级** = yf 队在「yf2 自拿第二」 vs 「yf1 拿第二（放 yf2 第三）」 vs 「阻止 @3 拿第二」之间的判定

**为何叫「双进优先级」**：掼蛋比的不是「赢某一圈」，而是 **谁先出完 + 谁第二出完**。一个队的胜负由「两名队员名次之和」决定。

C1-C6 不同闭合路径下「双进」目标不同：

| 情形 | 闭合者 | 头游 | 队整体目标 |
|------|--------|------|----------|
| **C1 路径 A** | yf1 接力 | yf1 | yf2 必第三 → 阻止 @3 拿第二 |
| **C1 路径 B** | yf2 三手清空 | yf2 | yf1 必抢第二 → 阻止 @3 拿第二 |
| **C2** | @1 SF 一手清 | @1 | yf 队必须拿第二（否则 @ 队双进） |
| **C3/C5/C6** | yf2 自闭合 | yf2 | yf1 必抢第二（否则 @ 队双进） |
| **C4** | @1 5 炸一手清 | @1 | yf 队必须拿第二（否则 @ 队双进） |

## 2. 牌理基础

### 2.1 §4.1 bomb family 跨型压杂牌

```
§4.1 总序：bomb family（4+ 张同点炸 / 同花顺 / 王炸）> 杂牌整牌（三带二 / 顺子 / 三连对 / 钢板 / 杂牌 TWT / 对 / 单）
         bomb family 同 family 内按「张数优势 + 同点优势」排序
```

- **C2**（@1 SF）：SF 是 bomb family 一员 → 可跨型压杂牌 TWT → yf2 圈 1 跟 TWT 必败 → @1 头游
- **C4**（@1 5 炸）：5 炸是 bomb family 一员 → 同点同张数可同型压回 → yf2 圈 1 跟 TWT 必败 → @1 头游（除非 yf2 6J 反抢）

### 2.2 §4.4 杂牌同型不跨型

```
§4.4 杂牌通道：杂牌整牌之间，**只能同型互压**，不能跨型压
例：TWT 不能压 Straight；TWT 不能压 ThreePair；TWT 不能压 TWT（不同点）
```

**C3/C5/C6**（@1 finish 是杂牌）：finish 不能跨型压 TWT → yf2 圈 1 跟 TWT 后 @1 必 PASS → yf2 圈 2 必领出 → yf2 自闭合

### 2.3 双进优先级判定流程

yf 队当前局：
- @1 已头游（C2/C4）OR yf2 已头游（C1 路径 B / C3/C5/C6）OR yf1 已头游（C1 路径 A）
- 还剩 3 家未出完
- 双进优先级判定 = 谁拿第二 = 阻止 @3 拿第二 OR 帮队友抢第二

判定逻辑：

1. **优先**：自己（yf2）能拿第二吗？
   - 若 yf2 当前有冲刺能力（剩 2 手 = 炸弹 + 单手）→ yf2 自己拿第二（继续自闭合）
   - 若 yf2 没冲刺能力（剩 ≥3 手）→ 进入判定 2

2. **次优**：队友（yf1）能拿第二吗？
   - 若 yf1 圈 1 已 bomb family 拦截（C1 路径 A）→ yf1 头游后 yf2 已第三，yf1 第二 = yf 队双进 ✓
   - 若 yf1 圈 1 未拦截 → 进入判定 3

3. **必须**：阻止 @3 拿第二
   - @3 当前剩牌数 + 是否有炸弹 → 估算 @3 冲刺能力
   - 若 @3 有冲刺能力 → yf2 必须用 bomb family / 更大 TWT 拦截 @3

## 4. 关键判定函数

### 4.1 _q1_double_second_priority

**作用**：双进优先级判定（C2/C4 接受 @1 头游 + C3/C5/C6 闭合后队整体策略）

**判定逻辑**：

1. yf2 当前是否已有冲刺能力（剩 2 手 = 炸弹 + 单手）？
   - 是 → yf2 自己继续自闭合拿第二
   - 否 → 进入 2
2. yf1 当前剩牌数 + 是否能抢第二？
   - 若 yf1 已 bomb family 拦截（C1 路径 A 已生效）→ yf1 必头游，yf2 必第三
   - 若 yf1 未拦截但仍有冲刺能力（剩 2 手 = 炸弹 + 单手）→ 让 yf1 拿第二
   - 若 yf1 也无冲刺能力 → 进入 3
3. @3 当前剩牌数 + 是否有冲刺能力？
   - 若 @3 有冲刺能力 → yf2 必须用 bomb family / 更大 TWT 拦截 @3 抢第二
   - 若 @3 也无冲刺能力 → yf2 PASS 等待更优时机

**返回**：最优动作 (idx, action) 或 None

**调用点**：
- `_q1_block_enemy` ④.5b (GUA-134 C3/C5/C6 dispatch) **之后、⑤ _q1_enemy_five_single_special 之前**
- 作为 C2/C4 「@1 必头游」+ C3/C5/C6 「yf2 已闭合头游」后的队整体策略判定

### 4.2 _is_double_second_priority_scenario

**作用**：探测 yf2 当前是否落在「双进优先级判定」场景

**触发条件（任一）**：
- @1 finish 是 bomb family（C2 SF / C4 5 炸）→ @1 必头游 → yf 队必抢第二
- yf2 整手 ≤ 6 张 且 yf1 整手 ≤ 6 张 → 双冲刺赛道，必须判定谁抢第二
- yf1 已 bomb family 拦截（C1 路径 A）→ yf1 必头游 → yf2 必第三

**返回**：ctx dict 或 None

### 4.3 _has_sprint_capability(hand)

**作用**：判断手牌是否具备冲刺能力（剩 2 手 = 炸弹 + 单手）

**冲刺能力定义**（GUA-125 §0.0 一手清空 vs 接力清空）：
- 手牌可拆为 2 个整牌型
- 其中至少 1 个是 bomb family（≥4 张同点炸 / 同花顺 / 王炸）
- 另一个是任意 ≤5 张整牌（单 / 对 / 三张 / 三连对 / 三带二 / 钢板 / 顺子 / 同花顺 / 炸弹）

**注**：冲刺能力 ≠ sprint 真闭环（sprint 真闭环需「出完 6J + 接力 X」两手清空）。这里只判定「结构上具备冲刺条件」。

### 4.4 _estimate_player_remaining(position, ec, game_state)

**作用**：估算某玩家当前剩牌数（用于双进优先级判定）

**来源**：
1. 平台报牌（self._get_reported_hand）
2. 记忆模块（memory_tracker）
3. 圈序出牌历史（self._build_play_history）

**返回**：估算的剩牌数
