## 3. 牌理基础

**@1 finish = SF（bomb family §4.1）**：

| 规则 | 应用 |
|------|------|
| §4.1 总序 | bomb family 可跨型压杂牌 TWT |
| §4.4 杂牌同型 | 杂牌不能跨型压杂牌 |
| **§4.1 vs §4.4** | bomb family（SF / 4+ 张炸 / 王炸）可跨型压杂牌 |

**这意味着**：

1. **yf2 圈 1 跟 TWT（如 `777+22`）** → @1 SF 跨型压回（§4.1）→ @1 余 0 → @1 头游
2. **yf2 圈 1 跟 bomb family（6J）** → @1 SF 同 family 同型可压（SF 是 bomb family，6J 也是 bomb family）→ @1 SF 压回 → @1 头游
3. **yf2 圈 1 跟 同花顺** → @1 SF 同型可压（更大点）→ @1 头游
4. **yf2 圈 1 PASS** → @1 圈 2 领出 SF 一手清 → @1 头游

⚠️ **C2 中所有 yf2 圈 1 动作都让 @1 头游**——这是不可改变的现实。

## 5. C2 最佳路径：跟 TWT 形成冲刺能力 + 圈 2 反抢 @3

**为什么「跟 TWT」是 C2 最佳动作**：

| 维度 | 跟 TWT | 出 6J | PASS |
|------|--------|-------|------|
| **yf2 余手** | JJJJJJ + 888（**2 手 = 冲刺能力**）| 777+888+22（3 手，无冲刺能力）| 14 张（4 手）|
| **圈 2 闭合 @3 概率** | **高**（剩 2 手，闭合路径清晰）| 中（3 手接力清空）| 低（多手接力）|
| **闭合路径示例** | 圈 2 6J + 圈 3 三连对 + 圈 4 对 | 圈 2 三连对 + 圈 3 对 | 取决于 @3 圈 3 出什么 |
| **冲刺能力** | ✅ | ❌ | ❌ |
| **与 @3 接力闭合** | ✅ | 取决于 @3 反应 | — |

**结论**：**yf2 圈 1 跟 TWT 形成冲刺能力是 C2 最佳路径**——既接受 @1 头游，又最大化冲刺 @3 拿第二名的概率。

## 7. 关键判定函数

```python
def _c2_decision(self, game_state, action_list, ec):
    """
    C2 决策：接受 @1 头游，yf2 圈 1 跟 TWT 形成冲刺能力，圈 2 反抢 @3 拿第二名

    @1 finish = SF（bomb family）→ @1 必头游不可阻挡
    yf 队策略 = 接受 @1 头游，合力冲刺 @3
    """
    if not self._is_c2_scenario(game_state, ec):
        return None

    # 1. 找到最小 TWT（min 点）
    twt_options = self._find_twt_options(action_list)
    if not twt_options:
        return None

    # 2. 跟 min TWT（形成冲刺能力：剩 2 手 = 6J + 单手）
    return min(twt_options, key=lambda act: self._get_twt_point(act))
```

- `_q1_block_enemy` ⑤ `block_with` 命中 bomb-like 前插入 `_c2_decision`
- 仅在 C2 场景触发（@1 finish = SF + yf2 整手 ≥ 10 张）
