## 3. C4 真实牌理：6 张炸压 5 张炸

**关键牌理**：

| 规则 | 应用 |
|------|------|
| §4.1 bomb family | bomb family 可跨型压杂牌 TWT |
| §4.1 bomb family 同型 | bomb family 同点同张数 = 同型互压 |
| **§4.1 张数优势** | **6 张炸压 5 张炸**（同点不同张数，张数大者压张数小者）|

**这意味着**：

1. **yf2 圈 1 出 JJJJJJ（6 张炸）** → 6 张压 5 张（同点不同张数，张数优势 §4.1）→ @1 PASS
2. **yf2 圈 1 跟 TWT** → @1 5 炸同型压回（同点同张数）→ @1 头游（**已接受**）
3. **yf2 圈 1 PASS** → @1 圈 2 出 5 炸一手清 → @1 头游（**已接受**）

⚠️ **C4 中只有「yf2 出 6J」能闭合**——**这是 C4 的唯一最佳路径**。

## 5. C4 最佳路径：yf2 必出 6J

**为什么「出 6J」是 C4 最佳动作**：

| 维度 | 出 6J | 跟 TWT | PASS |
|------|--------|-------|------|
| **yf2 余手** | 777+888+22（3 手）| JJJJJJ + 888（2 手 = 冲刺能力）| 14 张（4 手）|
| **@1 反应** | PASS（不能压 6 张炸）| 同型压回 → @1 头游 | @1 圈 2 一手清 → @1 头游 |
| **闭合 @3 概率** | **高**（yf2 圈 2 领出）| 中（yf2 圈 2 领出）| 低（@3 圈 3 领出）|
| **闭合路径示例** | 圈 2 三连对 + 圈 3 对 | 圈 2 6J + 圈 3 三连对 + 圈 4 对 | 取决于 @3 |
| **与 @3 接力闭合** | ✅ | ✅ | — |
| **@1 头游接受** | ✅ | ✅ | ✅ |

**结论**：**yf2 圈 1 必出 6J（bomb family 张数优势 §4.1）**——C4 中 yf2 闭合 @3 拿第二名的概率最高。

## 7. 关键判定函数

```python
def _c4_decision(self, game_state, action_list, ec):
    """
    C4 决策：yf2 圈 1 必出 6 张炸（bomb family 张数优势 §4.1）

    @1 finish = 5 星炸 → @1 一手清必头游
    yf 队策略 = 接受 @1 头游，yf2 出 6 张炸自闭合拿第二名
    """
    if not self._is_c4_scenario(game_state, ec):
        return None

    # 1. 校验 yf2 是否有 6+ 张同点炸（这是 C4 闭合的前置条件）
    if not self._has_six_joker_bomb(game_state):
        # yf2 没有 6+ 张炸 → 走「跟 TWT 形成冲刺能力」兜底路径
        return self._find_min_twt(action_list)

    # 2. 找到 yf2 的 6+ 张同点炸（JJJJJJ 等）
    six_joker_bomb = self._find_six_joker_bomb(action_list)
    if not six_joker_bomb:
        return None

    # 3. yf2 圈 1 出 6J 反抢 @1 5 炸
    return six_joker_bomb
```

**调用点**：

- `_q1_block_enemy` ⑤ `block_with` 命中 bomb-like 前插入 `_c4_decision`
- 仅在 C4 场景触发（@1 finish = 5 星炸 + yf2 有 6+ 张同点炸）
