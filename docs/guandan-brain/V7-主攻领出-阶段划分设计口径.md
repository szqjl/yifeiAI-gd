### 2.4 「回手 / K 原则 / 谁打谁收」（Q10 锁定）

**最小可操作定义**：

1. **组牌内**存在 **同型更大一手**，可在 **下一轮** 由己方压回（回收牌权）。
2. 一般遵循 **K 原则回收**：例——领出 `Pair/4`，组牌中须另有 **K 及以上（含级牌）对子** 作为回手，才算「有回手」。
3. **炸/同花顺接回**：组牌内仍有 Bomb / StraightFlush，可作为任意整型领出的回手（L11/L14 被压夺权语义的可算版；**不限**「仅 ≥2 炸才许领 core 顺」）。
4. 语义等价：**谁打谁收**、**有打有收**（与 `docs/knowledge/skills/04_common_skills/02_card_language.md` 一致）。

**`is_core` 边界（2026-07-10 定音）**：`is_core` = **禁轻拆**（部分取用 core 组），**≠ 禁整组出**。P2/P3/P4 领出组牌整手结构时，即使 `is_core=1.0` 也允许；整组打出由 `_get_broken_core_type`（`used==total`）放行。

**实现提示**（非牌例硬编码）：回手判定消费 `card_mask` / `group_type_map` + 当前 `curRank` 的单张/对子/三带二强度序 + Bomb/SF 存在性，不单独写「44 必须 KK」或「双炸才许领顺」补丁。

## 4. 文档优先级链（主攻领出要领 · 摘要）

命中即执行，不叠加冲突（实施时映射为 intent + scorer，禁止牌例硬编码）：

| 优先级 | 触发（摘要） | 动作 |
|--------|--------------|------|
| **P1** | 有王，或 ≥2 张 **&lt;10 散单（不含级牌）** | 首出 **倒数第二小** 单 |
| **P2** | 无 P1，三带二/三张充足且有回手 | 首出三带二（**仅 1 手小夯 → 移交 stage_2**） |
| **P3** | 顺子成套多、孤单少且有回手 | 首出短小顺（**仅 1 手小顺 → 移交 stage_2**） |
| **P4** | P1–P3 不命中，或 **无回手 TWT/顺** | **首出小对子** |

**L11/L14 补充**：唯一小 TWT/顺 **stage_2 才出**；被压后 **stage_2** 可 R11+091 改炸（非 stage_1 plan）。

**L33 补充**：无回收大牌的夯在 stage_1/2 仅试探一轮；**stage_3 残局不受此限**。
