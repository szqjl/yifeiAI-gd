## 下一步唯一动作

**启动 3 局冒烟批跑**，从最简单的测试开始：

```powershell
# 仓库根目录
.\RUN_V8_VS_LALALA.bat
```

该命令链路：`.bat` → `scripts/launchers/v8/run_v8_vs_lalala_games.py --games 3 --platform openguandan` → `BatchExecutor`（启 `guandan.exe :8181` + 4 客户端 + 等 3 局打完 + 报告战绩）。

**首次冒烟预期可能遇到的问题**（按概率排序）：

1. `guandan.exe` 启动后端口 8181 未及时监听 → restart_manager 重试逻辑应自动处理
2. CREATE_ROOM/JOIN_ROOM 协议字段与 README 不一致 → 需查 `openguandan_latest/README.md` 调整
3. 上行消息 type 包装格式错误 → 调 `new_platform_adapter.py`
4. `gameResult` 字段 `victory` 单值 vs `victoryNum` 四席 → 需在 recorder 层反推

**如果冒烟失败**：读 `logs/yf1_v8_*.log` + `logs/yf2_v8_*.log` 定位，按方案 §3 逐阶段调试。

**冒烟前净盘**（可选，首次可跳过——无旧牌谱污染风险）：
```powershell
Get-Process guandan -ErrorAction SilentlyContinue | Stop-Process -Force
Remove-Item tmp\.batch_executor.lock -ErrorAction SilentlyContinue
Get-ChildItem game_records -Filter *.json -ErrorAction SilentlyContinue | Remove-Item -Force
Remove-Item batch_executor\latest_victory_num.json -ErrorAction SilentlyContinue
```
