## 二、本轮做了什么（2026-06-16 会话）

### 2.1 GUA-050 局面信念向量 (P0) — 已实施 + 已推送

在 V7 引擎 512 维特征的 188-195 位置插入 8 维局面信念向量：

| belief 维度 | 含义 | 计算方式 |
|-------------|------|----------|
| `[0]` my_strength | 自己牌力 | 炸弹×0.2 + 王×0.3 + 级牌×0.1 |
| `[1]` partner_strength | 对家牌力 | 1.0 - partner_rest/27 |
| `[2]` opponent_pressure | 对手压迫程度 | 对手剩牌少 + 级牌落后 |
| `[3]` level_progress | 级牌进度 | (selfRank-oppoRank) 归一化 -5~5→0~1 |
| `[4]` trump_ready | 有级牌/王? | 0/1 |
| `[5]` bomb_count | 我方炸弹数 | curBombNum/10 (clamp 0~1) |
| `[6]` opponent_bomb_risk | 对手炸弹风险 | 未出炸弹×进度系数 |
| `[7]` last_card_meaning | 上家出牌信号 | 0=无关 / 0.25=常规 / 0.5=强力 |

**模型兼容**：belief 放在 188-195（原零填充区），模型 0-187 权重不受影响，可立即推理。**belief 信号在下次 GUA-038 重训时激活**。
