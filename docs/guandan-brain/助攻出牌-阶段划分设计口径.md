## 3. 模块划分（GUA-117）

### 3.1 三层结构

```text
_recommend_play()  [助攻/超弱]
  │
  ├─ Layer 0  guard：§一 全局约束 + §四 黑名单（+ 现有 R08/R09/GUA-113）
  │
  ├─ Layer 1  非领出：**不新写函数** → 现 `_recommend_play()` / `_stage_mid_dispatch()` / `EndgameDecider` Q1 + Guard（§4.3 落盘表）
  │
  └─ Layer 2  is_lead → _stage_assist_feed(stage)
         ├─ stage_1  → 1.1 探路首出
         ├─ stage_2  → 2.1 同款匹配送牌
         └─ stage_3  → 3.1 队友剩张表（Q2 优先，与 assist_prefer 对齐）
```

### 3.2 路由（实施目标）

```text
_recommend_play()
  ├─ role ∈ {助攻, 超弱}
  │     ├─ guard Layer 0（约束 1–3、黑名单、R08…）
  │     ├─ is_lead 且 (stage_1 | stage_2 | 27 overlay)
  │     │     → _stage_assist_feed()
  │     ├─ stage_3 + EndgamePreprocessor.is_active
  │     │     → EndgameDecider Q0/Q1；Q1 未命中且 is_lead → _stage_assist_feed(stage_3)
  │     ├─ stage_2 非领出 → _stage_mid_dispatch()（GUA-091，§4.3）
  │     └─ stage_1 非领出 → _recommend_play() 四场景（GUA-075，§4.3）
  └─ …
```

**不得共用**：`_stage_open_plan()`、`_stage_main_lead_plan()`（GUA-116）、`_recommend_lead_impl()` 主攻链。
