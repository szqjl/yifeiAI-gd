# 阶段6训练GUI增强版使用指南

## 📋 概述

阶段6训练GUI增强版是一个完整的训练管理工具，整合了1312数据转换器，提供了从数据加载到模型评估的完整流程。

## 🚀 快速开始

### 方法1: 使用批处理文件（推荐）

1. **双击运行** `run_stage6_training_gui.bat`
2. 批处理文件会自动：
   - 检查Python环境
   - 检查必要的Python包
   - 创建必要的目录
   - 启动GUI

### 方法2: 使用Python脚本

```bash
python run_stage6_training_gui.py
```

## 📊 功能模块

### 1. 数据管理标签页

#### 数据目录选择
- 选择包含训练数据的目录（默认：`game_records`）
- 点击"加载数据"分析数据统计信息

#### 数据格式转换
- **检查并转换1312格式**: 自动检测并转换1312格式的数据
- **验证数据质量**: 检查数据完整性和有效性

#### 数据统计
显示以下统计信息：
- 总文件数
- 有效文件数
- 总样本数
- 平均每文件样本数

### 2. 训练配置标签页

#### 基本参数
- **训练轮数**: 默认80轮
- **批次大小**: 默认64
- **学习率**: 默认0.0002
- **最大样本数**: 默认15000

#### 模型路径
- 设置模型保存路径（默认：`models/bc_model_stage6_enhanced.pth`）

#### 阶段6特色配置
- ✅ 启用策略原因学习（26类原因类型）
- ✅ 启用胜率导向损失（学习有效策略）
- ✅ 启用动态阈值调整（局面自适应）
- ✅ 训练完成后自动进行游戏导向评估

#### 配置管理
- **保存配置**: 将当前配置保存为JSON文件
- **加载配置**: 从JSON文件加载配置
- **重置为默认**: 恢复默认配置

#### 训练控制
- **开始训练**: 启动训练流程
- **停止训练**: 停止正在进行的训练
- **暂停训练**: 暂停训练（开发中）

### 3. 训练监控标签页

#### 核心指标
实时显示以下指标：
- 训练轮次
- 动作准确率
- 策略准确率
- 策略理解率
- 策略原因准确率
- 胜率导向损失
- 策略一致性
- 预测阈值
- 概率校准

#### 训练日志
显示详细的训练日志，包括：
- 训练进度
- 损失值变化
- 准确率变化
- 错误信息

### 4. 训练评估标签页

#### 评估配置
- 选择要评估的模型文件
- 点击"开始评估"进行评估

#### 评估结果
显示以下评估指标：
- 胜率
- 策略适应性
- 决策质量
- 预测准确性
- 综合评估分数
- 改进分析

## 🔄 完整工作流程

### 步骤1: 准备数据

1. 将1312格式的数据文件放入`game_records`目录
2. 切换到"数据管理"标签页
3. 点击"检查并转换1312格式"自动转换数据
4. 点击"验证数据质量"检查数据完整性
5. 点击"加载数据"查看数据统计信息

### 步骤2: 配置训练

1. 切换到"训练配置"标签页
2. 设置训练参数（轮数、批次大小、学习率等）
3. 选择模型保存路径
4. 配置阶段6特色功能
5. （可选）保存配置以便下次使用

### 步骤3: 开始训练

1. 点击"开始训练"按钮
2. 切换到"训练监控"标签页查看训练进度
3. 观察核心指标的变化
4. 查看训练日志了解详细信息

### 步骤4: 评估模型

1. 训练完成后，切换到"训练评估"标签页
2. 选择训练好的模型文件
3. 点击"开始评估"
4. 查看评估结果和改进建议

## 💡 使用技巧

### 1. 数据转换
- 1312格式数据会自动检测并转换
- 转换后的数据会覆盖原文件（建议先备份）
- 转换过程会显示在日志中

### 2. 配置管理
- 保存常用配置，避免重复设置
- 可以为不同数据集创建不同的配置
- 配置文件是JSON格式，可以手动编辑

### 3. 训练监控
- 实时查看训练指标变化
- 如果指标异常，可以及时停止训练
- 训练日志可以导出保存

### 4. 模型评估
- 评估需要一些时间，请耐心等待
- 评估结果可以帮助优化训练参数
- 可以多次评估不同版本的模型

## ⚠️ 注意事项

1. **数据备份**: 转换1312格式数据时会覆盖原文件，建议先备份
2. **训练时间**: 训练可能需要较长时间，请确保有足够的时间
3. **资源占用**: 训练会占用较多CPU/GPU资源，建议关闭其他程序
4. **模型保存**: 训练过程中会定期保存模型，但建议手动备份重要模型

## 🔧 故障排除

### 问题1: GUI无法启动

**解决方案**:
1. 检查Python是否安装（需要3.7+）
2. 运行批处理文件会自动检查并安装依赖
3. 手动安装：`pip install torch numpy`

### 问题2: 1312转换器不可用

**解决方案**:
1. 检查`src/knowledge_processor/1312_replay_converter.py`是否存在
2. 如果不存在，GUI仍可使用，但无法转换1312格式数据
3. 可以手动转换数据后再使用GUI训练

### 问题3: 训练失败

**解决方案**:
1. 检查数据目录是否正确
2. 检查数据文件格式是否正确
3. 查看训练日志中的错误信息
4. 尝试减少批次大小或训练轮数

### 问题4: 评估失败

**解决方案**:
1. 检查模型文件是否存在
2. 检查模型文件是否完整
3. 确保数据目录包含评估数据
4. 查看评估日志中的错误信息
