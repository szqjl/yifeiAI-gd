# 批量更新现有JSON数据指南

## 📋 问题分析

### 当前情况
- ✅ 现有JSON数据包含：玩家ID、初始手牌、动作序列、级牌等级
- ❌ 现有JSON数据缺少：真实的比赛结果（都是"unknown"）、排名信息（rank）

### 解决方案
**不需要废弃现有数据！** 只需要从.rep文件补充缺失的比赛结果信息。

## 🎯 两种方案对比

### 方案1: 批量更新现有JSON（推荐）✅

**优点**：
- ✅ 保留现有数据（手牌、动作等）
- ✅ 只补充缺失的信息（比赛结果、排名）
- ✅ 速度快，不需要重新解析所有数据
- ✅ 不会丢失数据

**缺点**：
- ⚠️ 需要找到对应的.rep文件
- ⚠️ 如果.rep文件不存在，无法更新

**适用场景**：
- 现有JSON数据基本完整
- 只需要补充比赛结果
- .rep文件可用

### 方案2: 重新从.rep文件转换

**优点**：
- ✅ 数据完全来自.rep文件，更可靠
- ✅ 可以重新验证所有数据

**缺点**：
- ❌ 需要重新解析所有数据
- ❌ 可能丢失现有JSON中的额外信息
- ❌ 速度较慢

**适用场景**：
- 现有JSON数据有问题
- 需要完全重新生成
- .rep文件是唯一数据源

## 🚀 推荐方案：批量更新

### 使用批量更新脚本

```bash
python scripts/tools/batch_update_json_from_rep.py
```

### 脚本功能

1. **自动查找对应的.rep文件**
   - 根据JSON文件名中的日期时间查找
   - 支持多个可能的.rep文件位置

2. **从.rep文件提取比赛结果**
   - 提取Rank动作（排名信息）
   - 提取GameEnd动作（游戏结束状态）
   - 推断所有玩家的排名

3. **更新JSON数据**
   - 更新`game_info.game_result`（从"unknown"改为"win"/"loss"）
   - 添加`game_info.rank`（玩家排名）
   - 添加`game_info.rank_name`（排名名称：头游/二游/三游/四游）
   - 添加`game_info.all_ranks`（所有玩家排名映射）

4. **保留现有数据**
   - 不修改手牌、动作等现有数据
   - 只补充缺失的比赛结果信息

### 更新后的数据格式

**更新前**：
```json
{
  "game_info": {
    "curRank": "2",
    "game_result": "unknown"
  }
}
```

**更新后**：
```json
{
  "game_info": {
    "curRank": "2",
    "game_result": "loss",  // ✅ 真实的比赛结果
    "rank": 3,              // ✅ 玩家排名
    "rank_name": "三游",     // ✅ 排名名称
    "all_ranks": {          // ✅ 所有玩家排名
      "1": 1,
      "2": 3
    }
  },
  "_conversion_meta": {
    "result_updated_from_rep": true,  // ✅ 标记已更新
    "rep_file": "..."                 // ✅ .rep文件路径
  }
}
```

## 📊 更新统计

脚本会显示：
- ✅ 成功更新的文件数
- ℹ️ 已有结果（无需更新）的文件数
- ⚠️ 未找到.rep文件的文件数
- ⚠️ 无法提取结果的文件数
- ❌ 错误的文件数

## ⚠️ 注意事项

### 1. .rep文件位置

默认查找路径：
- `C:\Program Files (x86)\gdgame\MobileGD\replay\`
- 如果.rep文件在其他位置，需要修改脚本中的查找逻辑

### 2. 文件名匹配

脚本根据JSON文件名中的日期时间查找对应的.rep文件：
- JSON: `replay_player3__2024-02-04_12_15_56.json`
- .rep: `szqjl_2024-02-04_12_20_23_/_2024-02-04_12_15_56.rep`

如果文件名格式不匹配，可能无法找到对应的.rep文件。

### 3. 数据备份

**建议在更新前备份数据**：
```bash
# 备份game_records目录
cp -r game_records game_records_backup
```

## 🔄 更新流程

1. **备份数据**（可选但推荐）
2. **运行更新脚本**
   ```bash
   python scripts/tools/batch_update_json_from_rep.py
   ```
3. **检查更新结果**
   - 查看统计信息
   - 检查更新后的JSON文件
4. **验证数据**
   - 确认比赛结果已更新
   - 确认排名信息已添加
