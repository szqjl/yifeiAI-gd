# 掼蛋AI可视化回放系统使用说明

## 简介
掼蛋AI可视化回放系统是一个图形化界面的游戏回放工具，用于直观展示掼蛋AI的决策过程和游戏进程。

## 功能特性

### 基础功能
- ✅ 图形化游戏记录选择
- ✅ 实时牌面可视化渲染
- ✅ 基础回放控制（播放/暂停/上一步/下一步）
- ✅ 自动播放功能，支持速度调节
- ✅ 游戏进度条拖动
- ✅ 玩家剩余牌数实时显示
- ✅ 当前动作详细信息展示

### 高级功能（开发中）
- ⏳ 决策分析面板
- ⏳ 规则违反自动标记
- ⏳ 多AI对比分析
- ⏳ 统计图表生成

## 使用方法

### 方法1：直接运行批处理文件
1. 双击运行 `REPLAY_GAME.bat` 文件
2. 在弹出的可视化界面中选择游戏记录
3. 使用控制按钮进行回放

### 方法2：命令行运行
1. 打开命令行终端
2. 进入项目根目录
3. 运行命令：`python replay_gui.py`

## 界面说明

### 1. 顶部工具栏
- **游戏记录**：下拉选择要回放的游戏记录
- **刷新列表**：刷新游戏记录列表

### 2. 回放控制区
- **播放/暂停**：控制回放的开始和暂停
- **上一步/下一步**：单步控制回放
- **进度条**：拖动调整回放进度
- **速度调节**：调整自动播放速度（0.1x - 5.0x）

### 3. 牌面展示区
- **玩家位置**：显示4个玩家的位置和名称
- **剩余牌数**：实时显示每个玩家的剩余牌数
- **当前动作**：可视化展示当前玩家打出的牌
- **步骤信息**：显示当前步骤的详细信息

### 4. 游戏信息区
- 显示游戏的基本信息，包括文件名、大小、修改时间等

## 快捷键说明
- **空格**：播放/暂停
- **左箭头**：上一步
- **右箭头**：下一步

## 游戏记录格式
支持回放系统生成的JSON格式游戏记录，文件位于 `game_records` 目录下。

## 注意事项
1. 确保Python环境已正确配置
2. 首次运行可能需要加载游戏记录列表，请耐心等待
3. 对于大型游戏记录，加载可能需要一定时间
4. 如果遇到界面卡顿，可以降低自动播放速度

## 常见问题

### Q: 为什么无法选择游戏记录？
A: 请确保 `game_records` 目录下有JSON格式的游戏记录文件。

### Q: 为什么播放没有反应？
A: 请检查是否已选择游戏记录，或者游戏记录中是否包含动作数据。

### Q: 如何调整界面大小？
A: 可以直接拖动窗口边缘调整大小。

```powershell

```

### 方法3：直接使用Python脚本

```powershell
# 设置环境变量
$env:PYTHONPATH="D:\guandanscore\YiFeiAI-GD\src"

# 基础回放
python src\communication\replay_select.py

# 交互式回放
python src\communication\replay_select.py --interactive
```

## 功能特点

### 基础回放模式
- 快速查看完整游戏回放
- 显示所有出牌步骤
- 自动分析规则使用情况

### 交互式回放模式（推荐）
- **上一步/下一步**：逐步查看游戏过程
- **自动播放**：自动按步骤回放
- **实时规则分析**：显示当前步骤的规则违反情况
- **控制键**：
  - `1` - 开始自动播放
  - `2` - 停止自动播放
  - `3` - 下一步
  - `4` - 上一步
  - `q` - 退出
  - 回车 - 默认下一步

## 注意事项

1. 确保Python环境已正确安装
2. 确保所有依赖包已安装：`pip install -r requirements.txt`
3. 如果遇到编码问题，使用PowerShell脚本而不是批处理脚本
4. 游戏记录需要先运行游戏并保存后才能回放

## 故障排除

### 问题：找不到模块 'communication'
**解决**：确保设置了PYTHONPATH环境变量，或使用提供的脚本（已自动设置）

### 问题：未找到游戏记录
**解决**：先运行游戏以生成记录文件，记录会自动保存在 `game_records/` 目录

### 问题：PowerShell执行策略错误
**解决**：运行 `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
