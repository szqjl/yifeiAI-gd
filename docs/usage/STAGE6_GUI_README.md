# 🎯 阶段6游戏导向训练GUI工具

## 📖 简介

阶段6游戏导向训练GUI是专门为"从预测准确转向赢得游戏"的训练目标设计的可视化训练工具。它提供了实时监控、策略原因学习效果展示、胜率导向损失可视化等阶段6核心功能。

## 🚀 快速开始

### 方式1：双击启动（推荐）
直接双击 `run_stage6_training_gui.bat` 文件启动图形化界面

### 方式2：命令行启动
```bash
cd D:\YiFeiAI-GD
python run_stage6_training_gui.py
```

### 系统要求
- Python 3.7+
- PyTorch
- tkinter (通常随Python安装)
- matplotlib
- numpy

## 🎯 阶段6核心理念展示

GUI顶部展示了阶段6的核心理念：
- 从"预测卡牌的AI" → "赢得游戏的AI"

## ⚙️ 训练配置

### 基本配置
- **训练数据目录**: 存放训练数据的目录（默认: `game_records`）
- **训练轮数**: 建议100轮（阶段6需要更多轮次来学习策略原理）
- **批次大小**: 默认64
- **学习率**: 默认0.0002（比阶段5更低，以适应新损失函数）
- **模型保存路径**: 训练完成后保存的模型路径

### 阶段6特色配置
- ✅ **策略原因学习**: 学习26类策略原因类型
- ✅ **胜率导向损失**: 基于策略有效性的权重调整
- ✅ **动态阈值调整**: 根据游戏阶段自动调整预测阈值
- ✅ **自动评估**: 训练完成后自动进行游戏导向评估

## 🚨 注意事项

1. **内存使用**: 阶段6训练需要更多内存，建议使用足够的RAM
2. **训练时间**: 100轮训练可能需要较长时间，请耐心等待
3. **磁盘空间**: 模型文件和检查点会占用磁盘空间
4. **CUDA支持**: 如有GPU，训练速度会显著提升

## 🆘 故障排除

### 常见问题
- **GUI无法启动**: 检查tkinter是否正确安装
- **训练失败**: 检查训练数据目录和文件权限
- **内存不足**: 减少批次大小或使用CPU训练
- **图表不更新**: 确保matplotlib正确安装

### 日志分析
通过训练日志分析问题：
- 查看错误信息和警告
- 关注准确率和损失值的变化趋势
- 检查模型保存是否成功
