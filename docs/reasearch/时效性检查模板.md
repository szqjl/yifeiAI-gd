# 调研文档时效性检查模板

> 将以下内容添加到每个调研文档的**顶部**（frontmatter 区域）

---

## 📋 Frontmatter 模板

在每个调研文档开头添加：

```yaml
---
created: YYYY-MM-DD
updated: YYYY-MM-DD  # 最后修改日期
reviewed: YYYY-MM-DD  # 最后回顾日期
status: 活跃 / 待更新 / 已过期  # 见下方状态定义
tags: [调研，分类标签]
related_gua: [GUA-xxx, GUA-yyy]  # 关联的缺陷编号
related_iter: [迭代名]  # 关联的迭代
next_review: YYYY-MM-DD  # 下次回顾日期
---
```

---

## 🟢 状态定义

| 状态 | 定义 | 操作 |
|------|------|------|
| 🟢 **活跃** | 结论仍适用，已部分落地 | 每季度回顾 |
| 🟡 **待更新** | 结论部分过时，需要补充新信息 | 1 个月内更新 |
| 🔴 **已过期** | 结论已完全过时或被证伪 | 标记归档，创建新版 |

---

## ✅ 时效性检查清单

### 基础检查（每次打开文档时）

- [ ] 检查 `updated` 是否超过 3 个月
- [ ] 检查 `related_gua` 中的 GUA 是否已关闭
- [ ] 检查是否有新的竞品/平台/技术出现

### 深度检查（每季度）

- [ ] 逐条检查核心结论是否仍适用
- [ ] 检查是否有项目决策推翻了调研结论
- [ ] 检查是否有新的 GUA/ITERATIONS 需要关联
- [ ] 更新 `reviewed` 和 `next_review`

### 项目里程碑后

- [ ] 检查调研建议是否已落地
- [ ] 在文档中添加"落地情况"章节
- [ ] 更新索引文档的统计表格

## 📝 文档结构建议

每个调研文档应包含：

```markdown
# 标题

<!-- Frontmatter -->

## 🎯 核心结论（3-5 条）

1. 结论 1
2. 结论 2
3. 结论 3

## 📊 详细分析

### 子主题 1
### 子主题 2

## 🔗 与项目关联

### 已落地
- [ ] 建议 1 → GUA-xxx / PR-yyy
- [ ] 建议 2 → TASK-zzz

### 待验证
- [ ] 建议 3 → 待实验

### 已过期
- ~~过时的结论~~ （删除线标记）

## 📚 参考资料

- 来源 1
- 来源 2

## 📅 更新日志

| 日期 | 更新内容 | 更新者 |
|------|---------|--------|
| YYYY-MM-DD | 初次创建 | 姓名 |
| YYYY-MM-DD | 补充 XXX | 姓名 |
```

## 🚨 过时结论标记方法

### 方法 1：删除线 + 注释

```markdown
~~过时的结论~~ 

> ⚠️ **已过期** (2026-06-02): 原因说明
> **替代方案**: 新结论或参考文档
```

### 方法 2：警告块

```markdown
> [!WARNING] 已过时
> 此结论在 2026-05-31 的批跑实验中被证伪
> 见 [[../guandan-brain/ITERATIONS#2026-05-31]]
```

### 方法 3：状态表格

在文档末尾添加：

```markdown
## 结论状态追踪

| 结论 | 状态 | 更新日期 | 备注 |
|------|------|---------|------|
| 结论 1 | ✅ 已落地 | 2026-05-31 | GUA-026 |
| 结论 2 | ⏳ 待验证 | 2026-05-31 | 需更多样本 |
| 结论 3 | ❌ 已证伪 | 2026-06-01 | 见 ITERATIONS |
```

---

## 💡 最佳实践

1. **创建时即标注**: 新建文档时就填写 frontmatter
2. **关联可点击**: 用 `[[文档名]]` 或 `[文本](路径)` 链接到相关文档
3. **结论可追溯**: 每条核心结论都应有关联的 GUA/ITERATIONS
4. **定期清理**: 每季度检查一次，标记过时内容
5. **版本控制**: 重大更新时创建新版本，保留历史记录

## 📋 快速检查命令

在 PowerShell 中检查所有调研文档的最后修改时间：

```powershell
Get-ChildItem "docs\reasearch\*.md" | Select-Object Name, LastWriteTime | Sort-Object LastWriteTime
```

在 Git 中查看文档更新历史：

```bash
git log --oneline docs/reasearch/
```
