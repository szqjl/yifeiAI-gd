# 掼蛋规则（二）胜负与目标

本文档为掼蛋 AI 的**胜负目标与决策依据**。所有决策引擎、策略和 RL 设计都应与此对齐。  
常量与名次定义见：`src/game_logic/guandan_constants.py`。

---

## 1. 每副牌的目标（必须遵守）

- **每副牌都要争头游；己方头游 + 二游即获胜。**
- 表述（代码常量 `GAME_OBJECTIVE`）：  
  **「每副牌争头游，己方头游+二游即获胜；牌力强主攻冲刺，牌力弱助攻掩护。」**
- **强化赢的意识**（`WIN_FIRST_PRIORITY`）：  
  **「本局唯一目标：己方赢（头游+二游）；一切出牌围绕争头游、保二游，不赢则无意义。」**  
  策略与优先级在 context 带 `game_objective` / `win_first_priority` 时，应对「有利于己方赢」的决策加分（如一手出完、冲刺、掩护队友）。

---

## 2. 名次与获胜方

- **头游**：最先出完牌的玩家（名次 1）。
- **二游**：第二个出完（名次 2）。
- **三游**：第三（名次 3）；**末游**：最后（名次 4）。
- **获胜方**：头游与二游属于同一方时，该方获胜（`WINNING_RANKS = (1, 2)`）。

---

## 3. 在代码中的使用方式（让其他 AI / 后续开发记住）

- **规则层**：`guandan_constants.py` 中定义 `GAME_OBJECTIVE`、`RANK_*`、`RANK_NAMES`、`WINNING_RANKS`。
- **主决策入口**：M1 / V5 / Stage5 会在 **context** 或 **message** 中注入本条目标，供下游使用：
  - **M1（stage_router）**：`context['game_objective']`、`context['win_first_priority']`（强化赢意识）、`context['winning_ranks']`。
  - **V5 / Stage5（HybridDecisionEngineV5、YF_V5_Stage5_DecisionEngine）**：`message['_game_objective']`（内部键，不发给服务器）。
- **策略、规则与 RL**：应通过以下方式做**目标对齐**（优先级、奖励设计、角色分工等）：
  - 使用 `context.get('game_objective')`（阶段处理器、优先级系统等）；
  - 或 `message.get('_game_objective')`（V5/Stage5 下游）。
- 新增或修改决策逻辑时，应阅读本规则并保持与「争头游、头游+二游即获胜」一致。
