一、全局底层约束（AI 每轮执行前校验，违反则禁止出牌）
约束 1：队友领牌时动作规则（优先级最高）
IF 领牌方 = 队友（主攻）：
仅可顺最小零碎牌（单只顺 5-9、对只顺 33-77，三带 / 顺子直接 PASS）
禁止使用 A、级牌、王、炸弹压队友领出牌
禁止拆自身完整配套牌型顺牌
禁止抢牌权，无条件让队友回收出牌权
ELSE 领牌方 = 上家 / 下家（对手）：进入对手领牌决策分支

约束 2：炸弹使用硬性锁死规则
开局阶段：禁止主动开炸弹领牌
炸弹触发开炸仅 3 种合法场景（其余场景一律 PASS）
场景 A：对手压制队友进攻
场景 B：对手剩余≤10 张，具备冲刺风险
炸弹分配逻辑：小炸弹优先解围，大炸弹留残局拦截对手冲刺

约束 3：组牌永久保留规则
队友高频打出的牌型，自身必须保留完整一套，不得拆散
长顺子全程不拆，仅顺最小散牌消耗单张
红桃配不用于自身组牌跑牌，仅预留补队友所需牌型

二、分阶段完整落盘决策树（AI 按轮次阶段执行）
阶段 1：开局（stage_1轮，局势探路）
分支 1.1 AI 获得首轮领出牌权
出牌优先级从高到低：
最小对子（33~77）→ 信号告知队友助攻，标准开局动作
单牌极多无小对子：出 6-10 以上中单吊下家，严禁 3/4/5 极小单
禁止动作：顺子、连对、三带、炸弹、大单张（A / 级牌）首发

分支 1.2 对手领牌，AI 判定是否管牌
上家领小牌型：必须用 / 级牌 / 大小王顶上，逼对手消耗大牌，减少队友压力
下家领极小散牌：直接大牌卡死，禁止放小牌让下家顺牌
对手长顺子 / 连对：无必要不消耗大牌，仅在对手剩牌少再管
队友不要该牌型：强制压死，切断对手循环领牌路线

分支 1.3 开局手牌整理逻辑
优先消耗孤立极小单，保留多套匹配队友的完整牌型
炸弹完整封存，不参与开局消耗

阶段 2：中局拉锯（stage_2）
分支 2.1 AI 拿到出牌权（炸赢 / 压赢对手后）
固定出牌逻辑：只输出队友打过的同款牌型
量化匹配规则：
队友常单 → 输出 6~10 中小单，便于队友 级牌 / 王接手
队友常对子 → 输出 55~JJ 中等对子，不输出超大对子压制
队友常三带二 → 输出最小三带二，保留大三带残局用
队友常短顺子 → 输出等长度最小顺子
禁止行为：自创队友从未出过的牌型（顺子 / 连对等）

分支 2.2 对手压制队友（队友出牌被对手大牌封住）
执行流水线：
立刻开最小可用炸弹拿牌权
炸弹落地后，直接输出队友刚刚被封的同款牌型送接风
无同款则拆最小零散牌凑同款，不换其他牌型

分支 2.3 对手持续领牌压制队友
上家无限领小牌：每轮必须顶大牌，不全程 PASS
下家持续顺零碎：全程卡死，仅拿到牌权时送队友所需牌型

阶段 3：残局（任意玩家手牌≤8 张，冲刺阶段）
分支 3.1 队友剩余牌数匹配送牌规则（AI 领牌时唯一出牌标准）
队友剩 1 张：仅输出最小单张，禁止对子 / 三带 / 顺子
队友剩 2 张：仅输出最小对子，禁止单张
队友剩 3 张：输出小三不带 / 小三带二
队友剩 4 张：优先中等对子，备选小三带
队友剩 5 张：输出 三带二或5连最小顺子
队友≥6 张：回归中局匹配牌型逻辑

分支 3.2 对手进入听牌（对手≤5 张）
主动消耗大王、炸弹拦截对手冲刺
自身剩余牌全部作废，优先封锁对手头游可能
哪怕放弃送牌机会，也要压制对手冲刺牌型

分支 3.3 队友仅剩 2~3 张，即将头游
可拆单枚小型炸弹凑精准送牌型
所有大牌全部用于开路送牌，不预留防守

三、对手领牌标准化响应函数（AI 通用接口）
输入参数：领牌方、领出牌型、领牌点数、对手剩余张数、队友剩余张数
输出三选一动作：PASS / 压牌 / 开炸
领牌方 = 队友：仅顺最小散牌，其余全部 PASS
领牌方 = 上家，牌型偏小：执行顶牌（最小可压制大牌）
领牌方 = 下家，极小散牌：执行卡死（中等大牌压制）
对手用大王 / 炸弹封队友：输出开炸动作
对手剩余≤5 张且牌型整齐：开炸拦截
无上述条件：输出 PASS

四、AI 禁止动作黑名单（每轮校验，命中直接拦截出牌）
队友领牌时用 A、级牌、王、炸弹压牌
开局主动出炸弹、长顺子、连对
拿到牌权输出队友从未打出的陌生牌型
前期拆配套三带、顺子、连对消耗
对手未压制队友、对手无冲刺风险时主动开炸弹
残局送牌时牌型与队友剩余张数不匹配
红桃逢人配用于自身组牌跑牌，不预留送队友
自身抢头游，消耗关键大牌阻断队友进攻链
