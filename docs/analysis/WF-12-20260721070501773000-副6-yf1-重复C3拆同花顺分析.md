### 管线还原

1. **GUA-091 中局推荐**：推荐原组牌 `Straight S7 S8 S9 HT HJ`。
2. **GUA-075 匹配失败**：日志显示该推荐无法匹配平台 `actionList`，主路径未返回。
3. **R13 Guard**：剔除 6 个平台标成炸弹/同花顺但实际不符的候选。
4. **组牌前置过滤**：日志称“移除 11/13 个拆核心动作，保留 2”，但错误保留 `Trips/3`。
5. **启发式回退**：在 2 个候选中选择原始 actIndex=33，最终打出 `Trips/3`。

### 两个判定为何正好相反

`to_card_mask()` 按组型顺序写入：先写 `StraightFlush`，后写 `ThreePair` 子组。赋值语句是 `mask[card] = (gid, ...)`，所以同名键发生以下覆盖：

```text
写 gid0 StraightFlush：C3 → gid0
写 gid4 33 子组：      C3 → gid4（覆盖 gid0）
最终 card_mask[C3] = gid4
group_members[0] 与 group_members[4] 仍分别保留各自的 C3
```

#### `Trips/3` 为何被误判为完整组

1. `_get_broken_core_type()` 逐张执行 `card_mask.get(card)`，得到 `[4,4,4]`，`touched_gids={4}`。
2. gid4 的真实成员是 `[D3,C3]`；多集合交集 `used=2`，组大小 `total=2`。
3. 函数只在 `0 < used < total` 时判拆核；这里 `used==total`，额外的第二张 `C3` 没有被检查是否来自别的 gid，于是返回 `broken=None`。
4. `_is_partial_composite_lead()` 只拦 `Pair` 拆 `pair_in_three_pair`，没有覆盖“`Trips` 吃完整 pair 子组 + 外部同点牌”的组合，因此也返回 `False`。
5. 启发式 `_is_group_consistent()` 只计算 gid 集合大小；`set([4,4,4])={4}`，于是判一致并加 `+10000`，不校验动作 3 张是否超过 gid4 的 2 张容量。

#### 完整 `StraightFlush` 为何反而被删除

1. 动作 `C2 C3 C4 H7 C6` 查单值 mask 得到 `[0,4,0,0,0]`，`touched_gids={0,4}`。
2. 对 gid0，同花顺五张全部匹配，未拆；但对 gid4，动作拿到一个 `C3`、未拿 `D3`，得到 `used=1,total=2`。
3. `_get_broken_core_type()` 因此返回 `pair_in_three_pair`；主攻过滤规则把它当成拆三连对子核心并删除。
4. 即使跳过硬过滤，启发式也会因 gid 集合大小为 2 判“不一致”，再按两个 core gid 给予 `-300` 拆局扣分。

真实函数最小复现：过滤输入 `[Trips/3, StraightFlush]`，输出只剩 `[Trips/3]`；直接让启发式给两者评分时分别为 `9977` 与 `-254`。

### 根因

- **R-D04：正确的实例级灵活组牌在导出为单值 mask 时丢失多归属。** 两副牌有两个 `C3`，一个在 gid0 同花顺、一个在 gid4 的 33 子组；但 `card_mask` 是 `Dict[str, tuple]`，只能存一个 `C3`。后写覆盖后得到 `card_mask['C3']=(4,1.0,2)`，同花顺候选归属丢失。
- `_get_broken_core_type()` 先通过单值 `card_mask` 枚举 touched gids。对 `Trips/3` 得到 `[4,4,4]`，再与 gid4 成员 `[D3,C3]` 比较，误判 `broken=None`。
- **R-D05：启发式评分被错误表示放大。** `_is_group_consistent()` 只看 gid 集合大小，三个牌串均映射 gid4，于是误判一致并加 `+10000`；动作包含 3 张、gid4 实际只有 2 张也未校验。
- 反向误判：完整同花顺中的 `C3` 也映射 gid4，所以完整 `StraightFlush` 会呈现 gids `[0,4,0,0,0]`，被当作跨组拆局。

最小复现结果：

```text
Trips3         gids=[4,4,4]     broken=None                heuristic_consistent=True
StraightFlush gids=[0,4,0,0,0] broken=pair_in_three_pair heuristic_consistent=False
```
