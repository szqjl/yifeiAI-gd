# 拆炸弹问题分析与修复

## 问题描述

YF策略在决策时经常出现拆炸弹的情况，导致炸弹资源浪费。

## 问题根源分析

### 1. 逻辑顺序问题

**原始代码逻辑**（736-750行）：
```python
if is_natural_single and not is_rank_card:
    score_adjustment += 40.0  # 天然单张加分
elif action_rank_val >= 15:
    score_adjustment += 35.0  # 大牌值加分
elif is_rank_card:
    score_adjustment += 20.0  # 级牌加分
elif is_in_bomb or is_in_straight:
    score_adjustment -= 15.0  # 拆炸弹减分
```

**问题**：
- 根据`combine_handcards`的定义，天然单张是指某个rank只有一张的牌，理论上不应该在炸弹中
- **但是，如果一张牌在顺子中（`is_in_straight`），它可能同时是天然单张**（在组成顺子之前，它是天然单张；组成顺子后，它在顺子中）
- 原始代码中，如果一张牌是天然单张，只会执行第一个`if`分支（+40分）
- 不会执行`elif is_in_bomb or is_in_straight`分支（-15分）
- **最终得分：+40分，如果这张牌实际上在顺子中，就会导致拆顺子的单张得分反而更高！**
- 同样，如果一张牌在炸弹中（虽然理论上不应该同时是天然单张），也会因为逻辑顺序问题导致拆炸弹的单张得分更高

### 2. 减分力度不足

- Normal模式：拆炸弹只减15分，而天然单张加40分，净得分+25分
- Special模式：拆炸弹减30分，但special模式非炸弹单张加50分，净得分+20分
- 主动出牌策略：单张满足阈值时加20分，没有检查是否在炸弹中

### 3. 主动出牌策略未检查炸弹

主动出牌策略（820-824行）只检查单张是否满足阈值，没有检查是否在炸弹中，导致拆炸弹的单张仍然可能获得加分。

## 修复方案

### 1. 调整判断顺序（优先级修复）

**修复后逻辑**：
```python
# 先检查是否在炸弹/顺子中，如果是则大幅减分
if is_in_bomb or is_in_straight:
    score_adjustment -= 50.0  # 大幅增加拆炸弹的惩罚
elif is_natural_single and not is_rank_card:
    score_adjustment += 40.0  # 天然单张加分
# ... 其他情况
```

**效果**：
- 拆炸弹的检查优先级最高
- 即使牌是天然单张，只要在炸弹中就大幅减分
- 避免拆炸弹的单张获得高分

### 2. 增加减分力度

| 模式 | 修复前 | 修复后 | 说明 |
|------|--------|--------|------|
| Normal模式 | -15分 | -50分 | 大幅增加惩罚，确保拆炸弹得分远低于不拆炸弹 |
| Special模式 | -30分 | -80分 | Special模式更严格，几乎禁止拆炸弹 |

### 3. 主动出牌策略增加炸弹检查

在主动出牌策略中，检查单张是否在炸弹中：
```python
if is_in_bomb_for_active:
    score_adjustment -= 30.0  # 拆炸弹减分
    strategy_reason = "避免拆炸弹（即使满足阈值）"
elif action_rank_val_for_active < active_cur[0]:
    score_adjustment += 20.0  # 正常加分
```

## 修复效果预期

### 修复前
- 天然单张在炸弹中：+40 - 0 = +40分（未执行减分）
- 大牌值单张在炸弹中：+35 - 0 = +35分（未执行减分）
- 主动出牌单张在炸弹中：+20 - 0 = +20分（未检查炸弹）

### 修复后
- 天然单张在炸弹中：-50分（优先执行减分）
- 大牌值单张在炸弹中：-50分（优先执行减分）
- 主动出牌单张在炸弹中：-30分（主动检查炸弹）

### 对比示例

假设有两个单张动作：
- 动作A：天然单张，不在炸弹中 → +40分
- 动作B：天然单张，在炸弹中 → -50分

**修复前**：动作B可能得分更高（如果其他因素影响）
**修复后**：动作A得分明显高于动作B，优先选择动作A

## 特殊情况处理

### 1. 残局情况

残局时（下家剩<=4张），如果必须出单张且只有炸弹中的单张可用，可能需要特殊处理。当前修复中，残局逻辑仍然优先检查是否在炸弹中，确保不轻易拆炸弹。

### 2. Special模式

Special模式（连续PASS过多）时，拆炸弹的惩罚更严格（-80分），几乎完全禁止拆炸弹，符合"不使用炸弹/顺子中的牌"的策略。

3. **测试场景3**：主动出牌时，有多个单张可选
   - 预期：优先选择不在炸弹中的单张

   - 预期：严格避免拆炸弹，即使其他单张得分较低
