# 天然单张定义说明

## 定义

**天然单张**：指手牌中某个rank（点数）只有一张的牌。

例如：
- 手牌中有且仅有一张3（如`S3`），没有其他花色的3，也没有对子、三张、炸弹等，则`S3`是天然单张
- 手牌中有两张3（如`S3`和`H3`），则它们不是天然单张，而是对子
- 手牌中有四张3（如`S3`、`H3`、`C3`、`D3`），则它们不是天然单张，而是炸弹

## 代码实现

### combine_handcards函数

在`src/communication/utils.py`的`combine_handcards`函数中：

1. **第一次统计**（23-34行）：
   - 按rank统计手牌
   - 如果某个rank只有1张：加入`cards["Single"]`
   - 如果某个rank有2张：加入`cards["Pair"]`
   - 如果某个rank有3张：加入`cards["Trips"]`
   - 如果某个rank有4张或更多：加入`cards["Bomb"]`

2. **组成顺子后重新统计**（309-319行）：
   - 从手牌中移除组成顺子的牌，得到`nowhandcards`
   - 对`nowhandcards`重新统计
   - 如果某个rank只有1张：加入`newcards["Single"]`
   - 最终返回的`sorted_cards["Single"]`就是`newcards["Single"]`

### 使用方式

在`src/communication/yf2_v5.py`中：

```python
# 组合手牌，获取天然单张、炸弹、顺子等信息
sorted_cards, bomb_info = combine_handcards(hand_cards, cur_rank, card_val)
single_member = sorted_cards.get("Single", [])  # 天然单张列表
bomb_member = []  # 炸弹成员列表
for bomb in sorted_cards.get("Bomb", []):
    bomb_member.extend(bomb)

# 判断是否是天然单张
is_natural_single = action_card in single_member
# 判断是否在炸弹中
is_in_bomb = action_card in bomb_member
```

## 重要特性

### 1. 天然单张不会在炸弹中

根据定义和代码逻辑：
- 如果某个rank只有1张，它就是天然单张，不会是炸弹
- 如果某个rank有4张或更多，它就是炸弹，不会是天然单张
- **理论上，一张牌不应该既是天然单张又在炸弹中**

### 2. 天然单张可能在顺子中

- 如果一张牌是天然单张，但被用来组成顺子了，它就不会出现在最终的`newcards["Single"]`中
- 如果一张牌在顺子中（`is_in_straight`），它可能曾经是天然单张，但现在在顺子中

### 3. 级牌的特殊处理

- 级牌（当前等级）可能有特殊处理
- 红桃配（H2）可能有特殊处理
- 但这些不影响天然单张的基本定义

## 测试验证

运行`test_natural_single.py`可以验证：
- 天然单张的定义是否正确
- 天然单张是否会在炸弹中（应该不会）
- 各种边界情况

## 修复建议

**重要说明**：
- 根据`combine_handcards`的逻辑，一张牌不应该既在`bomb_member`中又在`single_member`中
- 但是，**一张牌可能既是天然单张又在顺子中**（在组成顺子之前是天然单张，组成顺子后在顺子中）
- 如果发现"单张既是天然单张又在炸弹中"的情况，可能的原因：
  1. **级牌或特殊牌的处理问题**：检查级牌、红桃配等特殊牌的处理逻辑
  2. **顺子组成逻辑问题**：检查顺子组成时是否正确移除了相关牌
  3. **判断逻辑问题**：检查`is_natural_single`和`is_in_bomb`的判断是否正确
  4. **边界情况**：某些特殊情况下，代码逻辑可能出现问题
