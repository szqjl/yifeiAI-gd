# 1312掼蛋数据格式分析

## 📋 数据来源
1312掼蛋平台的真实比赛记录数据，包含完整的游戏对局信息。

## 🔍 数据格式分析

### 1. 当前数据格式（JSON）

```json
{
  "player_id": 0,
  "initial_hand": ["D9", "C2", "C3", ...],
  "actions": [
    {
      "cur_pos": 0,
      "cur_action": "['Discard', 'Discard', ['C4', 'DA']]"
    }
  ]
}
```

### 2. 数据字段说明

#### ✅ 已有字段
- **player_id**: 玩家ID（0-3）
- **initial_hand**: 初始手牌列表（26张牌）
- **actions**: 动作序列
  - **cur_pos**: 执行动作的玩家位置
  - **cur_action**: 动作字符串，格式为 `['Discard', 'Discard', [卡牌列表]]`

#### ❌ 缺失字段（需要补充）
- **all_players_hands**: 所有玩家的手牌信息
- **game_info**: 游戏信息
  - **curRank**: 当前级牌等级（如"4"、"A"）
  - **game_result**: 游戏结果（胜负信息）
- **result**: 游戏最终结果（哪个队伍获胜）

### 3. 从图片信息推断的补充数据

根据图片描述，可以推断以下信息：

#### 级牌等级
- **本方级牌**: "4"（Level 4）
- **对方级牌**: "A"（Level A）

#### 玩家手牌信息
从图片中可以推断各玩家的手牌分布：
- **Top Player**: 已出牌信息
- **Bottom Player**: 已出牌信息
- **Left Player**: 手牌信息（包含三张、对子、四张等）
- **Right Player**: 手牌信息（包含大小王、单张、对子、三张、四张等）

### 4. 卡牌编码格式

1312平台使用的卡牌编码：
- **花色**: C（梅花）、D（方块）、H（红心）、S（黑桃）
- **点数**: 2-9, T（10）, J, Q, K, A
- **特殊牌**: R（大王/红心配）、B（小王/黑心配）

示例：
- `CA`: 梅花A
- `HT`: 红心10
- `R`: 大王/红心配
- `B`: 小王/黑心配

### 5. 动作格式解析

动作字符串格式：`['Discard', 'Discard', ['C4', 'DA']]`
- 第一个元素：动作类型（Discard/PASS）
- 第二个元素：重复的动作类型
- 第三个元素：卡牌列表

## 🔄 转换需求

### 目标格式（ReplayParser期望格式）

```json
{
  "player_id": 0,
  "initial_hand": ["D9", "C2", ...],
  "all_players_hands": {
    "0": ["D9", "C2", ...],
    "1": [...],
    "2": [...],
    "3": [...]
  },
  "game_info": {
    "curRank": "4",
    "game_result": "win"  // 或 "loss"
  },
  "actions": [
    {
      "cur_pos": 0,
      "cur_action": "['Discard', 'Discard', ['C4', 'DA']]"
    }
  ]
}
```

### 转换策略

1. **补充all_players_hands**
   - 从initial_hand推断其他玩家手牌（如果可能）
   - 或使用默认值（空列表）

2. **补充game_info**
   - **curRank**: 从文件名或数据中提取，默认"2"
   - **game_result**: 需要从游戏结果推断（如果数据中有）

3. **验证数据完整性**
   - 检查手牌数量（应为26张）
   - 检查动作序列的合理性
   - 验证卡牌编码格式

1. **级牌等级处理**
   - 如果无法从数据中提取，使用默认值"2"
   - 或从文件名中提取（如果包含）

2. **游戏结果处理**
