# 掼蛋 AI 队友与对方识别说明

## 规则约定

掼蛋为 4 人两两一队：

- **座位 0 与 2** 为一队  
- **座位 1 与 3** 为一队  

因此：

- **队友位置**：`teammate_pos = (my_pos + 2) % 4`
- **对手位置**：`(my_pos + 1) % 4`（下家）、`(my_pos + 3) % 4`（上家）

## 实现位置

### 1. 统一工具（`src/communication/game_recorder.py`）

- `get_teammate_pos(my_pos)`：根据己方座位返回队友座位
- `get_opponent_positions(my_pos)`：返回两名对手座位元组
- `is_teammate(my_pos, other_pos)`：判断 `other_pos` 是否为己方队友
- `ensure_my_pos_int(data, fallback_player_id)`：从消息中安全取出 `myPos` 并转为 int（优先 `myPos`，其次 `playerPosition`）

### 2. 座位同步（服务器 myPos）

各客户端在**游戏开始**或**首次 act** 时，用服务器下发的 `myPos` 更新本地 `self.player_id`，保证后续队友/对手计算一致：

| 系列 | 同步时机 | 说明 |
|------|----------|------|
| M1   | `_handle_game_start`、首包 act 触发开局 | 使用 `ensure_my_pos_int` |
| V4   | `handle_notification` 中 `stage == "beginning"` | 使用 `ensure_my_pos_int`，并更新 `self.player_id` |
| V5 / V5_stage5 | `handle_notification` 中 `is_beginning` | 已有 myPos 更新逻辑 |
| V7   | `handle_game_start`、`handle_action_request` | 使用 `ensure_my_pos_int`，并注入 `action_data["myPos"]` 供决策引擎使用 |

### 3. 决策层使用

- **M1**：`stage_router`、`phase_handlers` 中通过 `(my_pos in [0,2] and pos in [0,2]) or (my_pos in [1,3] and pos in [1,3])` 判断队友，等价于 `(my_pos + 2) % 4 == pos`。
- **V5 / V5_stage5**：`_extract_game_state` 中 `teammate_pos = (my_pos + 2) % 4`，对手为 `(my_pos+1)%4` 与 `(my_pos+3)%4`。
- **V7**：决策引擎从 `game_state.get("myPos", self.player_id)` 取座位，客户端保证传入的 `action_data["myPos"]` 与服务器一致。

## 为什么之前会「拼命压制、打压队友」？

逻辑上，代码里**已经有**「队友出牌时不压制、直接 PASS」的规则，例如：

- M1：`phase_handlers` 里 `_is_teammate(greater_pos, my_pos)` 为真时 `return 0`（PASS，不压制队友）
- V5：`greater_pos == teammate_pos` 时按「队友出牌必须 PASS」处理

问题出在 **己方座位号 `my_pos` 和服务器不一致**：

1. **服务器按连接顺序发 `myPos`**（例如先连的是 0，后连的是 1、2、3），若客户端**没有用服务器下发的 `myPos` 更新本地 `self.player_id`**，就会一直用启动时的“期望座位”（如 yf1 用 0、yf2 用 2）。
2. 这样算出来的 **`teammate_pos = (my_pos + 2) % 4` 就错了**：  
   例如实际你是 1 号位（队友是 3），但本地以为自己是 0 号位（以为队友是 2）。当 3 号位（真实队友）出牌时，`greater_pos = 3`，你算的 `teammate_pos = 2`，于是 `3 == 2` 为假，**被当成对手**，就会去压制。
3. 结果就是：**真实队友出牌时，AI 误判为对手，拼命压牌**，看起来就像「一直压制队友」。

修复方式就是第二项任务做的：**在游戏开始或首次 act 时，用服务器下发的 `myPos` 同步到 `self.player_id`**，并统一用 `ensure_my_pos_int` 取座位。这样 `my_pos` 与服务器一致，`teammate_pos` 正确，`greater_pos == teammate_pos` 时就会正确 PASS，不再压制队友。
