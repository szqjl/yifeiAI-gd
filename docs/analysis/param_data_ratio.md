# 模型/数据比例分析 — CardCountingNetwork

> **关联**：GUA-223 / CardCountingNetwork-训练方案.md §8 Phase 0 ②  
> **创建**：2026-08-09  
> **数据源**：`data/training/card_counting_v1/`（581 样本 / 27 match / 4 个 Botzone 日志）

## 一、数据现状

| 指标 | 数值 |
|------|------|
| 总样本数 | **581**（含 4 个 warning，drop 后 577） |
| V8 决策样本 | 241（41.5%） |
| Match 数 | 27 |
| 维度 | 108 × 3 = 324 |
| **样本/维度** | **1.79** |
| curRank 分布 | 26×"2" + 1×"5"（GUA-221 match） |

## 二、模型规模评估

### 2.1 Transformer 290K（原方案）

| 项 | 数值 |
|----|------|
| 参数 | 290,000 |
| 样本/参数比 | 581 / 290K = **0.0020**（严重过拟合） |
| 学术经验值 | 样本/参数 ≥ 10（保守）/ ≥ 100（推荐） |

**结论**：Transformer 290K 在 581 样本下**完全不可行**——需要 ~29 万样本才能达到经验下界。

### 2.2 LSTM 50K（评审修订建议）

| 项 | 数值 |
|----|------|
| 参数 | ~50,000 |
| 样本/参数比 | 581 / 50K = 0.0116 |
| 仍过拟合 | 是（建议 ≥10 样本/参数 → 需 50 万样本） |

**结论**：LSTM 50K 仍不可行——但加 dropout 0.5 + weight_decay 1e-3 + 早停可缓解。Phase 1 仅做"形式可行性验证"，不期待 val_loss 收敛。

### 2.3 缩减模型 LSTM 5K（探索性）

| 项 | 数值 |
|----|------|
| 参数 | ~5,000 |
| 样本/参数比 | 581 / 5K = 0.116 |
| 仍欠样本 | 是（但接近 0.1 警戒线） |

**结论**：5K 参数是当前数据规模下的**上限模型**——做 Phase 1 baseline 可行。

## 三、数据规模扩展路径

| 路径 | 预期新增样本 | 累计 | 样本/维度（vs LSTM 5K） |
|------|-------------|------|-------------------------|
| 当前基线 | 581 | 581 | 0.116 |
| 跑 lalala 9 局（60 副 × 21 步） | +1,260 | 1,841 | 0.368 |
| Botzone 监听 30+ 场 | +300 match × 21 步 = +6,300 | 8,141 | **1.628** |
| Botzone 监听 100+ 场 | +21,000 | 21,581 | 4.316 |
| lalala 30 局 | +4,200 | 25,781 | 5.156 |
| **目标** | — | **30,000+** | **≥6.0** |

**结论**：当前 581 样本距 LSTM 5K 训练所需 ~30K 样本**差 50×**。Phase 1 LSTM 5K baseline 不能训出可用模型——只能验证形式可行性。

## 四、Phase 0 硬门槛 ② 结论

| 项 | 结论 |
|----|------|
| 当前数据/维度 | 1.79（远低于 24 目标） |
| LSTM 5K 在当前数据 | 可训练（形式上），val_loss 不期望收敛 |
| LSTM 50K 在当前数据 | 不可训练（参数远超样本） |
| Transformer 290K | 必须 ≥30K 样本才能跑 |
| **Phase 1 推荐** | **LSTM 5K** baseline + dropout 0.5 + 早停 |
| **Phase 1 不期待** | 槽位准确率 >75%（评估指标需修订为"形式可行性"） |
| **数据累积优先** | lalala 9 局 + Botzone 30 场（累计 8K 样本，样本/维度 1.6） |

## 五、Phase 1 验收标准修订

| 原标准（方案 §11.1） | 修订后（Phase 1 当前数据下） |
|---------------------|---------------------------|
| 槽位准确率 >75% | **形式可行性 = val_loss 收敛 + train/val gap <30%** |
| 王牌 recall >85% | **王牌平均预测概率 > 0.5（不限 recall）** |
| val_loss 收敛 | 保留 |
| 推理延迟 <20ms | 保留 |
| ECE <0.10 | **N/A（数据不足校准无意义）** |
| Brier <0.15 | **N/A** |

**修订理由**：581 样本训练 5K 参数模型，所有"超越规则 baseline"指标都不现实。Phase 1 目标是验证"模型架构 + 训练流程 + 数据管线端到端可跑通"，真实 KPI 等数据累积到 ≥8K 步后再考核。
