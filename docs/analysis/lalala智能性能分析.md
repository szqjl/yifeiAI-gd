# lalala AI 智能性能分析报告

## 一、核心架构

### 1.1 决策流程
```
rule_parse (主入口)
├── 被动出牌 (passive)
│   ├── 残局处理 (one_hand, numofmy <= 10)
│   ├── Single() - 单张处理
│   ├── Pair() - 对子处理
│   ├── Trips() - 三张处理
│   ├── ThreeWithTwo() - 三带二处理
│   ├── ThreePair() - 三连对处理
│   ├── TwoTrips() - 钢板处理
│   ├── Straight() - 顺子处理
│   └── Bomb() - 炸弹处理
└── 主动出牌 (active)
    ├── 优先顺序：单张 < 三连对/钢板 < 顺子 < 三带二 < 三张 < 对子
    └── 使用固定阈值 cur = [9,10,9,8,10,10,2]
```

### 1.2 关键数据结构
- **手牌组合**：`combine_handcards` - 优先组合同花顺和顺子
- **剩余牌分析**：`rest_cards` - 分析牌库剩余牌
- **牌型分析**：`get_remain_card_type` - 判断剩余牌型可能性
- **炸弹计算**：`cal_bomb_num` - 计算当前炸弹数量

## 二、核心智能特性

### 2.1 队友保护机制
```python
# 当队友已经压制对手时，判断是否让队友继续
if (myPos+2)%4 == greaterPos:
    if curVal >= max_val or curVal >= max_val-2:
        return 0  # 让队友继续
```

**特点**：
- 队友已压制且当前牌值足够大时，选择PASS
- 队友剩余牌少（<=4）时，更倾向于让队友继续
- 队友剩余牌多时，会谨慎出牌（只出刚好大一级的牌）

### 2.2 残局处理策略

#### 2.2.1 一手牌判断 (`one_hand`)
- 当自己剩余牌 <= 10 时，优先考虑能否一手出完
- 判断条件：
  - 如果队友已压制，优先出非炸弹牌型
  - 如果对手已压制，优先出炸弹牌型
  - 考虑对手剩余牌数和最大炸弹大小

### 2.3 炸弹使用策略

#### 2.3.1 炸弹选择 (`choose_bomb`)
**优先级**：
1. 级牌炸弹（1张级牌 + 3张普通牌）
2. 级牌炸弹（2张级牌 + 2张普通牌）
3. 不拆顺子的炸弹
4. 不拆三带二的炸弹
5. 同花顺（如果已有天然同花顺）

**特点**：
- 优先使用不灵活的炸弹（级牌炸弹）
- 避免拆顺子和三带二
- 同花顺优先级较高（+32分）

#### 2.3.2 炸弹使用时机
```python
# 1. 炸弹多时（>=3）更容易使用
if cur_Bomb_num >= 3:
    return choose_bomb(...)

# 2. 对手剩余牌少时（<=18）更容易使用

    return choose_bomb(...)

        return choose_bomb(...)
```

### 2.4 单张策略

#### 2.4.1 正常模式 (`normal`)
- 优先使用天然单张（不在炸弹、对子、三张中）
- 避免使用级牌单张（除非对子少于3个）

#### 2.4.2 特殊模式 (`special`)
- 当 `pass_num >= 5` 或 `my_pass_num >= 3` 时触发
- 从大到小遍历，避免拆炸弹和顺子
- 用于紧急情况（连续PASS过多）

#### 2.4.3 残局单张策略
```python

    # 1. 优先用 >= max_val 的天然单张
    # 2. 其次用 >= max_val 的非炸弹单张（不拆顺子）

    # 4. 最后用 >= max_val-2 的非炸弹单张

```

### 2.5 主动出牌策略

#### 2.5.1 优先级顺序
1. **单张**：如果最小单张 < 9（cur[0]），且下家不是只剩1张
2. **三连对/钢板**：如果存在且满足条件
3. **顺子**：如果最小顺子 < 8（cur[4]）
4. **三带二**：根据 `rankthree` 函数判断
5. **三张**：根据 `rankone` 函数判断
6. **对子**：根据 `ranktwo` 函数判断
7. **单张**：最后选择

#### 2.5.2 固定阈值

### 2.6 手牌组合优化

#### 2.6.1 同花顺优先

## 三、关键优势

### 3.1 队友配合
- **保护机制完善**：当队友已压制时，会判断是否让队友继续
- **残局配合**：队友剩余牌少时，优先让队友出牌

### 3.2 炸弹使用
- **经济性**：优先使用不灵活的炸弹（级牌炸弹）
- **时机把握**：根据对手剩余牌数和炸弹数量决定是否使用
- **随机性**：增加不确定性，避免被对手完全预测

### 3.3 残局处理
- **一手牌判断**：优先考虑能否一手出完
- **大牌优先**：残局时优先使用大牌
- **避免浪费**：避免在不必要的时候使用炸弹

### 3.4 手牌优化
- **同花顺优先**：优先组合同花顺
- **避免拆牌**：避免拆炸弹和顺子组合其他牌型

## 四、潜在弱点

### 4.1 固定阈值
- 主动出牌使用固定阈值，可能不够灵活
- 没有根据游戏阶段动态调整

### 4.2 单张策略
- 单张策略相对简单，可能不够精细
- 没有考虑"卡点出单"等高级技巧

### 4.3 炸弹策略
- 炸弹使用时机判断可能不够精确
- 没有考虑"炸不打四"等规则

### 4.4 组牌策略
- 组牌策略相对简单，可能不够优化
- 没有考虑"一炸保两单"等原则
