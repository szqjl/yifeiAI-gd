## 根因推断

停顿发生在**第1副牌中段**，第2、3副无此现象。可能的根因：

1. **服务器端第1副牌的特殊逻辑**：第1副牌有进贡/还贡流程，可能触发额外计算
2. **内存分配/GC**：服务器首次处理游戏消息时触发 GC
3. **lalala 客户端的决策延迟**：lalala 是 Python 脚本，首次决策可能因模块加载/缓存命中慢

**待验证**：在 M3/M1 批跑中观察是否复现同样现象。
