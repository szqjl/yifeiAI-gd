# 卡2级 V7 根因分析 (GUA-062 批跑，2026-06-18)

## 数据概况

| 指标 | 卡2级 (24副) | 全局V7 (79副) | 结论 |
|------|:-----------:|:-----------:|------|
| PASS率 | 44.4% | 46.1% | **PASS不是原因** |
| 游戏步数 | 25.3步 | 25.2步 | 游戏长度正常 |
| 有炸弹的副 | 20/24 (83%) | — | 不缺炸弹 |
| 每副炸弹数 | 1.2次 | — | 够用 |

## 根因：出牌类型极单一 → Single 霸占决策

| 出牌类型 | 卡2级占比 | 全局占比 | 偏差 |
|----------|:--------:|:--------:|:----:|
| **Single** | **80.5%** | 66.4% | **+14.1pp** |
| Pair | 3.0% | 7.1% | **-4.1pp** |
| Bomb | 8.6% | 10.2% | -1.6pp |
| Trips | **0.0%** | 0.4% | — |

**卡在2级时，V7 的非PASS决策中 80.5% 是单张。** 对比全局 66.4%，2级场景更极端。

## 根因解读

### 不是 PASS 太多
PASS率 44.4% 和全局 46.1% 几乎一致。V7 在2级并不会比别的级更多PASS。

### 是 BC argmax collapse 的后果
BC 模型学到：训练数据中 "Single" 是最常见的出牌 → argmax 总是选 Single。grouping_engine v2 的评分虽然算出来了，但 V7 决策链没有用它来做动作选择——仍然是 BC 模型 argmax 主宰。

**具体表现**：
- 对手出单张 → V7 跟单张（PASS或出更大的单张）
- 对手出对子 → V7 多数 PASS（Pair只占3%），少数跟对
- 对手出三带二 → V7 几乎不响应
- 炸弹用了也白用：V7 炸完后继续出单张，不转换牌型节奏

### 炸弹使用过早
炸弹使用时机在前 12% 位置（游戏早期），炸完后无力持续压制。

### 手牌不是问题
卡2级的手牌分布与其他级无显著差异——**不是发牌烂**。

## 结论

**V7 卡在 2 级不是因为 PASS 多，而是因为 BC 模型的 argmax collapse 导致它只会出单张。** 单张打法是掼蛋里最弱、最被动的节奏——对手牵着走，没有主动权。分组引擎 v2 的评分未接入实际动作选择。

## 验证路径

下一步应该：打印几副卡2级的牌谱，确认 V7 的出牌序列是否呈现「连续单张 → 偶尔炸弹 → 继续单张 → 被压制」的模式。
