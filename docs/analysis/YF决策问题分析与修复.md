# YF决策问题分析与修复

## 📋 问题概述

用户反馈了4个关键问题：

1. **yf1一开始出牌就拆了三张2** - 主动出牌时不合理拆牌
2. **yf2有单张K，但用4个J开炸** - 被动出牌时没有优先使用多余单张
3. **yf2有444555钢板，但没有出，而是直接出三张Q** - 没有识别和优先使用复杂牌型
4. **yf2有单张级牌J、小王、大王，但拆了一对K来压制单张Q** - 被动出牌时没有优先使用多余单张和级牌/王

## 🔍 问题分析

### 问题1：主动出牌时拆三张2

**根本原因**：
- 虽然使用了扫描器识别多余单张，但优先级系统可能没有正确使用扫描结果
- 拆牌评估机制可能没有生效，或者权重不够高
- 开局阶段，优先级系统可能选择了拆三张的动作

**修复方案**：
1. 在优先级系统中增强对拆牌的惩罚（特别是开局阶段）
2. 优先使用扫描结果中的多余单张
3. 如果动作会拆三张或拆炸弹，大幅降低优先级

### 问题2：被动出牌时没有优先使用多余单张

**根本原因**：
- 虽然使用了 `_find_excess_singles_for_action()` 方法，但可能没有正确识别多余单张
- 或者识别到了，但优先级不够高，被其他动作（如炸弹）覆盖

**修复方案**：
1. 在被动出牌时，优先使用多余单张（优先级最高）
2. 只有在没有多余单张时，才考虑其他动作（如炸弹）

### 问题3：没有识别和优先使用复杂牌型

**根本原因**：
- 虽然扫描器识别了复杂牌型（如钢板），但优先级系统可能没有正确使用
- 或者优先级系统的权重配置中，复杂牌型的权重不够高

**修复方案**：
1. 在优先级系统中提高复杂牌型（钢板、三连对、三带二等）的权重
2. 在主动出牌时，优先选择复杂牌型
3. 在扫描结果中识别复杂牌型，并在优先级系统中使用

### 问题4：被动出牌时没有优先使用级牌/王

**根本原因**：
- 被动出牌时，虽然识别了多余单张，但可能没有优先使用级牌/王
- 或者级牌/王的优先级不够高，被其他动作覆盖

**修复方案**：
1. 在被动出牌时，优先使用级牌/王（优先级最高）
2. 只有在没有级牌/王时，才考虑其他动作
