# 模型文件管理方案

## 📋 问题

由于Gitee免费版仓库容量限制（500MB），模型文件（.pth）不能推送到Git仓库。但多台电脑需要共享模型文件进行训练。

## 🎯 解决方案

### 方案1：外部存储 + 下载脚本（推荐）

#### 1.1 使用云存储（推荐）

**优点**：
- ✅ 不占用Git仓库空间
- ✅ 支持大文件
- ✅ 可以版本管理
- ✅ 多台电脑可共享

**实施步骤**：

1. **上传模型文件到云存储**
   - 阿里云OSS / 腾讯云COS / 百度云 / OneDrive / Google Drive
   - 按版本组织：`models/v1/`, `models/v2/` 等

2. **创建模型下载脚本**

```python
# download_models.py
"""
从云存储下载模型文件
"""
import os
import requests
from pathlib import Path

# 模型文件清单（存储在Git仓库中）
MODEL_MANIFEST = {
    "bc_model_stage5_balanced.pth": {
        "url": "https://your-cloud-storage.com/models/bc_model_stage5_balanced.pth",
        "size": 2800000,  # 2.8MB
        "md5": "abc123..."  # 可选：校验文件完整性
    },
    # ... 更多模型
}

def download_model(model_name, force=False):
    """下载单个模型文件"""
    if model_name not in MODEL_MANIFEST:
        print(f"❌ 模型 {model_name} 不在清单中")
        return False
    
    model_info = MODEL_MANIFEST[model_name]
    local_path = Path("models") / model_name
    
    # 检查文件是否已存在
    if local_path.exists() and not force:
        print(f"✅ 模型已存在: {local_path}")
        return True
    
    # 创建目录
    local_path.parent.mkdir(parents=True, exist_ok=True)
    
    # 下载文件
    print(f"📥 下载模型: {model_name}...")
    try:
        response = requests.get(model_info["url"], stream=True)
        response.raise_for_status()
        
        total_size = int(response.headers.get('content-length', 0))
        downloaded = 0
        
        with open(local_path, 'wb') as f:
            for chunk in response.iter_content(chunk_size=8192):
                f.write(chunk)
                downloaded += len(chunk)
                if total_size > 0:
                    progress = (downloaded / total_size) * 100
                    print(f"\r  进度: {progress:.1f}%", end='')
        
        print(f"\n✅ 下载完成: {local_path}")
        return True
    except Exception as e:
        print(f"❌ 下载失败: {e}")
        return False

def download_all_models():
    """下载所有模型文件"""
    print("=" * 60)
    print("下载模型文件")
    print("=" * 60)
    
    success = 0
    failed = 0
    
    for model_name in MODEL_MANIFEST:
        if download_model(model_name):
            success += 1
        else:
            failed += 1
    
    print("\n" + "=" * 60)
    print(f"下载完成: 成功 {success}, 失败 {failed}")
    print("=" * 60)

if __name__ == "__main__":
    import sys
    if len(sys.argv) > 1:
        # 下载指定模型
        download_model(sys.argv[1])
    else:
        # 下载所有模型
        download_all_models()
```

3. **创建模型清单文件**（存储在Git中）

```yaml
# models_manifest.yaml
models:
  bc_model_stage5_balanced:
    file: bc_model_stage5_balanced.pth
    url: https://your-storage.com/models/bc_model_stage5_balanced.pth
    size: 2800000
    description: "Stage5平衡训练模型"
    required: true  # 是否必需
    
  bc_model_stage6_enhanced:
    file: bc_model_stage6_enhanced.pth
    url: https://your-storage.com/models/bc_model_stage6_enhanced.pth
    size: 14480000
    description: "Stage6增强模型"
    required: false
```

### 方案2：只推送训练脚本，模型本地生成

**适用场景**：每台电脑独立训练

**优点**：
- ✅ 不需要共享模型文件
- ✅ 每台电脑训练自己的模型

**缺点**：
- ❌ 无法共享预训练模型
- ❌ 无法快速部署已训练好的模型
