- 对手出Pair Q、Single 5等，yf有可选动作但仍PASS
- 这些PASS都是被动出牌（curPos != myPos）

**可能原因**：
1. `OpeningPassiveHandler._handle_pair_passive()` 中，如果策略建议"让对子"，直接返回0
2. `OpeningPassiveHandler._handle_other_passive()` 中，如果牌力<5，直接返回0
3. `OpeningPassiveHandler._handle_single_passive()` 可能在某些情况下直接返回0
