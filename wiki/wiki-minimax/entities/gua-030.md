# GUA-030 原则映射登记

## GUA 元信息

- **编号**：GUA-030
- **标题**：原则→代码的映射登记表
- **优先级**：P1
- **状态**：**closed（2026-05-31 关单）**
- **归属**：M3 / M1 / V5+ 多引擎
- **影响范围**：原则文档与代码实现的索引层

## 问题描述

掼蛋原则分散在多个 markdown 文档（`01_bomb_techniques.md`、`01_passing_skills.md` 等），缺乏统一的"原则 ID → 源文件 → 归属引擎"映射表，导致：
1. 重复原则难以识别
2. 实现进度无法跟踪
3. 多引擎迁移时无法对齐
