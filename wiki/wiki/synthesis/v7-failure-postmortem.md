# V2-V7 失败根因分析

## 背景

V2-V7 是掼蛋 AI 的 6 次神经网络路线尝试,**全部未达到工业级可用标准**。本文综合两份核心文档,梳理失败根因,并指导新 V7 架构设计。

## 失败时间线

```
V2(知识图谱) → V4(纯BC) → V5(大规模BC) → V6(RL自对弈) → V7(BC+RL混合)
   ❌             ❌          ❌            ❌              ❌
```

| 版本 | 核心路线 | 失败根因 |
|------|----------|----------|
| V2 | 知识图谱 | 状态空间爆炸,工程不可行 |
| V4 | 纯 BC 模仿 | 缺乏决策目标,只学表面动作 |
| V5 | 大规模 BC | 数据量不能突破质量瓶颈 |
| V6 | RL 自对弈 | 奖励稀疏,训练不稳定 |
| V7 | BC+RL 混合 | 仍未跳出"模仿动作"框架 |

## 共性根因

### 根因 1:模仿动作 ≠ 学习决策

V4/V5/V7 的端到端 BC 都在做**动作模仿**:
- 输入:手牌 + 历史
- 输出:下一张出牌
- 损失:与人类出牌动作的交叉熵

**问题**:人类出牌是基于"牌权争夺"目标的优化结果,只模仿动作不模仿目标,会学到"形似神不似"的策略。

### 根因 2:缺乏模块化分解

所有 V 系列都试图用**单一神经网络**解决整个决策问题:
- 输入维度:数百维
- 输出维度:数百维
- 长程依赖:80+ 轮

**问题**:单一网络难以同时学习"组牌"和"残局"这种差异巨大的子任务。

### 根因 3:端到端评估难

- 一个完整的对局是 80+ 轮的串联
- 中间任何一步错,后续都错
- 难以定位**哪一轮/哪个模块**出问题

### 根因 4:训练数据不足

- 高质量人类对局数据稀缺
- 自对弈数据质量低(尤其是早期)
- 数据规模不能突破质量瓶颈

## 与 M3 的对比

| 维度 | V2-V7(NN 路线) | M3(规则路线) |
|------|----------------|---------------|
| 决策目标 | 隐式(模仿) | 显式(规则) |
| 可解释性 | 低 | 高 |
| 调试成本 | 高 | 低 |
| 工业落地 | 0 | ✅ 成功 |
| 上限潜力 | 理论高 | 受规则设计限制 |

## 新 V7 的设计反思

基于以上分析,新 V7 做出以下架构调整:

### 1. 从"端到端"到"模块化"

- 类人决策五阶段
- 模块化分阶段训练
- 每个阶段独立训练与评估

### 2. 从"模仿动作"到"学习目标"

- 牌权争夺作为显式学习目标
- 强化学习的奖励函数围绕"牌权"设计

### 3. 从"纯 NN"到"神经 + 规则混合"

- 借鉴 M3 的**模块化思想**和**角色定位**
- 借鉴 ABL-GD 的**神经 + 逻辑混合架构**
- NN 处理模糊场景,规则处理长尾

### 4. 从"黑盒评估"到"模块化评估"

- 每个阶段有独立指标
- 中间状态可视化
- 失败归因可定位到具体模块
