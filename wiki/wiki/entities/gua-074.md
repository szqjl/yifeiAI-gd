# GUA-074 V 系列方法论反思（十一层分析 + 三层混合架构）

## 状态

**open**（里程碑文档，下一阶段战略定调）

## 文档定位

V 系列（V1-V7）两年方法论的**里程碑级反思**，对应 synthesis-v7-current-state-2026-06-19 战略转向。

## 十一层分析

1. V1-V6 历史回顾
2. **端到端 NN 结构性失败**（val_acc ≠ 实战胜率）
3. **三层混合架构**（Guard + 记牌 + 策略）
4. **规则叠加的非线性交互**（GUA-066 翻车）
5. **Lalala 基准未校准**（参 concept-benchmark-uncalibrated）
6. 模块化 NN 路径
7. 信念建模（concept-belief-modeling）
8. 知识接入粒度（concept-knowledge-integration-granularity）
9. 行动纲领（synthesis-knowledge-integration-roadmap）
10. 长期路线（wiki/concepts/self-play-policy-gradient.md）
11. **V7 范式转移**：从"端到端 BC"到"模块化 NN + 规则补全"

## 三层混合架构

```
Layer 1: Guard 规则        → 硬约束（[[gua-071]]）
Layer 2: 记牌信念          → 规则/NN 记牌（[[gua-072]]）
Layer 3: 策略选择          → heuristic/NN 分类（[[gua-071]]）
```

## 关键论断

1. **V7 的 NN ≠ 端到端 NN**：NN 只做记牌+策略分类
2. **GUA-064（重训 NN）与本文不冲突**：NN 范围已收窄
3. **Lalala 上限锁死**：所有胜率解读加 caveat
