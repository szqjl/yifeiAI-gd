## 核心改动

### MemoryTracker.get_hand_count 优先级链

```
优先级链：手牌记录 → 已出牌记录 → _estimate_player_remaining
```

| 优先级 | 来源 | 覆盖场景 |
|--------|------|----------|
| P1 | 对手主动报手牌 | 极少数 |
| P2 | play_history 反推 | 常规 |
| P3 | `_estimate_player_remaining`（增强点）| 兜底 |

### _estimate_player_remaining 增强

基于 `card_state` 108 张牌全量追踪 + 排除法推断对手手牌：

```python
def _estimate_player_remaining(player_id: str) -> List[Card]:
    # L1: 直接从 card_state 减去已出牌
    remaining = card_state - played_cards
    if len(remaining) >= 0:
        return remaining
    # L2: 基于对手历史出牌模式估算
    return estimate_from_history(player_id)
    # L3: 兜底使用统计先验
    return statistical_prior()
```

### 关单条件（7 项）

1. `card_state` 完整（108 张无丢失）
2. `play_history` 完整记录
3. `_estimate_player_remaining` 三层降级覆盖所有场景
4. 单测覆盖 8 种典型牌局
5. `MemoryTracker.get_hand_count` 优先级测试通过
6. 不破坏 V7 引擎兼容性
7. 性能：调用耗时 < 1ms
