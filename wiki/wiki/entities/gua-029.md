# GUA-029 炸弹规则包 R1-R6

## 规则清单

| 编号 | 规则 | 说明 |
|------|------|------|
| R1 | `choose_bomb` 修复 | 选炸条件补全，rank 优先级重排 |
| R2 | 必回炸 | 队友被炸时若手牌有同级或更大炸弹必须回炸 |
| R3 | ≤7 张阻断 | 手牌 ≤7 张且非头游时不主动炸 |
| R4 | 不压队友 | 队友出牌时即使更大也不压 |
| R5 | 残局 ONE_HAND | 残局仅一手时优先炸出清场 |
| R6 | 三带二联动 | 与 [[gua-026]] 拆牌保护协同 |

## 模块

- 主入口：`m3_utils.choose_bomb`
- 调用方：`src/decision/strategy_engine.py`、`src/decision/phase_handlers.py`
