## 问题描述

在「双进」局面下（即我方两人都有进牌机会），需要决定 yf1 和 yf2 中哪个先冲刺。当前 `sprint_capability` 判定粒度过粗：

```python
# 当前（粗粒度）
def is_sprinting_v0(hand_count: int) -> bool:
    return any(count >= 4 for count in hand_count_by_rank.values())
```

**缺陷**：
1. 未考虑炸弹家族（4 张同点 vs 4 张不同点是不同 sprint 强度）
2. 未考虑剩余回合数（剩 2 手 = 炸弹 + 单手 ≠ 剩 5 手 + 5 张同点）
3. 未考虑贡牌贡献（刚接完贡牌不应误判为 sprint）

## 数据源升级链

本 GUA 的数据源升级路径：

```
GUA-135 粗粒度 (≥4 张同点)
   ↓
GUA-136 单牌级 (_estimate_player_remaining + MemoryTracker)
   ↓
GUA-137 整手结构 (grouping_plan + num_rounds + has_bomb_family)
   ↓
GUA-138 LRU 缓存 (性能 100x 提升)
```

详见 [[sprint-precision-upgrade-chain]]
