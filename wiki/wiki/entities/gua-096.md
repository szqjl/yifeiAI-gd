# GUA-096 post_batch_log 净盘批跑落盘 hook

## 状态

✅ 已 commit + push + pytest 7/7 PASS（2026-06-29）

## 职责

批跑执行后**强制落盘**到：
- `v7_vs_lalala_scores.json`
- `v7_vs_lalala_state.json`
- 净盘标记（clean batch flag）

## 关键约束

- 落盘失败 → 批跑视为失败，禁止进入下一轮
- 净盘标记必须带 SHA256 校验
- 与 GUA-033「局≠副」口径严格一致

## 实现

- 模块：`scripts/hooks/post_batch_log.py`
- 触发：批跑结束后（无论成功失败）
- 校验：victoryNum [0]=[2] / [1]=[3] 镜像
