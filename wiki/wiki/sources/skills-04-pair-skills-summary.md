# 对子技巧摘要

> 来源：docs/knowledge/skills/04_common_skills/01_pair_skills.md

## 核心原则

**情况不明，对子先行**（S-PR03 逢五出对）

## 牌型统计

- 对子占 **24.77%**
- 平均每局 **7.6 手**
- 出牌时机：中局、收尾阶段都常见

## 子技巧集

组 / 顺 / 顶 / 让 / 封 / 逼 / 送 / 抢 / 拆

### 关键技巧

| 技巧 | 描述 |
|------|------|
| 逢五出对 | 对手剩 5 张时优先出对 |
| 大对子抢出 | 抢在对手前出大对 |
| 送对顺序 | 次中 → 大 → 小 |
| 让队友对 | 主动 PASS 让队友出对 |

## 引擎关联

- **M3**：有基础对子出牌逻辑，但缺乏"让队友对"等协作语义
- **V5+ / V7**：需要 4 人协作视角下的对子选择策略
- 关联 `PRINCIPLES_MAPPING.md §十`
