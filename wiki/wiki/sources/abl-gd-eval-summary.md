# ABL-GD 168 伪动作评估 - 摘要

## 评估对象

南京大学 LAMDA 组论文：基于反绎学习（ABL）的掼蛋 AI 路线（ABL-GD）。评估其在 V7 引擎中的可行性。

## 评估方法

| 维度 | 检查项 |
|------|--------|
| 168 伪动作列表 | 论文是否公开 168 个伪动作的具体定义 |
| ABLN 网络结构 | 反绎学习网络的输入/输出/损失函数 |
| 与 v1006 平台兼容性 | actionList 协议是否对齐 |
| 训练数据需求 | 论文是否提供预训练模型或数据 |
| 实战胜率证据 | 是否有第三方复现/对 lalala 评测 |

## 评估结论

**弃用（备选）**

| 理由 | 详情 |
|------|------|
| 论文未公开 | ABLN 网络结构、168 伪动作列表均未公开，无法复现 |
| 复现成本高 | 反绎学习需要符号-神经混合架构，与 V7 模块化路线不兼容 |
| 平台对齐差 | 论文基于旧版协议，与 v1006 23456 端口不直接兼容 |
| 替代方案更优 | [[modular-training-v7]] 路线（套路七）已规划完整模块化训练，无需引入 ABL |

## 备选触发条件

如满足以下任一条件，重新评估：
- 论文公开 ABLN 实现细节
- 团队获得 LAMDA 组直接合作
- 模块化路线 V7 BC 阶段卡死且 ABL-GD 路径成为唯一解
