# 规则摘要：02 快速入门

## 来源

- 原始文件：`docs/knowledge/rules/01_basic_rules/02_quick_start.md`（1401 字符）
- 真源定位：江苏掼蛋规则（文档化副本）
- 原始真源：`.cursor/rules/guandan-knowledge.mdc`

## 核心内容

新手四步路径，介绍如何从零开始一局掼蛋：

1. **认识牌具**：两副标准扑克合用，共 108 张，含逢人配（红桃级牌）
2. **理解目标**：四人两队（对家互为队友），从 2 打到 A，A 级双上赢局
3. **出牌规则**：首家出某类型牌，其余玩家必须跟同类型最大或 Pass
4. **升级与进贡**：上游获得进贡牌，下游交最大牌（逢人配可跳），下游领出
