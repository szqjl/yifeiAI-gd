# 组牌技巧（§二十二 ★ P-G01 总纲）

## 文件位置
- 路径：`docs/knowledge/skills/07_opening/04_card_grouping_skills.md`
- 章节：§二十二 ★ 组牌（**P-G01 组牌总纲**）

## 核心理论框架

### P-G01 组牌总纲三维度
1. **轮次优先**（最少轮次打完）
2. **可控性**（出牌后能否收回牌权）
3. **可变性**（保留变化、不组死）

### 牌力计算法（V7 增强版）

以 `src/v/nn/features/grouping_engine.py` `_score_power()` 代码为真源。

**加分项**：

| 牌型/情况 | 分值 |
|----------|------|
| 同花顺 | +3 分/个 |
| 5 头炸 | +3 分/个 |
| 4 个级牌炸弹 | +3 分/个 |
| 6 张及以上炸弹 | +3 分/个 |
| 普通 4 头炸 | +2 分/个 |
| 四大天王（2R+2B） | +4 分/组 |
| 逢人配（百搭，未配入炸弹/同花顺） | +1 分/张 |
| 大王 | +1 分/张 |
| 对级牌 | +1 分/对 |
| 三连对 | +1 分/个 |

**减分项**（每满足一类扣 1 分，多张多组叠加扣）：

| 牌型/情况 | 分值 | 条件 |
|----------|------|------|
| 小单张 | -1 分/张 | rank 2~9（不含王/逢人配/级牌） |
| 小对子 | -1 分/组 | rank 2~5，无三带二保护（不含王对子） |
| 小三带二 | -1 分/组 | trip rank < 4 |
| 小顺子 | -1 分/组 | 最高牌 ≤6 |
| 小木板 | -1 分/组 | 最高牌 ≤6 |
| 小钢板 | -1 分/组 | 最高牌 ≤6 |

### 牌力分级与角色定位

| 牌力区间 | 角色 |
|----------|------|
| ≥ 8 分 | 超强主攻 |
| 5-7 分 | 主攻 |
| 2-4 分 | 助攻 |
| < 2 分 | 超弱 |

**临界点**：4-5 分之间可发生角色转换（主攻 ↔ 助攻）

## 组牌顺序优先级

```
总目标：去单化 / 最小轮次
  ↓
① 同花顺（SF_FIRST）  ← 同花优先炸弹
  ↓
② 4/5 头炸（BOMB_FIRST）
  ↓
③ 三带二 / 三连对 / 钢板 / 对子 / 顺子
```

### 关键口诀
- **一炸保两单**：组炸多出 2 单可接受
- **慎组天王炸**：拆王压单/对要谨慎
- **破二炸弹不能搭**：破 2 头的炸弹不要硬搭（与 GUA-026 拆 trips 边界相关）
- **预留 3 配百搭**：百搭配 3 放后压
- **同花优先炸弹后**：先配同花顺再配炸弹
- **易顺易封顶**：拆大王/拆级牌/大顺子封顶
- **长套组小套，单张最大化**
- **消除赘牌**：顺子消单/夯与木板消对
- **用好逢人配**：配炸/补缺
- **牌型不组死、保留变化**

### 牌型补充
- **孤张定律**（vs 五十定律）：含级牌/A 的顺子常被提前发现，外面单张几乎必在队友/对手
- 见 [[concept-isolated-card-law]]

- 引入 `enumerate_groupings` + 牌力分 CG-R01~R07
- 见 engine-v5plus（如不存在则需创建）

### V7 引擎
- 5 维权重评分：
  - 炸 × 0.3
  - 手数 × 0.3
  - 回收 × 0.1
  - 灵活 × 0.1
  - 去单化 × 0.2
- 见 wiki/entities/engine-v7.md

- **M3 vs V5+ 组牌路径冲突**：P-G01 要求按 SF→BOMB→三带二/连牌 顺序评分，V7 5 维权重与"一炸保两单/慎组5头/破二炸弹不搭"存在微观差异。需在 [[concept-engine-mapping-principles]] 明确"原则层 vs 评分函数层"分两层。
- **"破二炸弹不能搭" vs V7 5 头炸评分**：边界判定需落到 GUA-026/031 跟踪里。
- **强牌弱打 vs 牌力 8 分以上主攻**：6 分主攻可转助攻的临界点需统一决策树。
