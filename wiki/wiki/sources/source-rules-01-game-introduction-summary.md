# 掼蛋基础规则-游戏介绍摘要

> 原文件：`docs/knowledge/rules/01_basic_rules/01_game_introduction.md`（835 字）

## 核心内容

本文件为 L1 Rules 知识库基础条目，介绍掼蛋游戏基本盘：

- 游戏人数：4 人（2v2 队级对抗）
- 牌数：每人 27 张
- 胜负条件：双上（一方两人均第一/第二名）
- 升级机制：从 2 → A → 结束

## 关键术语（与平台数据口径对齐）

| 术语 | 含义 |
|------|------|
| **局** | 一次「A 级双上过关」游戏 |
| **副** | 一名玩家出完手牌（episodeOver） |
| **圈** | 4 个玩家各作为主牌一次 |
| **进贡/还贡** | 局末头游/末游交换牌 |
