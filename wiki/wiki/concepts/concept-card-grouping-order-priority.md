# 组牌顺序优先级（SF→BOMB→连牌）

## 总目标
**去单化 / 最小轮次**（用最少的出牌轮次打完所有手牌）

## 优先级顺序

```
① 同花顺（SF_FIRST）       ← 同花优先炸弹后
   ↓
② 4/5 头炸（BOMB_FIRST）
   ↓
③ 三带二 / 三连对 / 钢板 / 对子 / 顺子
```

## 关键口诀

| 口诀 | 含义 |
|------|------|
| **一炸保两单** | 组炸多出 2 单可接受 |
| **慎组天王炸** | 拆王压单/对要谨慎 |
| **破二炸弹不能搭** | 破 2 头的炸弹不要硬搭 |
| **预留 3 配百搭** | 百搭配 3 放后压 |
| **同花优先炸弹后** | 先配同花顺再配炸弹 |
| **易顺易封顶** | 拆大王/拆级牌/大顺子封顶 |
| **长套组小套** | 长套牌型先组小套 |
| **消除赘牌** | 顺子消单/夯与木板消对 |
| **牌型不组死** | 保留变化 |

## V7 5 维评分权重

| 维度 | 权重 |
|------|------|
| 炸（炸弹数量） | × 0.3 |
| 手数（轮次） | × 0.3 |
| 回收（牌权控制） | × 0.1 |
| 灵活（变形可能） | × 0.1 |
| 去单化（消除单牌） | × 0.2 |

## 引擎实现对比

| 引擎 | 路径 | 特点 |
|------|------|------|
| M3 | `combine_handcards` | 单路径 |
| V5+ | `enumerate_groupings` + 牌力分 | 多候选 + 评分 |
| V7 | 5 维评分函数 | 加权求和 |

## 紧张点

### M3 vs V5+ 组牌路径冲突
- P-G01 要求按 SF→BOMB→三带二/连牌 顺序评分
- V7 5 维权重与"一炸保两单/慎组 5 头/破二炸弹不搭"存在**微观差异**
- 需在 [[concept-engine-mapping-principles]] 明确"**原则层 vs 评分函数层**"分两层

### 破二炸弹不能搭 vs V7 5 头炸评分
- skills 口诀：破 2 头的炸弹不要硬搭
- CG-R 系列：拆 4 头炸产生赘牌不超过两张可组同花顺
- **边界判定**需落到 GUA-026/031 跟踪里
