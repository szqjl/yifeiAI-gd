# 掼蛋基本规则（队际对战）

## 队际配置
- **4 人两队**，按连接顺序决定座位号（0+2 vs 1+3）
- 座位 0 和 2 为一队，座位 1 和 3 为另一队

## 核心概念层级

| 概念 | 定义 | 关键判定 |
|------|------|----------|
| **一副** | 108 张发完到四人完牌 | order 确定 → 升级 + 决定下副进贡关系 |
| **一局** | 从 2 打到 A 并在 A 级双上过关 | A↔2 循环 50 次 → 平局 |

⚠️ **局 ≠ 副**（详见 [[局不等于副]]）

## 升级规则表

| 本队表现 | 升级数 |
|----------|--------|
| **双上**（头游 + 二游） | **+3** |
| 头游 + 三游 | +2 |
| 头游 + 末游 | +1 |
| 无头游 | +0 |

> 说明：升级级数 = 名次组合对应的级数。若本局未达 A，则 curRank + 升级数；若本局已在 A，则进入下一局判定。

## A 级特殊规则
- **A 级必须双上才算赢局**（单上 A 不算过关，下副继续）
- 连续 2 副未胜（停留在 A）降回 2
- **A↔2 循环满 50 次 → 平局**（无限循环机制）

## 进贡 / 还贡
- 每副结束后，末游向头游进贡**最大牌**
- 还贡：头游收到进贡后，向末游还贡**≤10 的牌**
- 进 / 还贡发生在下副发牌之前

## 双上 / 双下
- **双上**：本队占据头游 + 二游（+3）
- **双下**：对方占据头游 + 二游（本队末游 + 三游）
