# PB-002 缺陷发现 4 层闭环

## 核心思想

把**回放（replay）从「主力发现手段」降级为「抽检手段」**，前移到缺陷发现链路前段。

## 四层闭环

```
┌────────────────────────────────────────────┐
│ Layer 1: 静态校验                            │
│   - lint / type / 规则表一致性               │
│   - 失败即拦下 → 禁止入批跑                   │
└────────────────────────────────────────────┘
              ↓ 通过
┌────────────────────────────────────────────┐
│ Layer 2: 参数化测试                          │
│   - 矩阵测试 + 边界用例                       │
│   - 失败即拦下 → 禁止入批跑                   │
└────────────────────────────────────────────┘
              ↓ 通过
┌────────────────────────────────────────────┐
│ Layer 3: 异常扫描                            │
│   - endgame_anomalies / round_level_stats   │
│   - 异常预警 → 批跑后必跑                     │
└────────────────────────────────────────────┘
              ↓ 通过
┌────────────────────────────────────────────┐
│ Layer 4: WF-12 单步决策链路抽检              │
│   - DecisionTracer + 锚点筛选                │
│   - 抽样 10% 局次深挖                         │
└────────────────────────────────────────────┘
```

## 与 PB-001 的差异

| 维度 | PB-001 | PB-002 |
|------|--------|--------|
| 主力手段 | 回放 | 静态校验 + 参数化测试 |
| 抽检手段 | 无 | WF-12 + DecisionTracer |
| 拦下时机 | 批跑后 | 批跑前 |
| 适用版本 | M3 | V7 |

## 残局止血规则（GUA-099/100 引入）

- **GUA-099**：endgame 异常扫描默认开启
- **GUA-100**：Q1/Q2/Q3 残局规则集中入口（`endgame_rule` + `BAOSHU_RULE`）
- **GUA-101**：endgame agent 守门员
- **GUA-102**：Q1 规则表一致性校验
