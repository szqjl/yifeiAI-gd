# 传牌矩阵

按**剩余手牌张数**划分的传牌策略矩阵，是 [[gua-031]] 实施的核心参考表。

## 矩阵总表

| 剩余张数 | 首选策略 | 备选策略 |
|----------|----------|----------|
| **2 张** | 先中大后小 | — |
| **3-4 张** | 送单/对/三张通路 | 视牌型定 |
| **5 张** | 大概率三带二 | 送三带二或顺子 |
| **6 张** | 5+1 送单 | 4+2 送对 |
| **7 张** | 有王出单/对子通路 | 拆大牌 |
| **8 张** | 单/对/三张 | 视情拆 |
| **9 张** | 送 5 张牌型 | 三带二/杂花顺 |
| **10 张** | 三带二 + 杂花顺优先 | 其他组合 |

## 四大战术

- **砸锅卖铁**：全力一搏
- **调虎离山**：引开对手大牌
- **借刀杀人**：利用对手互斗
- **釜底抽薪**：断对手牌路

## 三大分析方法

1. **行牌排除法**：根据出牌顺序排除可能牌型
2. **记牌分析法**：5/10 核心点记忆（关键张数节点）
3. **逻辑推演法**：基于规则的演绎

## 常见误传（六病）

| 误传 | 含义 |
|------|------|
| 刻舟求剑 | 死守固定牌型 |
| 把队友打吐 | 传牌过小逼队友硬接 |
| 不加防守传牌 | 传牌时无防御 |
| 想当然传牌 | 不做推理 |
| 羊入虎口 | 送入对手控制 |
| 无意义传牌 | 传牌无战略目标 |

## 引擎落地

- **M3 P1**：4 条可硬编码（基于 `numoffri` / `numofnext` guard）
- **V5+**：完整矩阵实施
- **无 P0**

详见 [[gua-031]] 与 [[concept-engine-mapping-principles]]。
