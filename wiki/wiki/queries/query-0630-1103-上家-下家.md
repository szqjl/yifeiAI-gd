# 上家 下家

# 上家 / 下家

## 一、位置定义（平台标准）[{3}][{8}]

掼蛋是 **4 人 2v2 配对制**，上下家是**相对于 `myPos`** 的相对位置：

```
downPos     = (myPos + 1) % 4   // 下家（顺时针下一位）
upPos       = (myPos - 1) % 4   // 上家（逆时针上一位）
teammatePos = (myPos + 2) % 4   // 对家（队友）
```

**出牌顺序**：每轮接牌方 = `(curPos + 1) % 4`，下家先接。`curPos` 是**当前出牌方**（随轮次推进），不是固定指向某一方。[{3}]

---

## 二、核心策略：打上家、卡下家 [{1}][{2}][{6}]

"打上家卡下家"是掼蛋**四项基本原则**之一——**压制对家上游，阻止其跑牌**。

| 对象 | 策略 |
|------|------|
| **上家** | 主动压制、断其牌路，不让其顺畅出牌 |
| **下家** | 阻止其跑牌、控制牌权交接节奏 |
| **对家（队友）** | 让道、喂牌，配合其先走 |

---

## 三、冲突解决优先级 [{1}][{2}]

当上家/下家策略与队友保护冲突时：

| 局面 | 主策略 | 优先级 |
|------|--------|--------|
| 4 人在场 | GUA-029 通用原则 | — |
| 队友 rest | **GUA-031 让道** | 优先于 GUA-034 |
| 对手 [myPos+2] rest | **GUA-034 solo_sprint 拦头** | — |
| 接风 + 队友是 Pair/Bomb | GUA-036 TEAM-P01 接风让道 | **让道 > 评分最高** |

> **铁律**：队友 rest > 对手 rest；让道（WIND-P01 / TEAM-P01）> 评分最高

## 四、M3 引擎 PASS-P01~P04 让牌实现 [{1}][{2}]

| 原则 | 场景 | 动作 | 置信度 |
|------|------|------|--------|
| **PASS-P01** | 主动 | 送小单让队友接牌 | high |
| **PASS-P02** | 主动 | 防送炸（不主动给队友出炸机会） | high |
| **PASS-P03** | 被动 | `_is_teammate_greater` 时 `return 0` 让道 | high |
| **PASS-P04** | 主动 | 逢五喂队友 | **low**（未批跑验证） |

**关键边界**：
- GUA-026：PASS 不放宽"三带二禁拆炸弹/耗级牌"
- GUA-029：PASS 不放宽 R5"不压队友"原则

## 五、V7 L2 推荐管线的四场景 [{9}]

V7 引擎 L2 推荐管线针对上家/下家有明确场景划分：
- **领出**（每副第一手）
- **跟上家**（接上家出牌）
- **卡下家**（控制下家跑牌）
- **让对家**（给队友让道）

推荐结果需经 L2′ `_group_consistency_filter` 拦截保护（GUA-075），避免拆炸弹/拆同花顺。

## 六、单张控制技巧（针对上下家）[{4}]

| 技巧 | 说明 |
|------|------|
| **顺上家** | 上家单牌对自己有利 |
| **控下家** | 首用 Q，次用 JK，卡下家小单 |
| **让对家** | 不要越级打大牌拦对家 |
| **卡点出单** | 精确送牌给队友过单 |
