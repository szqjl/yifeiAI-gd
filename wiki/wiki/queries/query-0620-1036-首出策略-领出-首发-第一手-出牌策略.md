# 首出策略 领出 首发 第一手 出牌策略

# 首出策略（领出 / 首出 / 第一手）

## 一、概念区分

| 术语 | 含义 | 性质 |
|------|------|------|
| **领出** | 每副由谁先出第一张 | 规则产物 |
| **首出** | 领出者打出的**第一手牌** | 策略决策 |
| **第一手** | 同"首出" | 口语 |

⚠️ **领出 ≠ 首出策略**。领出者由平台/规则决定，首出什么牌型才是策略点。[1][2]

---

## 二、领出规则（谁先出）[2][3]

| 场景 | 领出者 |
|------|--------|
| 第一副 | 服务器决定 |
| 第二副起（普通进贡） | 进贡给上游者（受贡者）领出 |
| 双下 | 三游领出 |
| 抗贡 | 上游（头游）领出 |
| 普通升级 | 上游（头游）领出 |

> 实体赛旧规"下游领出"已被**平台 act 规则覆盖**。

---

## 三、首出牌型含义（牌语信号）[1]

| 首出牌型 | 牌语含义 |
|----------|----------|
| **小单** | 牌力强（无需大牌保护） |
| **对子** | 试探，意图不明 |
| **高单** | 助攻 / 交牌权 |
| **小顺** | 牌力强 / 有打有收 |
| **木板/钢板** | 中性 |
| **三张** | 弱牌（无力组更大牌型） |

---

## 四、首出高压线（P0）[1][5]

| 原则 | 含义 | M3 状态 |
|------|------|---------|
| **P-H01 / P-G04** | 进贡慎出单 | ✅ P0 实施 |
| **P-H02** | 火不打四（4 头炸慎首发）| ✅ P0 实施 |
| **P-H05** | 顺子慎始发 | ✅ P0 实施 |
| **P-C01~02** | 核心原则 | ✅ P0 |

---

## 五、逢人配首出策略 [1]

- **配炸弹**：有 4 头火苗子时
- **补缺**：缺 1 张成同花顺
- **配顺子**：中段优先（4-5-6-7-8）
- **预留策略**：首攻/过渡时暂不配，保留变化

---

## 六、角色驱动的首出 [1]

| 角色 | 牌力 | 组牌方向 |
|------|------|----------|
| 主攻 | ≥5 分 | 全面组牌，可激进配火 |
| 助攻 | 2-4 分 | 精简配火，**保留变化** |
| 超弱 | <2 分 | 配火优先，大胆配火 |

## 七、V7 引擎的首出决策流程 [1][9]

```
输入：手牌 + main_rank + 局况
  ↓
1. SF_FIRST：识别同花顺苗子
  ↓
2. BOMB_FIRST：识别炸弹
  ↓
3. enumerate_groupings()：枚举所有组法
  ↓
4. _score_power()：5 维评分
     = 0.3×炸弹 + 0.3×手数 + 0.1×回收 + 0.1×灵活 + 0.2×去单化
  ↓
5. 选择 power_score 最高的组法
```

### V7 已知限制 [1][9][10]
