# 两手整牌 · 残局 · 炸弹 · 冲刺头游

把 4 个关键词拆开来看：**两手整牌 → 残局 → 炸弹 → 冲刺头游**，Wiki 中没有一篇页面同时覆盖这四个词的合成场景，但可以从「炸弹执行 R6」「队友让道」「牌力分级」「首出高压线」四条线拼出完整策略。

---

## 一、定位：这是「残局冲刺」场景（不是首出/中局）

### 关键判定

| 信号 | 来源 | 含义 |
|------|------|------|
| **手牌 ≤ 10 张** | [[gua-062|手牌 ≤ 10 张残局豁免口径]] | 触发残局约束 |
| **手牌 ≤ 4 张** | 炸弹 R4 [2] | 默认不炸（R6 除外） |
| **剩两手整牌** | 推断 | 头游冲刺圈（1-2 轮即可打完） |

### "两手整牌" 的本质
不是「组牌阶段」的两手牌，而是**残局还剩 2 个牌型**的局面——每出一手基本就结束。属于 **R6 残局冲刺** 的典型触发场景 [2]。

---

## 二、炸弹决策：R6 是最高优先级

来自 [bomb-execution-rules] [2]：

| 规则 | 触发 | 决策 |
|------|------|------|
| **R6 残局冲刺** | 残局 + 对手牌力强 | **必出最大整炸抢头游** |
| **R4 剩 4 张默认不炸** | 手牌 ≤ 4 | 默认不炸，**R6 例外** |
| **R5 不压队友** | 队友已炸 | 不压（冲刺时此条让位 R6） |

### 冲刺阶段的资源取舍
- 炸弹是**冲刺头游的最终手段** [1][2]
- 「谁打谁收」原则：出手必须能**收回牌权或直接获胜** [1]
- 黑名单反例：**牌力不足时**、**不能保证回手**、**浪费在非关键局面** 的炸弹投入 [1]

---

## 三、"两手整牌" 的组牌选择

来自 [card-grouping-order-priority] [4] 与 [card-power-scoring] [7]：

### 牌力自检
```
超强主攻 (≥8 分) → 强攻跑牌，不犹豫
主攻 (5-7 分)   → 冲刺头游 ← 本场景
助攻 (2-4 分)   → 配合队友
超弱 (≤1 分)    → 防守、传牌
```

### 残局两手牌的最优组合
按 P-G01 优先级 [4]：
1. **同花顺**（一手清空，+3 分）
2. **4/5 头炸**（一手清空或抢牌权，+2~3 分）
3. **整牌型**（三带二、钢板、顺子、对子）

**关键口诀**：
- **一炸保两单**：组炸多出 2 单可接受 [4]
- **破二炸弹不能搭**：破 2 头的炸弹不要硬搭 [4]
- **慎组天王炸**：拆王压单/对要谨慎 [4]

## 四、队友配合：冲刺时让道 vs 抢牌权

来自 [teammate-yielding] [8]：

| 我方牌力 | 队友牌力 | 决策 |
|----------|----------|------|
| 强 | 弱 | 自己冲刺，PASS-P02 防送炸 |
| 弱 | 强 | PASS-P03 让道（`_is_teammate_greater` → `return 0`） |
| 相当 | 相当 | R6 残局冲刺原则优先 |

### 残局冲刺的边界
- **GUA-026**：即使让道给队友，**也不能拆炸弹/耗级牌** [8]
- **GUA-029**：PASS 不放宽 R5「不压队友」——但残局 R6 冲刺时此约束让位 [8]

## 五、首出高压线在残局的反转

来自 [query-0620-1036] [6]：

| 高压线 | 首出禁用 | 残局冲刺 |
|--------|----------|----------|
| **P-H02 火不打四** | 4 头炸不首发 | **解禁**：R6 必出最大整炸 |
| **P-H05 顺子慎始发** | 5+ 连牌慎首发 | 仍慎用（回收难），但两手牌时是合理选择 |
| **P-H01 进贡慎出单** | 进贡时不打小单 | 不适用（已是下游） |

**结论**：残局冲刺是 P-H02 的**唯一合法例外**（R6 触发）。

## 六、综合决策树

```
[两手整牌 残局]
  ↓
Q1: 我方牌力 ≥5 分？
  ├─ Yes → R6 必出最大整炸抢头游（P-H02 解禁）
  └─ No  → Q2: 队友牌力更强？
              ├─ Yes → PASS-P03 让道 (_is_teammate_greater → return 0)
              └─ No  → R6 仍冲刺，保留炸弹到最后一手
  ↓
Q3: 整牌型选择？
  ├─ 同花顺 → 优先（+3 分，一手清空概率高）
  ├─ 炸弹 → 次选（+2~3 分，R6 触发）
  └─ 顺子/三带二 → 兜底（注意 P-H05 慎用原则）
  ↓
Q4: 炸弹出手后能否回手？
  ├─ 能 → 出
  └─ 不能 → 改用其他牌型，炸弹留最后
```

## 一句话总结

**两手整牌残局冲刺头游** = **R6 触发** → **牌力 ≥5 分则必出最大整炸**（P-H02 火不打四在此解禁）→ **牌力不足则 PASS-P03 让道** → **整牌型优先同花顺 / 炸弹**，**慎用顺子**（P-H05）。
