# victoryNum 含义 局胜 副胜

# `victoryNum` 含义：局胜 vs 副胜

## 一、核心区分

`victoryNum` 在批跑体系中**主要指"局级"升级数**，而非"副级"。[{1}][{5}]

| 层级 | 字段 | 含义 |
|------|------|------|
| **局级** | `gameResult.victoryNum` | **本局升级数**（0/1/2/3） |
| **副级** | `act.stage.play.curRank` | **当前副**的 rank（每副重置） |

⚠️ **1 局 ≈ 多副**（实测 N=1 → 59 副）[{6}]

## 二、局级 `victoryNum` 取值含义 [{1}]

| victoryNum | 含义 | 场景 |
|------------|------|------|
| **0** | 本局未升级 | 劣势局（**失败**） |
| **1** | +1 级（如 2→3） | 标准局 |
| **2** | +2 级（如 2→4） | 大胜局（**双上**） |
| **3** | 双上/过 A | 完胜局 |

> 💡 **"胜利"判定**：在批跑 vs lalala 中，**胜局 = 双上（victoryNum≥2 且过 A）**，非简单 victoryNum>0。

## 三、数据结构

- **类型**：四元组 `[P0, P1, P2, P3]`
- **队伍**：`0+2` 一队 vs `1+3` 一队
- **批跑只读 `[0] vs [1]`**（禁止四席相加）
- `[2]`, `[3]` 是冗余副本

**队胜率公式**（口径）：
```
局胜率 = ΣvictoryNum==3 本队场次 / batch_games
副胜率 = 本队当游副数 / 总副数
```

## 四、KPI 口径选择（局 vs 副）

| 指标 | 推荐口径 | 来源 |
|------|----------|------|
| **胜率**（vs lalala） | **局胜率** | [{8}] |
| **平均升级数/局** | 局级聚合 | [{6}] |
| **副胜率** | 仅作辅助（会虚高） | [{8}] |

## 五、关键校验 [GUA-033, 已 closed 2026-05-31] [{5}][{7}]

```python
victory_num = sum_victories_from_game_result()
if victory_num != expected_victory_num(batch_games):
    log.WARNING(...) 
    skip_kpi_calculation()   # ← 不一致则不进 KPI
```

**backfill 范围**：`[0]+[1]==batch_games` 且 `[0]==[2], [1]==[3]`

## 六、当前战况（V7 vs lalala）[{2}][{8}]

| 指标 | V7 | M3 基线 |
|------|-----|---------|
| **局胜率** | 0.7% (1/138) | ~70% |
| **副胜率** | 10.1% (8/79) | 60-70% |

—— V7 **副胜率"看起来还行"**，但**局胜率几乎为零**，这就是「局 ≠ 副」经典陷阱：副级堆积小胜，但赢不下完整一局。[{6}]

## 七、一句话总结

> **`victoryNum` 是局级升级数**（0/1/2/3），不是副胜计数；KPI 应以**局胜率**为准，副胜率仅作描述性参考。
