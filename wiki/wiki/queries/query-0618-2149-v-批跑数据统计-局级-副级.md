# V7 批跑数据统计（局级 / 副级）

## ⚠️ 重要说明

Wiki 中**未直接记录 V7 批跑的具体胜率数据明细**（如「X 局 Y 副，胜率 Z%」这种数字）。以下是基于 Wiki 内容能拼凑出的**结构化信息**：

---

## 一、工具分工（局级 vs 副级）

| 粒度 | 工具 | 路径 | 说明 |
|------|------|------|------|
| **局级** | `analyze_v7_rounds.py` | `scripts/launchers/v-nn/` | 胜率、出牌分布 |
| **副级**（必走） | `analyze_v7_round_levels.py` | `scripts/tools/` | 局 ≠ 副口径校验，curRank 分组统计 |

> **核心原则**：V7 批跑分析**必须同时跑两套**（局级 + 副级），避免 局不等于副 统计陷阱。2][4][9

---

## 二、Wiki 中可见的 V7 胜率数字

| 指标 | 数值 | 来源 |
|------|------|------|
| **V7 vs lalala 副级胜率** | **3.0%** | [[3]] |
| **30% 门槛** | 跨越目标 | [[3]] |
| **胜率目标** | >90%（PHASE3 2026-05-24 升级，旧标准 >50%）| 3][7 |

> Wiki 中多次出现 **3.0% vs lalala** 这个数字，但**未记录**对应的局数、副数、批跑时间戳、随机种子。

---

## 三、批跑入口与配置

```bash
# V7 vs lalala 批跑
python scripts/launchers/v-nn/run_v7_vs_lalala_games.py \
  --config v7_lalala_config.json

# 局级分析
python scripts/launchers/v-nn/analyze_v7_rounds.py results/xxx/

# 副级分析
python scripts/tools/analyze_v7_round_levels.py \
  --records game_records_v7/ \
  --output reports/v7_round_analysis.csv
```

**配置字段**：对手机型、局/副数、输出目录、随机种子（`v7_lalala_config.json`）[[4]]

---

## 四、关键 KPI 指标

按 [[4]] `batch-evaluation`：

- **胜率**（副级口径）— V7 vs Lalala 核心胜负指标
- **副均得分** — 衡量「不是赢就是输」的细节质量
- **决策合理性** — 必杀/接风/还贡等关键决策正确率
- **出牌分布熵** — 衡量策略多样性
