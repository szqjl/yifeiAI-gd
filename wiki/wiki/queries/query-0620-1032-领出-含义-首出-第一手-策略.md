# 领出 含义 首出 第一手 策略

# 领出 / 首出 / 第一手 策略

## 一、核心概念区分

| 术语 | 含义 | 备注 |
|------|------|------|
| **领出** | 每副牌由谁先出第一张牌（领出者） | 由平台/规则决定，不是策略选择 |
| **首出** | 领出者**打出的第一手牌** | 真正的策略决策点 |
| **第一手** | 同"首出" | 口语表达 |

⚠️ **领出 ≠ 首出策略**：领出者是规则产物（谁能领出），首出牌型才是策略产物（领出后打什么）。[2][5]

---

## 二、领出规则（谁先出）[2][5]

| 场景 | 领出者 |
|------|--------|
| 第一副 | 服务器决定 |
| 第二副起（普通进贡） | **进贡给上游者（受贡者）**领出 |
| 双下情况 | 三游领出 |
| 抗贡情况 | 上游（头游）领出 |
| 无进贡（普通升级） | 上游（头游）领出 |

> ⚠️ **平台 vs 实体赛冲突**：实体赛旧规"下游领出"；**M3 引擎以平台 act 为准**（即上表"进贡给上游者领出"）。

---

## 三、首出策略（领出后打什么）

### 1. 牌语信号——首出牌型含义 [4]

| 首出牌型 | 牌语含义 |
|----------|----------|
| **首出小单** | **牌力强**信号（不需要大牌保护） |
| **首出对子** | 情况不明，试探 |
| **首出高单** | 助攻定位 / 交牌权 |
| **首出小顺** | 有打有收 / 牌力强 |
| **首出木板/钢板** | 中性牌 |
| **首出三张** | 弱牌（无力组更大牌型） |

### 2. 高压线原则（首出 P0）[1]

| 原则 | 含义 | M3 状态 |
|------|------|---------|
| **P-H01 / P-G04** | 进贡慎出单 | ✅ M3 P0 实施 |
| **P-H02** | 火不打四（4 头炸慎首发） | ✅ M3 P0 实施 |
| **P-H05** | 顺子慎始发 | ✅ M3 P0 实施 |
| **P-C01~02** | 核心原则（详见原则映射） | ✅ M3 P0 |

### 3. 逢人配首出策略 [7]

| 策略 | 适用场景 |
|------|----------|
| 配炸弹 | 有 4 头火苗子 |
| 补缺 | 缺 1 张成同花顺 |
| 配顺子 | 中段优先（4-5-6-7-8） |
| **预留策略** | **首攻/过渡时暂不配，保留变化**（百搭配 3 放后压） |

### 4. 角色定位驱动的首出 [6]

| 角色 | 牌力 | 首出组牌方向 |
|------|------|--------------|
| **主攻** | ≥5 分 | 全面组牌，奔最大化，可激进配火 |
| **助攻** | 2-4 分 | 精简配火，**保留变化** |
| **超弱** | <2 分 | 配火优先，过渡为主，**大胆配火** |

### 5. 让牌策略（PASS-P01~P04）[3]

首出阶段需考虑「先发有回手」——**先手出牌必须考虑能否收回牌权**，避免让队友陷入困境。

## 四、V7 引擎的首出决策 [8][9]

V7 组牌引擎处理首出流程：

```
输入：手牌 + main_rank + 局况
    ↓
1. SF_FIRST：识别同花顺苗子
    ↓
2. BOMB_FIRST：识别炸弹
    ↓
3. enumerate_groupings()：枚举所有组法
    ↓
4. _score_power()：5 维评分（炸弹 0.3 + 手数 0.3 + 回收 0.1 + 灵活 0.1 + 去单化 0.2）
    ↓
5. 选择 power_score 最高的组法
    ↓
输出：最优组法 + 牌力分
```

### V7 已知限制
- **首发 +1 分未实现**（口诀建议但未纳入）
- **配 5 头炸策略冲突**（未显式惩罚）
- **孤张定律/A 下放**（未量化）
- **GUA-062**：单元测试 27/27 通过，但实战 9 局队胜率 0%——**"单元测试 vs 实战"鸿沟**

## 五、关键数据基础 [10]

| 牌型 | 出现概率 | 首出含义 |
|------|----------|----------|
| 单牌 | 49.55% | 最高频，首出小单=强信号 |
| 对子 | 24.77% | 次高频，开局首选 |
| 三张 | 8.22% | 中频 |
| 炸弹 | 5.13% | 慎首发（P-H02） |
| 顺子 | 4.11% | 慎始发（P-H05） |
| 钢板 | 1.02% | 最低频 |

平均 **38.3 手/局，9.8 手/人**。

---

## 六、总结

1. **领出 = 规则问题**（谁能先出），**首出 = 策略问题**（领出后打什么）
2. **首出小单 = 牌力强**是核心牌语；**首发炸弹/顺子 = 高压线慎用**
3. M3 已实施 P0 高压线（P-H01/02/05 + P-G04），其他原则进 V5+ backlog
4. V7 用 5 维评分枚举最优组法，但**单元测试 ≠ 实战胜率**（GUA-062）
