# 送牌 喂牌 投喂 队友 让牌 送队友

# 送牌 / 喂牌 / 投喂 / 让牌 / 送队友 — Wiki 知识汇总

这些术语在 Wiki 中指向同一类策略簇：**2v2 团队协作中的牌权传递**。M3 和 M1 引擎分别有独立的实现路线。

---

## 一、战略原则层 [3][4]

掼蛋「**配合至上**」原则下的四大喂牌技巧：

| 技巧 | 说明 |
|------|------|
| **让道** | 避开队友牌型（不出大牌抢队友牌权） |
| **反向喂牌** | 逆向支援队友 |
| **拆牌喂牌** | 拆自家牌型喂队友 |
| **先大后小** | 先用大牌清路、再用小牌喂 |

> Wiki 中"送牌 / 喂牌 / 投喂 / 让牌"是同一策略的不同口语表达，最终都映射到上述四类技巧。

---
