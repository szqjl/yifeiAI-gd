# 两手整牌 · 残局冲刺 R6 炸弹 · 头游

## 定位：R6 残局冲刺场景

**判定信号**：
- 手牌 ≤ 10 张 → 触发残局豁免 [[1]]
- 剩两个牌型 → 1-2 轮打完，属于 R6 头游冲刺圈

---

## 核心策略

### 1. 炸弹决策：R6 是最高优先级 [[2]]

| 规则 | 决策 |
|------|------|
| **R6 残局冲刺** | **必出最大整炸抢头游** |
| **R4 剩 4 张默认不炸** | R6 例外 |
| **R5 不压队友** | 冲刺时让位 R6 |

**资源原则**：「谁打谁收」—— 出手必须能收回牌权或直接获胜。

### 2. 牌力自检 [[7]]

- **≥5 分**（主攻）→ R6 必出最大整炸（**P-H02 火不打四在此解禁**）
- **<5 分** → Q：队友更强？让道（PASS-P03） / 否则保留炸弹到最后一手

### 3. 整牌型优先序 [[gua-062|整牌型优先序]]

```
① 同花顺（+3 分，一手清空）
② 4/5 头炸（+2~3 分，R6 触发）
③ 三带二 / 钢板 / 顺子（顺子 P-H05 慎用）
```

---

## 决策树

```
[两手整牌 残局]
  ↓
Q1: 牌力 ≥5 分？
  ├─ Yes → R6 必出最大整炸（P-H02 解禁）
  └─ No  → 队友牌力更强？
              ├─ Yes → PASS-P03 让道
              └─ No  → R6 冲刺，炸弹留最后
  ↓
Q2: 整牌型选择？
  ├─ 同花顺 > 炸弹 > 顺子/三带二
  ↓
Q3: 炸弹出手后能否回手？
  ├─ 能 → 出
  └─ 不能 → 炸弹留最后
```

---

## 高压线在残局的反转

| 高压线 | 首出禁用 | 残局冲刺 |
|--------|----------|----------|
| **P-H02 火不打四** | 4 头炸不首发 | **解禁**：R6 必出最大整炸 |
| **P-H05 顺子慎始发** | 5+ 连牌慎首发 | 仍慎用，两手牌时可接受 |

---

## 一句话总结

**两手整牌残局冲刺头游 = R6 触发 → 牌力 ≥5 分则必出最大整炸**（P-H02 解禁）→ **牌力不足则 PASS-P03 让道** → **整牌型优先同花顺 / 炸弹**。
