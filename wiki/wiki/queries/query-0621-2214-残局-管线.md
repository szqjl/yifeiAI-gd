# 残局管线（Endgame Pipeline）速览

## 核心定位
V7 引擎在检测到**手牌 ≤ N（默认 10）**时注入 `decide()` 主路径的专用决策流程，**优先级最高**，凌驾于标准 Guard 链之上 [1][5]。

## 优先级链
```
残局管线 > GUA-075 > R01-R14 > heuristic
```

## 注入点
`v7_guards.py` 的 `decide()` 中，**`_inject_numofplayers` 之后、GUA-075 主路径之前**注入 `_endgame_context` [1][3]。

## 四角色分派
| 角色 | 触发 | 目标 |
|------|------|------|
| **Q0** 自己冲刺 | 场上最少手牌且主动方 | 跑牌打完收工 |
| **Q1** 敌方封锁 | 敌方有人手牌少 | 出牌权压制 |
| **Q2** 队友助攻 | 队友冲刺+自己有手牌 | 配合、不抢出牌权 |
| **Q3** 普通 | 残局但无上述条件 | 炸弹或常规 |

## 方案 A：硬排除
在 Guard 运行前对 `banned_types` + `baoshu.never_play` **一刀切**。优点是实现简单、所有 Guard 自动受益；代价是粒度粗 [1][4]。

## 三级降级兜底
- **L1**：仍可炸 → 出炸弹
- **L2**：无炸可出 → 被动 PASS
- **L3**：敌人报单+自己无炸+主动方+手牌全单张 → 放宽禁令打级牌以下最大 [1][3]

## 敌双残局处理
**下家优先**（出牌权威胁更大）+ `banned_types` 取**并集** + `recommended` 主目标优先但避所有禁令 [1][3]。
