# 掼蛋出牌顺序与上家/下家策略

## 一、位置关系（基础概念）

掼蛋是 **4 人 2v2 配对制**，按 `curPos` 顺时针推进出牌。位置关系相对于 `myPos`（己方位置）计算：[{2}]

```
downPos    = (myPos + 1) % 4   // 下家（顺时针下一位）
upPos      = (myPos - 1) % 4   // 上家（逆时针上一位）
teammatePos = (myPos + 2) % 4  // 对家
```

**出牌顺序**：每轮接牌方 = `(curPos + 1) % 4`，即下家先接。`curPos` 是当前出牌方（随轮次推进），**不是固定指向某一方**。[{2}]

---

## 二、核心策略：打上家、卡下家

「打上家卡下家」是掼蛋四项基本原则之一——**压制对家上游，阻止其跑牌**。[{1}][{3}]

| 对象 | 策略 |
|------|------|
| **上家** | 主动压制、断其牌路，不让其顺畅出牌 |
| **下家** | 阻止其跑牌、控制牌权交接节奏 |
| **对家（队友）** | 让道、喂牌，配合其先走 |

---

## 三、残局末段的优先级（冲突解决）

当上家/下家策略与队友保护冲突时，遵循以下优先级：[{1}]

| 局面 | 主策略 | 优先级 |
|------|--------|--------|
| 4 人在场 | GUA-029 通用原则 | — |
| 队友 rest | **GUA-031 让道** | 优先于 GUA-034 |
| 对手 [myPos+2] rest | **GUA-034 solo_sprint 拦头** | — |
| 接风 + 队友是 Pair/Bomb | GUA-036 TEAM-P01 接风让道 | **让道 > 评分最高** |

> **冲突铁律**：队友 rest > 对手 rest（互斥时走 GUA-031 让道）；让道（WIND-P01 / TEAM-P01）> 评分最高。[{1}]

---

## 四、配合至上的四大喂牌技巧

针对下家接牌时的 4 种喂牌手法：[{1}]

| 技巧 | 说明 | 典型场景 |
|------|------|----------|
| **让道** | 避开队友牌型，不出大牌抢队友牌权 | 队友即将跑牌 |
| **反向喂牌** | 逆向支援队友（接牌时故意放小） | 队友有 Bomb/Pair 接风 |
| **拆牌喂牌** | 拆自家牌型喂队友 | 队友缺特定牌型 |
| **先大后小** | 先用大牌清路、再用小牌喂 | 多轮连续接牌时 |

## 五、M3 引擎的 PASS-P01~P04 原则

针对上家/下家场景的让牌实现：[{1}]

| 原则 | 场景 | 动作 | 置信度 |
|------|------|------|--------|
| **PASS-P01** | 主动 | 送小单让队友接牌 | high |
| **PASS-P02** | 主动 | 防送炸（不主动给队友出炸机会） | high |
| **PASS-P03** | 被动 | `_is_teammate_greater` 时 `return 0` 让道 | high |
| **PASS-P04** | 主动 | 逢五喂队友 | **low**（未批跑验证） |

**关键边界**：
- **GUA-026**：PASS 不放宽「三带二禁拆炸弹/耗级牌」
- **PASS-P04**：以 flag 控制默认开关，需批跑验证胜率

## 六、领出 vs 首出（关键区分）

出牌顺序中容易混淆的两个概念：[{3}][{5}]

| 术语 | 含义 | 性质 |
|------|------|------|
| **领出** | 每副由谁先出第一张 | **规则产物**（服务器/进贡规则决定） |
| **首出** | 领出者打出的第一手牌 | **策略决策** |

⚠️ 领出 ≠ 首出策略。领出者由规则决定，**首出什么牌型才是策略点**。

**领出规则**（谁先出）：[{3}][{5}]

| 场景 | 领出者 |
|------|--------|
| 第一副 | 服务器决定 |
| 第二副起（普通进贡） | 进贡给上游者（受贡者）领出 |
| 双下 | 三游领出 |
| 抗贡 | 上游（头游）领出 |

## 七、首出牌型的牌语信号

领出后打什么牌型，对上下家有强信号意义：[{3}][{5}]

| 首出牌型 | 牌语含义 |
|----------|----------|
| **小单** | **牌力强**信号（无需大牌保护） |
| **对子** | 试探，意图不明 |
| **高单** | 助攻定位 / 交牌权 |
| **小顺** | 有打有收 / 牌力强 |
| **木板/钢板** | 中性牌 |
| **三张** | 弱牌（无力组更大牌型） |

**首出 P0 高压线**（M3 已强制实施）：[{4}][{6}]

| 原则 | 含义 | M3 状态 |
|------|------|---------|
| **P-H01 / P-G04** | 进贡慎出单 | ✅ P0 |
| **P-H02** | 火不打四（4 头炸慎首发） | ✅ P0 |
| **P-H05** | 顺子慎始发 | ✅ P0 |

## 八、总结要点

1. **位置基准**：上下家是相对 `myPos` 的概念，`curPos` 决定当轮出牌方
2. **核心原则**：打上家（压制上游）+ 卡下家（阻止跑牌）+ 让队友（喂牌/让道）
3. **冲突优先级**：队友 rest > 对手 rest；让道 > 评分最高
4. **首出 > 领出**：领出是规则，首出牌型才是策略决策点
5. **P0 高压线**：进贡慎出单、4 头炸慎首发、顺子慎始发——M3 已实施
