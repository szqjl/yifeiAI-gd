## 二、基于已知信息的策略推断

### 情境假设

假设：**curPos 指向敌方（剩 5 张）**，你手中有 4 张同号炸弹。

### 核心原则应用 [{1}][{6}]

| 原则 | 应用 |
|------|------|
| **打上家卡下家** | 若敌方为上家 → 压制；若为下家 → 阻止其跑牌 |
| **炸弹使用红名单** [6] | ✅ 关键冲刺阶段、阻止对手跑牌 = 建议使用 |
| **炸弹使用黑名单** [6] | ❌ 不能保证回手 = 避免使用 |

### 关键判断点

#### 1. 队友是否需要保护？

- **若队友 rest（即将跑牌）**：**优先 GUA-031 让道** > 评分最高 [{1}]
- **若队友 [myPos+2]（对家）也剩 5 张且为敌方**：触发 **GUA-034 solo_sprint 拦头**

#### 2. 4 星炸弹是否值得炸？

| 局面 | 建议 |
|------|------|
| 敌方 5 张 = 可能是三带二/顺子 | ✅ **炸掉**，封住其常见牌型通路 [7] |
| 敌方已出过大牌型 | ❌ **慎炸**，可能浪费在非关键局面 |
| 你方能回收牌权 | ✅ 炸 |
| 你方不能回收牌权 | ❌ **P-H02 火不打四**（高压线）[7] |

#### 3. 牌力评估

按 [6] 残牌张数策略：
- **5 张大概率是三带二**（统计上最高频）
- 若你方也接近残局，**先中大后小** / **送三带二或顺子**

## 五、结论

**敌方剩 5 张 + 4 星炸弹**的核心判断点：

1. **若敌方处于冲刺位且可能一回合跑完** → 必须炸（红名单触发）✓
2. **若敌方为下家** → 卡下家原则下，**优先阻止其跑牌** → 倾向炸
3. **若队友 rest 且即将跑牌** → GUA-031 让道 > 评分最高 → **未必炸**
4. **若不能保证回手** → P-H02 高压线 → **保留炸弹**
