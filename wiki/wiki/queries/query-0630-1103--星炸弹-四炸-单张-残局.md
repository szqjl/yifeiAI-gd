# 4星炸弹 · 四炸 · 单张 · 残局

Wiki 中没有同时精确覆盖"4星炸弹 + 四炸 + 单张 + 残局"这一特定合成的页面，但可以从**炸弹执行规则**、**残局管线**、**单张技巧**三条线拼出策略。

---

## 一、场景定位：残局冲刺 + 炸弹资源管理

| 信号 | 触发 | 来源 |
|------|------|------|
| 手牌 ≤ 10 张 | 残局激活（`R11_ENDGAME_MODE` 等开关生效） | [[endgame-pipeline]] |
| 手牌 ≤ 8 张 | 残局 Agent 可介入（Q 表可枚举） | [[module-endgame-agent]] |
| 4 头/5 头炸在手 | "四炸"=4 头炸弹，"五炸"=5 头炸弹 | [[bomb-execution-rules]] |
| 剩单张 + 整牌 | 冲刺/抢副关键节点 | [[skills-04-single-card-skills-summary]] |

## 二、炸弹决策：R6 残局冲刺是最高优先级

来自 [[bomb-execution-rules]]：

| 规则 | 触发 | 决策 |
|------|------|------|
| **R6 残局冲刺** | 残局 + 对手牌力强 | **必出最大整炸抢头游** |
| **R4 剩 4 张默认不炸** | 手牌 ≤ 4 | 默认不炸，**R6 例外** |
| **R5 不压队友** | 队友已炸 | 残局冲刺时让位 R6 |

### 4 头炸（"四炸"）的关键约束

- **P-H02 火不打四**：4 头炸**首出禁用**，但**残局冲刺 R6 是唯一合法解禁** [1][6]
- **一炸保两单**：组炸多出 2 单可接受 [1]
- **破二炸弹不能搭**：破 2 头的炸弹不要硬搭 [1]
- **慎组天王炸**：拆王压单/对要谨慎 [1]

### 5 头炸（"五炸"）= 终极冲刺武器

- 一手清空概率最高（+2~3 分）[1]
- 出牌顺序：先整后炸为常态；对手段位低且自己同张数时可先炸后整 [3]

## 三、单张策略：GUA-062 阈值判定

来自 [[skills-04-single-card-skills-summary]] [9]：

| 单张数 | 占比 | 判定 | 残局动作 |
|--------|------|------|----------|
| 0-2 张 | 0-7% | 牌型整齐 | 整牌/炸弹冲刺 |
| 2-4 张 | 7-15% | 正常 | 常规处理 |
| 5-6 张 | 19-22% | 单张较多 | **优先处理单张** |
| >7 张 | >26% | 组牌有问题 | 重组或 PASS 让道 |

### 单张选择子技巧
- **顺上家** / **控下家** / **让对家** / **卡点出单送队友过单** [9]
- **P-H01 双贡慎单**：双进贡情况下对单张选择要特别谨慎 [9]

## 四、决策树：四炸 + 单张 + 残局

```
[残局 持有 4/5 头炸 + 单张]
  ↓
Q1: 自己是场上最少手牌且主动方？
  ├─ Yes → Q0 自己冲刺
  │         ├─ 单张数 >4 → 先出单张清场
  │         ├─ 单张数 ≤4 → R6 必出最大整炸（P-H02 解禁）
  │         └─ 5 头炸 > 4 头炸 > 整牌 > 同花顺
  └─ No  → Q2/Q1/Q3 路线
              ├─ Q2 队友冲刺 → 送单过牌 (卡点出单)
              ├─ Q1 敌方封锁 → 炸弹压牌权 / 单张避让
              └─ Q3 普通 → L1 仍可炸 → L2 PASS → L3 放宽
  ↓
Q2: 炸弹出手后能否回手？
  ├─ 能 → 出（P-H05 顺子慎用原则）
  └─ 不能 → 改出单张，炸弹留最后
  ↓
Q3: 单张打给谁？
  ├─ 上家有利 → 顺上家
  ├─ 下家威胁 → 控下家（Q / JK / 卡小单）
  └─ 队友需过 → 卡点送队友
```

## 五、残局管线的硬约束

来自 [[endgame-pipeline]] [2] 与 [[module-endgame-preprocessor]] [7]：

| 决策点 | 当前选择 | 影响 4 头炸 + 单张 |
|--------|----------|---------------------|
| 注入位置 | `_inject_numofplayers` 之后 | numofplayers 必须先就绪 |
| 排除方式 | 方案 A 硬排除（`banned_types` + `baoshu.never_play`） | 单张可能被 `never_play` 禁 |
| R11 退让 | `partial`（阈值上调但仍抑制） | 4 头炸在残局仍受部分抑制 |
| L3 降级 | 敌人报单 + 自己无炸 + 主动方 + 手牌全单张 | **级牌以下最大**（无则出全部） |
| 敌双残局 | 下家优先 + `banned_types` 并集 | 炸弹需避所有禁令 |

## 六、紧张点与待验证

1. **GUA-062 实战鸿沟** [1][8][9]：V7 单元测试 27/27 通过，但 9 局批跑**队胜率 0%**——单张阈值判定尚未经批跑验证
2. **残局 Agent 关键瓶颈** [10]：激活率 66%，Q 命中率 36.5%，**端局残局胜率贡献几乎为 0**
3. **R11 退让级别未拍板** [2][4][5]：`partial` 是实验选择，待 `full_cede` / `threshold_only` A/B 验证
4. **4 头炸在 V7 残局的合法性** [1]：P-H02 解禁有设计依据，但代码边界未完全固化
5. **同牌数冲突保守策略** [3][4]：Q1/Q2 同牌数时封锁优先（Q1 胜），有损但安全

---

## 七、一句话总结

**4 头/5 头炸 + 单张 + 残局** = **残局激活** → **单张数 ≤4 则 R6 必出最大整炸抢头游**（P-H02 火不打四在此解禁）→ **单张数 >4 则先清单张**（顺上家/控下家/卡点送队友）→ **炸弹留作最后冲刺或牌权回收**（R11 `partial` 退让）→ **无炸+全单+敌人报单时触发 L3 放宽**（级牌以下最大）。

> ⚠️ 此决策树尚未经批跑验证，残局胜率贡献当前几乎为 0（GUA-062 / 残局 Agent 瓶颈）。
